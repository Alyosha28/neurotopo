# EXP-0001 v2 — Delayed evidence, block vs random recurrence

Registration date: 2026-09-23; v1 registered before implementation; v2 amendment frozen before scientific outcomes, after independent pre-run audit identified unmatched self-feedback. Decision scope is deliberately narrower than research Q1.

## Question and causal link
Does a block-independent GRU outperform a degree-matched connected random-mask GRU on delayed-evidence retrieval and overt answer revision at equal effective/allocated parameters, hidden-state count, training examples and dense execution operations?
Tested link: recurrent connectivity → computation. Representation semantics and general capability are untested. Block independence is an operational minimal multi-trajectory model, not evidence of competing hypotheses.

## Prior art and strongest rejection
RIMs already cover independent recurrent modules and sparse communication. No RIM replication or novel mechanism is claimed. conn2res is inspected for reuse; reservoir/readout-only optimization does not implement this BPTT question. Relevant inspection is recorded before the formal run in `research/prior_art/`.
Strongest rejection: all models may solve the task by caching candidate values and selecting later. Two supervised outputs establish observable answer revision, not internal belief revision. Also one training schedule cannot compare best achievable model performance.

## Task: delayed-evidence-v1
Four candidate IDs each carry a distinct random label from four classes (uniform random permutation). Four memory events arrive in independently shuffled order; prior cue identifies a candidate. A random delay (4 or 8 distractor events in training) follows; each distractor contains random ID/value with a distinct nuisance event tag. At a query event, predict the prior candidate's value. Then a reliable selector identifies either that candidate (confirm) or a uniformly selected other candidate (revise). After two more distractors, a final query requests that candidate's remembered value.
Each batch consists of counterfactual pairs sharing the exact prefix, suffix nuisance and candidate mapping, differing only in selector. One confirms, one revises. Thus revise always changes the true label. The selector never contains the label. Independent local RNG; class values and event channels are disjoint. Both output cross-entropies weighted 0.5. Output readout shared between times.
Held-out IID delay 8 and OOD delay 16, each 1,024 pairs; common fixed test seed 91001 + delay; no model selection on these sets. Training draws fresh independent pairs from seed 100000 + run seed. Training schedule shared for every model. No validation-based tuning, early stopping or checkpoint selection. Final checkpoint only. A prefix-free selector-only rule is chance 25%; a prior-only oracle reaches confirm 100%, revise 0%; full memory oracle 100%.

## Models
- M0: dense GRU, H=16, single state.
- M1: dense GRU, H=64; state-capacity-matched wider control, more effective weights.
- M2: tanh RNN, H=64, random regular recurrence degree 16; secondary only, dynamics confounded.
- M3: GRU, H=64, K=4 independent blocks of width 16; all blocks see all input channels; one linear readout on concatenated state. No adaptation, communication, routing, attention or auxiliary diversity loss.
- C0: GRU, H=64, random directed regular mask with 16 incoming and outgoing connections per node, strongly connected. Same mask across GRU gates; preserves all 64 diagonal self-connections exactly as in M3; randomize only non-diagonal edges and reject swaps creating diagonal edges. Masks sampled using degree-preserving directed double-edge swaps from block adjacency; mix 50 × non-diagonal edges successful swaps, reject disconnected samples. This is an algorithmic synthetic control, not a uniformly sampled graph or biological null model.
M3 and C0 use identical dense allocated matrices, elementwise masks and gate equations (PyTorch GRU reset-gate convention). Biases/readout/input weights and seed initialization are paired; recurrent weights scale by effective fan-in. Random graph seed = 200000 + run seed. Graph hashes, degrees, diagonal counts, connectivity and accepted swaps saved; diagonal equality is checked by analysis.

## Fixed budget and accounting
10 paired seeds 0–9. Each model: Adam lr=0.003, no weight decay, clip global gradient norm 1, 400 updates, batch=64 sequences (32 pairs), one recurrent update per input event. Train delay alternates 4/8 by update (same tokens per model). CPU float32, one thread, deterministic algorithms. No hyperparameter search.
Record active and allocated parameters, recurrent/non-recurrent weights, hidden floats, gate temporary count, nominal active MACs, actual dense forward linear MACs, 2 FLOPs per MAC, elementwise-mask multiplies, examples/tokens, state/parameter bytes, measured training runtime and inference median latency. Full backward FLOPs and process peak memory not claimed measured; report a labelled 3× forward training linear FLOP estimate with exclusions.
Primary matched pair must have exact equal counts and schedule; otherwise no scientific decision. Dense wider GRU has more effective parameters; M0/M2 comparisons are contextual. Full-state wider GRU executes the same dense linear sizes as M3, but mask overhead and optimization capacity differ.

## Outcomes and analysis
Primary outcome: joint pair success (both prefix answers and both final answers correct) on IID delay 8. Prespecified robustness endpoint: same on OOD delay 16. This unconditional outcome avoids selection on a model-dependent early-correct subset. Secondary: pre accuracy, confirm/revise accuracy and NLL, revise accuracy conditional on correct prefix, prior-consistent error on revise, paired final success, evidence sensitivity, training loss.
Paired unit is one model/graph/training seed, not one test example. Mean seed differences and deterministic 20,000-resample percentile paired-seed bootstrap 95% CIs; show all seeds and sample SD. Test population uncertainty conditional on these fixed sets is not included. IID/OOD support is a conjunction; additional model comparisons are exploratory, no best-comparison selection.

## Decision rule
SUPPORTED (bounded structural claim only): M3−C0 joint accuracy ≥0.03 with CI lower >0 on BOTH IID and OOD; confirm degradation ≤0.01 in both; pre accuracy ≥0.90 in both models/IID; additionally M3 must beat M1 joint accuracy by mean ≥0.03 in both (no additional CI criterion for this contextual contrast) to advance broad Gate 1. If structural thresholds pass but wider control does not, classify PARTIALLY_SUPPORTED and do not advance Gate 1.
FALSIFIED (this fixed-budget prediction only): training/sanity checks pass, both primary models IID pre accuracy ≥0.90, and primary IID effect CI upper <0.03 (excludes registered minimum useful gain). If stable adverse effect at OOD alone or thresholds partly pass, PARTIALLY_SUPPORTED only if a supported scoped positive effect exists; otherwise INCONCLUSIVE. Inadequate learning, resource mismatch, non-finite results or uncertainty spanning threshold imply INCONCLUSIVE. Failure to pass does not establish equivalence or universally falsify multi-trajectory models.
No gate advancement from this task alone establishes semantic trajectories. No adaptation may be added to rescue the result. Retain all outputs and report the simplest explanation.
