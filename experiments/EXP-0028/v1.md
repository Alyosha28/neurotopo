# EXP0028 v1：ARCH-0001 A1 实现、工程检查与可学习/非封顶任务资格

2026-09-29。目标门为 `ARCH-GATES-v1` 的 **A1 可运行计算**（`research/stage_gates.md`）。候选合同为 [`SC-REL-v3`](../../research/design/arch0001_successor_compatible_core_v3.md)（A0 冻结，决定0102）；本协议只问"候选与强控制能否端到端训练、状态更新与测试能否复现、任务是否有信息与非封顶余量、资源与工程失败是否记录"，不作 A2 效果判词。旧 Gate 1、ResearchLoop 与既有实验判词不变。

本协议在实现与任何研究数据之前冻结。运行后不得修改本文件；协议变更须开 v2 并保留 v1。

## 问题与最强反驳

问题：`SC-REL-v3` 及其预写主控制 `INV-COMP` 能否在预先限定的命令响应任务上达到基本学习资格，并且存在控制侧非封顶余量的任务条件？

最强反驳（运行前记录）：A0 合同与 EXP0020/0021/0023 证据显示，无噪二值命令响应任务上的强 `INV`/结构化模型多 seed 已达 100% 或 99.94% 全时点准确率；候选与 `INV-COMP` 的差异只是有限预算下的计算路径偏置，因此本任务族很可能**不存在**同时可学习且控制非封顶的条件。若扫描菜单内全部条件封顶或不可学，本实验的预期结论就是"该菜单不能承载 A2 比较"，而不是候选优越或失败。

先例边界：`s_0,s_1` 是当前 Gram 的确定函数，不增加状态信息（决定0102）；共同旋转下的内积编码、正交不变量与动作条件未来测试分别有经典/近邻先例（`research/prior_art/evidence_matrix.md`、`novelty_boundary.md`）。本协议不主张机制新颖性。任务信息检查（见下）还须显式记录"简单显式解法"是否存在。

## 候选、控制与臂

- `CAND` = `SC-REL-v3`：六值递归状态 `H∈R^{3×2}`；学习编码器 `Embedding(2,6)` 经列径向变换与初始共同旋转得 `H0`；每步先施加环境扰动 `N_t` 得 `V=Tφ(N_t(H_{t−1}),u_t)`，再对两个假设命令各做一次无未来扰动的 `Tφ(V,v)` 读出 `s_0,s_1`，修正器 `Bθ=0.1·tanh(MLP([g(V),s_0,s_1]))∈R^{2×2}`，输出 `H_t=radial(V(I₂+Bθ))`，逐步读出 `r(H_t)=wᵀg(H_t)+b`。基础转移 `Tφ(H,u)=radial(H(I₂+Aφ(g(H),onehot(u))))`，控制器为 `Linear(5,32)→Tanh→Linear(32,4)`；修正器为 `Linear(5,32)→Tanh→Linear(32,4)`，末层零初始化，故起始修正为0。
- `EXTRA_SUP` = 与 `CAND` 同控制器、同编码器/读出的固定"基础 REL"臂：不施加 `Bθ`，但同样计算两次假设转移、接受同一分支监督。用于避免把额外监督误判为修正机制。
- `INV_COMP` = 预写强不变量控制：`J₁=radial(reshape(M₁([g(H),onehot(u)]),3,2))`，`Jⱼ=radial(Jⱼ₋₁+reshape(Mⱼ([g(Jⱼ₋₁),onehot(u)]),3,2))`，每块 `Linear(5,w)→Tanh→Linear(w,6)`，读出同为 `r(J_d)`。菜单 `w∈{32,48,64,96}×d∈{1,2,3}`（12项），编码器、扰动输入顺序、分支监督、训练样本与优化预算同候选。
- `INV32_1` = 菜单项 `(w=32,d=1)`，仅用于任务难度扫描与 IID8 前测，不自动成为 A2 主控制。

模型初始化（种子 `s`）：构造后 `torch.manual_seed(s)`；编码器 `N(0,.5)`、读出 `weight~N(0,.1)`、`bias=0`；控制器/控制块首层 `xavier_uniform(gain=1)`、末层 `xavier_uniform(gain=.5)`、bias=0；修正器首层 `xavier_uniform(gain=1)`、末层零初始化、bias=0。`CAND` 与 `EXTRA_SUP` 的编码器/读出/控制器初始权重逐位相同。

## 任务与数据生成

沿用 EXP0020v2 的二值 HOLD/FLIP 命令响应任务与公开生成规格：初始位 `b0` 半0半1随机置换；每步命令 `u_t∈{0,1}`；真值 `b_t=b_{t-1} xor u_t`；每步先对物理状态施加共同旋转 `R_t`（轴单位高斯、角均匀 `[-amp,amp]`、Rodrigues），可选对第二列施加额外旋转 `E_t`（leak 幅），再进入模型。`MIX` 序列半数为全 HOLD，半数为第一步强制 FLIP 的 i.i.d. Bernoulli(.5) 更新流。

本协议新增一个**登记过的扰动轴**：观测噪声 `ε_t`。生成器在旋转/leak 之后加入 `ε_t∼N(0,σ²I_{3×2})`，模型只收到加噪后的 `H` 与当期命令，标签始终是无噪真值 `b_t`；`σ=0` 时逐位复现 EXP0020 生成器（工程测试断言）。该轴用于构造"当前读出容易、持续跟踪困难"的条件；它改变的是任务难度，不改变候选方程、读出或分支监督定义。

评估流一律 1024 条、`MIX`；一条流同时含 HOLD 行与 UPDATE 行。主评估共同旋转幅为 `π`（训练幅为 `.4`，故为分布外外推），次评估为 `.4`。

## 判据（运行前冻结）

**工程检查（全部通过才算 A1 可运行前提）**：形状与有限值；规范检查分两类——`CAND`/`EXTRA_SUP` 做全路径共同旋转等变（把 `common/leak/noise` 按 `R·R_t·Rᵀ` 共轭、初态加 `R`，logits 逐位一致，容差 1e−5），`INV_COMP` 按设计重生成规范状态、不做全路径等变，改为单步更新对输入左乘 `R` 的规范不变（容差 1e−5）；单一递归状态（state_dict 无额外递归缓冲）；训练/推理算子调用数符合登记值（`CAND`/`EXTRA_SUP` 推理每步 3 次基础转移 + 1 次修正器，训练每步 5 次基础转移 + 1 次修正器；`INV_COMP` 推理每步 `d` 块、训练每步 `3d` 块）；全部参数在第二次更新时获得有限非零梯度（修正器末层零初始化，首步其上游为零梯度，登记为两步规则）；前缀一致性（改写未来命令/标签不改变过去 logits）；同种子两次前向哈希一致；`σ=0` 生成器与 EXP0020 逐位一致；固定 4 样本 T1 tiny-fit 50 步（lr=1e−2）loss 至少下降 10%。

**任务信息检查（两个证据同时满足）**：(i) 目标为 `(b0, commands)` 的确定函数，由运行内独立 XOR 重算核对、无标签噪声；(ii) 在 `σ=0` 上存在并实测一个简单显式解法（Gram 重编码器：由 `g(H)` 恢复当前位、施加命令、输出规范状态），该解法在无噪条件的翻转时点准确率 ≥ .995。`σ>0` 条件下"信息"由合格控制的准确率显著高于随机（见下）与目标确定性共同支持；`σ>0` 的最优可达上界未知，此项列为 A2 校准的未决限制，不在 A1 内声称。

**控制侧非封顶（任务合格）判据**：对菜单第 i 项，用 `INV32_1`、种子 `28101,28102`、1000 次固定更新课程训练，在主评估流上记 `flip_accuracy`（命令为 FLIP 的时点准确率）与 `hold_accuracy`。合格当且仅当：两 seed 均值 `flip_accuracy∈[.60,.95]`、每 seed `∈[.55,.97]`、`hold_accuracy` 均值 `≥.60`。取菜单预定顺序中**第一个**合格项为合格条件；全部 8 项尝试与结果保留。菜单顺序：`(64,leak0,σ0)`、`(256,leak.4,σ0)`、`(64,0,.05)`、`(64,0,.15)`、`(64,0,.4)`、`(256,.4,.05)`、`(256,.4,.15)`、`(256,.4,.4)`。

**主控制选择（仅在存在合格条件时）**：用同条件、同预算、种子 `28101,28102` 训练全部 12 个 `INV_COMP` 菜单项；保留通过学习资格（`flip_accuracy` 均值 `≥.60`、每 seed `≥.55`、`hold_accuracy` 均值 `≥.60`）的项，按实测执行算子估计量与候选的绝对对数比最小选主控制；平局取参数少者。与候选的算子比、参数、样本、更新与实测时延逐项披露；看候选结果前不更换选择规则。

**A1 学习资格（合格条件上，独立种子 `28111,28112,28113`）**：`CAND`、选定 `INV_COMP`、`EXTRA_SUP` 三臂各 3 seed、1000 次固定更新课程。每臂通过当且仅当：`flip_accuracy` 三 seed 均值 ≥.60、每 seed ≥.55、`hold_accuracy` 均值 ≥.60、无工程失败、且种子 `28111` 的独立重放哈希/指标一致。A1 只要求两臂"能学"，**不要求 `CAND` 优于控制**。

**IID8 前测（合同 A1 第1步，不计 A1 通过）**：`CAND` 与 `INV32_1`、种子 `28101..28103`、1000 次课程更新，评估 EXP0020 的 IID_H/IID_U/LONG_H/LONG_U/ROT_H/ROT_U/LEAK01_U/LEAK04_U 八格；记录是否达到 EXP0020 的 `≥.95` 学习旗标，仅作前测证据。

## 判词表（互斥）

| 条件 | 判词 |
|---|---|
| 工程检查任一失败 | `INCONCLUSIVE / ENGINEERING_FAILURE` |
| 菜单内无合格条件 | `INCONCLUSIVE / NO_QUALIFIED_CONDITION` |
| 有合格条件但 12 项控制全不通过 | `INCONCLUSIVE / CONTROL_QUALIFICATION_FAILED` |
| 有合格条件与主控制，但任一臂学习资格失败 | `INCONCLUSIVE / LEARNING_QUALIFICATION_FAILED` |
| 工程、任务、控制、学习四项全部通过 | `SUPPORTED / A1_RUNNABLE` |

`SUPPORTED` 只说明候选与强控制在限定任务/种子/预算上可训练、可复现、任务有信息与非封顶余量；A2–A6 仍未评估，旧 Gate 1 仍 `NOT_PASSED`。

## 训练、资源与失败保留

固定课程沿用 EXP0020：1000 次更新、batch 64、Adam lr=3e−3 betas(.9,.999) eps1e−8、clip1、长度课程 T1/T2/T4/T8（125/250/500/1000），训练共同幅 `.4`，训练 leak 与 σ 取该条件值；全时点 BCE 均值 `L_actual` 加 `0.1·L_branch`，无早停、无 checkpoint 选择、不换 seed/LR。逐臂记录 loss、监测曲线、检查点、评估 logits、数据与源码哈希。

资源记录：研究更新数、样本数、每 token 内部转移次数、分配/有效参数、递归状态值与字节、算子级执行估计量（MAC 计数，标注为估计）、实测训练/评估时延与进程 CPU 时间；峰值内存未测则明示 `NOT_MEASURED`。非有限值、超时、缺记录均写失败文件并保留。

预算上限：研究更新 60000；单次运行墙钟 1800 秒；独立重放 600 秒。
