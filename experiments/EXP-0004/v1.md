# EXP-0004 v1 — Matched recurrence under learned curriculum, long-delay transfer

Conditional registration: run only after independent review accepts EXP-0003's original-noise curriculum feasibility. The fixed schedule is transferred unchanged; fresh seeds and final tests. No biological or adaptive mechanism.

## Question / scope
Does block-independent recurrence improve delayed-evidence retention and overt answer revision over matched random recurrence after both learn the IID task? Causal link: recurrent connectivity → computational generalization. Prior art: RIMs/conn2res/TRNN already cover modularity, memory and recurrence; this is a bounded test, not a novelty claim. Cached candidate values remain a sufficient solution.

Strongest rejection: performance can reflect optimization under one curriculum; longer-delay effects need not imply competing semantic hypotheses. EXP-0003's delay8/16 dense scores are near ceiling, so testing a 3pp improvement there would have inadequate headroom. Before inspecting any EXP-0004 outcome, choose noise delay32 as primary and delay64 as prespecified robustness; delay8 is training-adequacy, delay16 descriptive transfer. This choice is informed by calibration, not this study's final tests. No selection of the best delay after results.

## Decision rules
IID adequacy: every M3 and C0 seed at delay8 has pre≥0.90 and joint≥0.50. If it fails, INCONCLUSIVE for transfer attribution; record optimization failures as practical adverse outcomes. Additional primary floor guard: if BOTH M3 and C0 mean joint accuracy at delay32 are below0.10, classify INCONCLUSIVE. This prevents a near-chance long-delay comparison being interpreted as equivalence.

Paired training/graph seeds are replication units. Deterministic20000-resample percentile bootstrap (seed640001), report mean effect, SD,95%CI and every seed. Primary comparison M3−C0 on joint pair accuracy; secondary contextual comparison M3−M1. No cross-seed best checkpoint.

SUPPORTED, scoped structural-transfer claim: M3−C0 mean≥0.03 and95%CI lower>0 at BOTH32 and64, confirm degradation≤0.01 at both, and M3−M1 mean≥0.03 at both. PARTIALLY_SUPPORTED if structural thresholds pass but wider baseline does not. FALSIFIED for the registered ≥3pp primary benefit prediction only if adequacy/matching/floor checks pass and delay32 CI upper<0.03. Otherwise INCONCLUSIVE. Report ceilings as limited sensitivity, not universal lack of value. No automatic semantic-specialization or biological claim.
