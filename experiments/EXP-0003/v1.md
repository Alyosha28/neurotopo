# EXP-0003 v1 — Nuisance payload × curriculum learnability

Registered 2026-09-23 before implementation/results. Follow-up to the failed delayed-task learning in EXP-0001/0002; no architectural mechanism is added. Causal chain: input/training conditions → computational task performance. Prior art: curriculum learning (Bengio et al., ICML 2009), RNN optimization difficulties (Pascanu et al., ICML 2013), plus existing RIMs/TRNN boundaries; see research/prior_art/learning_conditions.md.

## Question and rejection
Can a fixed length curriculum restore H64 dense-GRU learning of the original delayed-evidence task, and is random distractor payload associated with the failure? Strongest rejection: changing nuisance payload also changes input magnitude; changing curriculum alters training distribution, length and target-delay exposure. Neither intervention identifies a unique gradient mechanism or semantic interference.

## Frozen factorial
Four arms: noise_direct, blank_direct, noise_curriculum, blank_curriculum. Same H64 dense GRU, Adam0.003, batch64, clip1, two-output CE (0.5 each), float32 deterministic CPU1, 6000 updates; paired seeds 8101–8103. Direct schedule: delay8 ×6000. Curriculum: delay0 ×2000, delay2 ×1000, delay4 ×1000, delay8 ×2000. Fixed start segment uses previously observed delay0 feasibility at update2000; later schedules are hypotheses, not tuned outcomes. No early stopping/extension.

Blank intervention: generate the original batch first, then clear only the candidate/value channels at ALL DISTRACTOR-tagged events, including the two post-evidence nuisance events. Preserve type tags, event positions, sequence length, memory/prior/selector, targets and RNG consumption. Noise is the exact original generator. Arm pairs at the same schedule share all draws, initial weights and optimizer; across schedules RNG streams have different draw consumption. All arms have equal updates/examples, but curriculum has fewer processed tokens/linear FLOPs. Report both. No efficiency or architecture comparison is inferred.

Training RNG=510000+seed. Fixed monitoring RNG=520000+delay; 256 pairs, evaluated at updates400/2000/3000/4000/6000 for the currently trained delay and payload. No decisions use monitoring. Final-only held-out RNG=530000+delay, 1024 pairs, ALL arms evaluated on noise/blank × delays8/16. Fixed final checkpoint; final tests are distinct from EXP-0001/0002 and monitoring.

## Outcomes and decisions
Primary: final noise delay8 pre accuracy and unconditional joint counterfactual accuracy. Feasible means each of all 3 seeds meets pre≥0.90 and joint≥0.50. Secondary: cross-payload, OOD16, confirm/revise, NLL, conditional revision, evidence sensitivity and monitoring curve. Report every seed and paired differences; three seeds are feasibility screening, not a precise population effect estimate.

SUPPORTED (bounded curriculum recovery): noise_curriculum is feasible and beats noise_direct joint accuracy by≥0.10 in every paired seed. PARTIALLY_SUPPORTED: a blank arm is feasible or a noise arm is feasible without satisfying the preceding recovery contrast. INCONCLUSIVE: no arm is feasible. FALSIFIED is not used for broad architecture claims. Performance drops/inconclusive findings count as information for the workflow.
