# EXP0029 v1：ARCH-0001 候选学习资格复现与失败模式诊断（12 seed）

2026-09-29。目标门为 `ARCH-GATES-v1` 的 A1 学习资格条款；候选仍为已冻结的 [`SC-REL-v3`](../../research/design/arch0001_successor_compatible_core_v3.md)（A0，决定0102），本轮**不修改候选、协议、损失或推理路径**，只做复现扩样与失败机制诊断。上一轮 EXP0028 v1 判词 `INCONCLUSIVE / NO_QUALIFIED_CONDITION`（决定0103）：工程与复现通过，任务菜单无合格条件，且 IID8 前测 `CAND` 2/3 seed、`INV_COMP` 3/3 seed。本协议只回答"学习资格在本预算下有多可靠、失败长什么样"；不产生 A2 效应判词，也不改变 A1 因任务余量未过而仍未通过的状态。

## 问题与最强反驳

问题：在 EXP0028 冻结的 IID8 课程与预算下，`CAND`、`EXTRA_SUP`（基础 REL＋同分支监督）、`INV_COMP(w32,b1)` 的 12-seed 学习资格失败率与失败模式是什么？失败是否与共享基础部件（编码器/控制器/读出）或修正器路径相关？

最强反驳（运行前记录）：EXP0028 的 1/3 失败可能只是单次随机事件；12 seed 完全可能全部通过，从而说明 3-seed 规则本身过于苛刻，而不是候选不稳。反之，若失败率接近 1/3，任何 A2 比较都建立在不可复现的学习资格上，必须先做 v4。两种结果都按下表裁决。

## 设计

- 臂（3）：`CAND`＝`SC-REL-v3`；`EXTRA_SUP`＝同控制器/编码器/读出、同分支监督但不施加修正的基础 REL（A0 合同的控制臂）；`INV_COMP(w32,b1)`＝A0 合同的预写强控制菜单项。实现直接复用已冻结的 `src/neurotopo/arch0001_core.py`，不修改该文件。
- 种子：`28201..28212`（12 个新 seed，未用于 EXP0028 的扫描/前测/保留集）。同一 seed 内三臂共享训练数据流（配对比较），不同 seed 的初始化与数据均不同。
- 训练：与 EXP0028 前测逐项相同——1000 次更新、batch 64、Adam lr=3e−3 betas(.9,.999) eps1e−8、clip1、长度课程 T1/T2/T4/T8（125/250/500/1000）、训练共同幅 `.4`、leak0、σ0、`L=L_actual+0.1·L_branch`；无早停、无 checkpoint 选择。
- 评估：EXP0020 的 8 个 cell（IID_H/IID_U、LONG_H/LONG_U、ROT_H/ROT_U、LEAK01_U/LEAK04_U），每 cell 1024 条；评估流按 seed 独立（`root=[285001, seed, length, mode_id]`），不跨 seed 复用同一条流。全部 cell 报告，不据结果选择。
- 预算：36 个拟合、36000 研究更新；墙钟上限 1800 秒；独立重放上限 600 秒。非有限值、超时、缺记录一律写失败文件并保留。

## 主终点与判词表（运行前冻结）

主终点：每臂通过 EXP0020 学习旗标的 seed 数；旗标＝`IID_H` 全时点准确率 ≥.95 且 `IID_U` 全时点准确率 ≥.95 且 `IID_U` 翻转时点准确率 ≥.95。

失败模式分类（只看失败 seed）：`HOLD_COLLAPSE`＝`IID_H`≥.95 且 `IID_U` 翻转时点 ≤.65；`PARTIAL_FIT`＝`.65<`翻转时点`<.95` 且 `IID_H`≥.90；`TASK_LEARNING_BROKEN`＝`IID_H`<.90；`ENGINEERING`＝非有限值/异常/缺记录。

| 条件（互斥，按序判定） | 判词 |
|---|---|
| 任一臂出现 `ENGINEERING` 失败 | `INCONCLUSIVE / ENGINEERING_FAILURE` |
| `INV_COMP` 通过 <11/12 | `INCONCLUSIVE / CONTROL_LEARNING_UNRELIABLE` |
| `CAND` 通过 <11/12 | `INCONCLUSIVE / CANDIDATE_LEARNING_UNRELIABLE`（v4 前置条件，见决定0104） |
| `CAND` ∈{11,12}/12 且全部失败均为 `HOLD_COLLAPSE` | `PARTIALLY_SUPPORTED / LEARNING_QUALIFICATION_AT_BUDGET` |
| 其余（失败存在但不可归类） | `INCONCLUSIVE / FAILURE_MODE_UNRESOLVED` |

判词只针对"该预算/该前测任务上的学习资格"；`PARTIALLY_SUPPORTED` 不表示候选可用于 A2，也不表示 A1 通过（A1 仍缺非封顶合格任务）。

## 预注册诊断（不参与判词，只用于解释与 v4 设计）

1. 训练损失检查点：每 seed 记录第 125/250/500/1000 步附近 25 步均值，检查失败是早期停滞还是晚期不收敛。
2. 命令响应一致性：评估流上 `response_joint_accuracy`（对两个假设命令的后继读出同时正确）与 `current_ok_next_response_bad`，用于判断失败是"命令不敏感"还是"状态错误"。
3. 臂间配对：逐 seed 记录哪几条臂同时失败，判断失败是否与共享基础部件相关（三臂同败）还是修正器路径相关（仅 `CAND` 败）。
4. 全部 8 个 cell 的逐 seed 准确率与失败 seed 的逐 cell 明细；不做任何事后筛选。
5. 与 EXP0028 已暴露的 3 个 seed 分开报告，不与新 seed 合并做主终点。
