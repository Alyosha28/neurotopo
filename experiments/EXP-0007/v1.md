# EXP-0007 v1 — Cross-delay transfer of a frozen-state linear readout

Registered 2026-09-23 before implementation or EXP-0007 outcomes. ITER-0004 excluded a large deficit in **within-delay** uncued candidate decoding at delay32, while the original pretrained task readout still lost accuracy. This is a new observational diagnostic within the existing Gate1 boundary; no recurrent architecture, topology, checkpoint or training schedule changes. Prior art: `research/prior_art/cross_delay_decoding.md` and `representation_probes.md`. The directly tested chain link is hidden-state representation → fixed linear readout transfer; no biological or semantic trajectory claim.

## Question and strongest rejection

Does a linear readout of the **prior-cued candidate value** fitted from delay8 hidden states lose more accuracy when applied to delay32 states of the independent-block GRU than the matched random-mask GRU, relative to each model's own delay32-fitted readout?

Delay8→32 changes both the number of full-noise distractors and recurrent updates. Even a positive model difference shows only transfer properties of this fixed ridge family. Hidden-state mean/variance shifts, input accumulation, nonlinear geometry, finite sample effects and ridge regularization can each contribute. The probe differs from the original task head, which was trained jointly across both output times and multiple short delays; it cannot establish that its failure caused the original task gap.

## Frozen material and data

Use the thirty tracked checkpoint inputs from EXP-0005, source EXP-0004 commit `eec9ca4`, models M3 `multi_gru`, C0 `random_gru`, contextual M1 `gru_wide`, seeds9101–9110. Verify byte hashes, reconstructed initial parameters/masks and exact original delay32/64 score replay for each model. Source model weights never update. M3/C0 state, effective/allocated parameters and original inference steps are matched; M1 is contextual with more effective parameters.

Use only the original full-noise task generator. Fit delays: 8,32,64. Each head uses 4,096 **unique counterfactual prefixes**, with late evidence and suffix excluded from hidden extraction. For fit A, RNG=`930000+delay`; for validation RNG=`940000+delay`; for final-only test RNG=`950000+delay` at delays32 and64, 2,048 unique prefixes each. Fit a second independent delay32/64 head B on 4,096 prefixes from RNG=`935000+delay` to measure refitting variability. Generate all data through `make_batch`, retain only even-indexed identical prefixes for hidden-state fitting, and preserve full pairs on final test for the original task-behavior guard. All models and heads use the same underlying examples for each named split/delay; test streams are disjoint from EXP-0001–0006. Reject exact prefix collisions within or across train/validation/test for the same delay.

Hidden states are taken immediately **after the pre-evidence QUERY** and before the EVIDENCE token. Applying each frozen original readout to every extracted prefix must reproduce its own pre-evidence logits. Fit each model's **single** train-only mean and population SD (floor 0.001) from the delay8 A training states. Use this one frozen affine transform for **all** delay8,32,64 heads and tests of that model/seed. Thus the matched long-delay head does not receive separate feature re-centering or scaling. Heads differ only in which labelled delay is used to fit the linear map.

For each model/seed fit ridge H64 plus intercept → four one-hot classes for the prior-cued candidate label, with 260 coefficients, fixed λ=1 on slopes and unpenalized intercept, float64 normal equations. Source head `H8A` uses delay8 A train data; target heads `H32A` and `H64A` use their respective A train data, and B heads use independent target-delay B train data. No hyperparameter search, checkpoint choice or test-set tuning. Classification is argmax of four linear scores. Report training/validation/test accuracies, coefficients/scaler hashes, all split identities, extraction/fitting costs and actual wall time. M3/C0 head capacity, labelled sample count and method are identical.

## Outcomes, guards and decision

**Primary** at the SAME fresh delay32 test states: for each trained-model seed define `L_M = accuracy(H32A_M→32) − accuracy(H8A_M→32)` and `D = L_M3 − L_C0`. D>0 means the short-delay probe transfers worse *relative to its own same-delay reference* in M3. Each seed has one D, not 2,048 independent replications. Paired-seed mean, sample SD and 20,000-resample percentile bootstrap 95% CI use fixed seed `960001`.

Before assigning a scientific decision, require: all ten seed/model checkpoint and data/resource checks pass; every M3/C0 seed has delay8 `H8A→8` validation prior-label accuracy≥0.90 and delay32 `H32A→32`/`H32B→32` validation accuracy≥0.90; M1 validation means for these heads≥0.90. For both M3/C0, mean absolute difference between H32A and H32B **test** accuracy at delay32 must be ≤0.02, otherwise probe refitting is too unstable for this attribution. The original task **pre-evidence** accuracy on the same new delay32 full pairs must be >0.10 in each primary model, with M3−C0 mean ≤−0.01 to establish the behavior to be explained. Any prerequisite failure yields INCONCLUSIVE with recorded reason; no data-dependent refitting.

**SUPPORTED** for the registered ≥5-point excess transfer loss if D's CI lower>+0.05. **PARTIALLY_SUPPORTED** if CI lower>0 but support fails; this establishes a positive direction without a confirmed 5-point magnitude. **FALSIFIED** for a ≥5-point excess if CI upper<+0.05 and the outcome is not already PARTIALLY_SUPPORTED. All other complete outcomes are INCONCLUSIVE. These ordered branches are mutually exclusive and apply only to this fixed decoder family and task.

Secondary, not a replacement endpoint: the four absolute H8A→8 validation, H32A→32 validation, H8A→32 test and H32A→32 test accuracies for each model/seed; original pretrained readout's pre/final task scores on the same final set; delay64 transfer and matched-head results; prior-label cross-delay shifts in the contextual dense model; target-head A/B per-seed variability. These descriptive results cannot identify whether state drift comes from input interference versus elapsed computation, nor prove causal mediation of original task errors.

No result changes EXP-0004/0006 verdicts or advances Gate1.
