# EXP-0017 v1：ORDER-OBS 四条件控制资格实验

2026-09-28，用户明确授权“开始实验”。本注册在新任务实现/研究样本与训练之前保存；只执行DIR0008草案中控制资格部分。轨道independent_benchmark，G1-MATCH-v3，无Gate1或模型包优势主张。A1/A2、学习全转移滤波均不训练。旧ORBIT与G1-RS配置不重开。

## 问题与决策价值

固定六状态操作代数(C/N)×操作可见性(O/U)下，全输入/读出D64能否学会IID且四cell均保留至少.02nat的OOD误差？D16作学习锚点。最强反驳是控制仍可精确模拟六状态滤波，或在预算内根本没学会。任一情况关闭这组固定2×2效果计划；不靠改LR、难度或效果阈值救配置。成功仅说明pilot窗口可用，仍不运行候选、宣称结构有益或开启Gate2。

先例与因果链：DIR0008报告的DeltaProduct/非交换转移/部分观测滤波。连接及算子组织→输入条件动态→有序状态/后验→组合与修订→追踪。本轮只测控制学习/余量，不隔离链上组织因果效应。

## 固定生成器与oracle

状态q=3b+j，j∈{0,1,2},b∈{0,1}，q0=0。r=(1,2,0,4,5,3)；s_C=(3,4,5,0,1,2)，s_N=(3,5,4,0,2,1)。操作r/s iid各1/2，U每操作独立以1/4遮蔽，O不遮蔽。每4操作后附传感器`1[j=0]`。统一5维one-hot词表：0=r,1=s,2=?,3=sensor0,4=sensor1。模型只看可见token，初hidden为0；不输入真实状态、操作概率或任务标签，四cell分别训练。

每个token后输出6维oracle后验。q0点质量；r/s置换推送，?以两种置换平均，sensor按兼容支持集过滤并归一化。无epsilon、clip或后验平滑；精确零概率在KL中贡献0。float64概率oracle与独立log-domain前向实现比对；完整可见oracle必须点质量且等于latent。支持与分母错误视作工程失败。

四cell固定顺序CO/CU/NO/NU。先生成独立操作与遮蔽流，再从操作生成状态/传感器；可见数据与oracle确定性。C/U中的sensor与操作不必交换，不把它称作全滤波器交换性控制。简单算法就是六状态归一化Bayes滤波，足够状态5自由度，不设单流容量障碍。

## 数据流、模型、训练

种子17001/17002/17003；每cell每seed D16与D64共享全部训练/评估数据。训练root使用NumPy SeedSequence([171001,seed,cell_index,step])，step1..750，再spawn两个独立子流供操作/遮蔽。评估用[172001,seed,cell_index,operations]；保留[173001,...]从未调用供未来独立效果设计，不承诺本轮自动启用。工程root固定[179001,0,cell_index,0]，不碰研究root。

两臂为PyTorch2.8 GRU(input5,H16/64,batch_first)+Linear(H,6)，全部门矩阵Uniform[-1/sqrt(H),1/sqrt(H)]、全部bias0；constructor后重设torch seed再按GRU weight_ih、weight_hh、readout.weight顺序初始化。参数数目以公式`3H(5+H)+6H+6H+6=3H²+27H+6`固定：D16=1206，D64=14022。输入无embedding；该控制资格不是与未来embedding候选的已匹配比较。

CPU float32、1线程、deterministic；Adam(lr=.001,betas=.9/.999,eps1e-8,weight_decay0)，全参数clip_grad_norm1。训练750更新，batch64，每序列32操作+8sensor=40token。训练loss是全token平均soft-target交叉熵；无checkpoint selection/early stopping/LR sweep。每150步记录loss和累计CPU/墙钟。执行顺序seed→cell→D16,D64；即使某cell资格失败仍完成注册24模型，保存完整矩阵，除非工程错误或时间到期。

IID32、OOD128操作（40/160token）各4096序列，按128一批评估。主KL为最终sensor之后的KL(oracle||prediction)，float64由logits稳定logsoftmax重算。记录每例KL、模型/数据hash、检查点、全训练loss、最终logits、token、latent最终状态和oracle。辅助报告后验熵、sensor1比例、oracle Bayes准确率、模型准确率、相对oracle准确率差及支持大小分布；这些不改变资格。非点质量历史硬分类误差不能解释为捷径。

## 唯一分支、统计与预算

主复制单位是3个训练seed；每cell每臂记录逐seed均值、样本SD与df2的95%t区间(t=4.302652729911275)，区间描述seed不确定性，不裁剪负下界、不替代判定。学习门：四cell的D64各seed IID KL严格<.10；余量门：四cell的D64各3seed OOD均值>=.02。等于学习阈值失败，等于余量阈值通过。D16不参与门。

优先级：工程/非有限/数据或缺记录→INCONCLUSIVE/ENGINEERING_ABORT；共享900秒预算超时→INCONCLUSIVE/INCOMPLETE_BUDGET（若先有工程错误保留工程错误）；完整24模型后任一D64学习失败→INCONCLUSIVE/LEARNING_FAILURE；否则任一cell余量失败→INCONCLUSIVE/CONTROL_CEILING；全部通过→SUPPORTED/CONTROL_PILOT_WINDOW。无OOD上界门，不把高OOD误差写成模型可学性证明。逐cell学习/余量旗标全部报告，单一整体判词不遮盖另一个事实。

研究上限18000更新、900秒run+analysis；独立复核300秒，不重新训练。总研究与重放1200秒。工程预检最多220更新（两模型各100 tiny-overfit+10计时），旧verify套件原有过拟合另列。计时仅用工程dummy输入，预估总成本需在900秒内，否则正式运行前新版本处理，不降任务预算暗跑。

任何非负KL候选相对某cell本批D64的最大平均改进≤该cell观测OOD KL均值；报告此有限实例界，不外推为普遍架构上限。成功只容许后续完整候选设计审查，无自动训练A1/A2。
