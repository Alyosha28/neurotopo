# EXP-0005 v1 — Frozen-model distractor-payload sensitivity

Registered 2026-09-23 before implementation or any EXP-0005 test outcome. This is a new diagnostic direction after ITER-0002's `STOP_MECHANISM_ESCALATION`; it does not add an architecture or reopen Gate 1. Prior-art context: `research/prior_art/evidence_matrix.md` and `research/prior_art/interference_diagnostics.md` (the latter is reviewed before execution). The causal link tested is **input perturbation → learned recurrent computation**. It does not test semantic hypotheses or biological topology.

## Question and strongest rejection

At fixed trained weights and sequence length, does removing random distractor payload alleviate the independent-block GRU's delay-32 deficit relative to the degree/self-loop-matched random-mask GRU?

Blank/id-only/value-only inputs were absent from training. Removing channels changes input amplitude, and any new response can arise from gate bias, input distribution shift or interactions with recurrent decay. Even an exact positive interaction cannot uniquely identify a memory-interference mechanism or prove that passive state decay is absent. The task remains solvable by caching candidates and selecting late evidence.

## Frozen material and controls

No training, checkpoint selection, architecture edits or parameter updates. Models: `multi_gru` (M3), `random_gru` (C0), and contextual `gru_wide` (M1). Reuse **all ten** EXP-0004 seeds 9101–9110 and only each final checkpoint. The thirty checkpoint byte copies and SHA-256 manifest are in `artifacts/EXP-0005/v1/input_checkpoints/` and `configs/exp0005_checkpoint_inputs.json`, copied from the frozen EXP-0004 run at `eec9ca4`. Source EXP-0004 model results hold the initial-parameter, graph and mask hashes. Before the new test, reconstruct each model from the registered seed and ensure the copied weights/mask match; replay the original EXP-0004 test streams and require exact prediction hashes/metrics for delays 32 and 64. Failure blocks interpretation and is retained as a provenance failure.

New held-out generator RNG = `740000 + delay`, 1024 counterfactual pairs for each delay32/64. This stream was not used in EXP-0001–0004, monitoring or model selection. The same base examples are regenerated with the same RNG seed for every model and payload condition. Inputs are identical in memory/prior/selector, labels, event tags and time. Each delay32 sequence has 32 pre-query and 2 post-evidence DISTRACTOR events; delay64 has 64+2. Only the candidate/value eight channels at tagged DISTRACTOR events change. No change to event count or recurrent updates.

Payload conditions:

- `full`: original independent random candidate+value one-hot pair at each distractor.
- `blank`: both candidate/value channel groups zero at every distractor; tags retained.
- `repeat`: copy the **first** generated distractor's candidate+value pair to every later distractor within each sequence. Per-event two-hot amplitude and across-sequence marginal distribution are preserved; within-sequence temporal variation is reduced. This is a correlated OOD input, not a pure random-noise intervention.
- `id_only`: retain original distractor candidate one-hot, zero its value channels.
- `value_only`: retain original distractor value one-hot, zero its candidate channels. These two conditions have equal one-hot amplitude and are exploratory channel-sensitivity comparisons, not semantic causality.

All variants call the original data generator first and consume identical random draws. All results use final model weights, without optimization or choosing a favorable checkpoint. M3/C0 maintain the exact parameter/state/mask-count controls of EXP-0004; all variants within one model use identical executed inference steps and dense linear operations. Record per-condition active/allocated parameters, state, inference FLOP proxy, latency and runtime. M1 has more effective parameters and is contextual.

## Outcomes and decision rule

Primary endpoint: unconditional joint counterfactual pair success on **new delay32** instances. For each seed compute `gap_full = M3_full − C0_full`, `gap_blank = M3_blank − C0_blank`, and `Δ = gap_blank − gap_full`. Compute paired-seed mean, sample SD and deterministic 20,000-resample percentile bootstrap 95% CI (seed 750001), using ten seed-level Δ values, not 10,240 test pairs as independent replications. Also report every seed's four absolute scores, the two gaps and M3's absolute blank gain. Test-instance uncertainty remains conditional on the fixed generated set.

Prerequisites: ten complete seeds and thirty valid checkpoints; exact original-stream replay, common base labels/tags/non-distractor inputs, source/config/data hashes and M3/C0 resource matching; on the new `full` delay32 stream both M3/C0 mean joint accuracies must exceed 0.10 and be below 0.97. On `blank`, M3's mean joint success must exceed 0.10. Any failure: INCONCLUSIVE, with failure record.

**SUPPORTED**, only for meaningful frozen-model payload sensitivity: Δ mean ≥ +0.03, CI lower > 0, and M3's absolute blank-minus-full mean ≥ +0.03. This says removing payload alleviates M3's **relative** deficit on this test; it does not establish that the blank gap is zero or identify a unique neural mechanism. **PARTIALLY_SUPPORTED** if Δ mean > 0 with CI lower > 0 but either registered 3-point practical threshold or the M3 absolute-gain requirement fails. **FALSIFIED** for this ≥3-point relative-alleviation prediction only if the prerequisites pass and CI upper < +0.03. All other complete outcomes are INCONCLUSIVE.

Secondary, not used to choose the primary decision: delay64 repeats the same metrics; delay32/64 `repeat`, `id_only`, `value_only` conditions and their gap interactions relative to `full`; `pre_accuracy`, confirm/revise accuracy and NLL, evidence sensitivity, and joint error overlap by counterfactual pair. A positive `repeat` interaction on the same-amplitude condition would make within-sequence payload variation a more plausible candidate. These exploratory contrasts receive descriptive seed differences and intervals; no multiple secondary endpoints can rescue a failed primary rule. A blank ceiling cannot establish equal underlying capacity or equivalence.

Gate 1 remains closed regardless of this diagnostic. EXP-0004's FALSIFIED decision remains unchanged. The registered branch after decision is `STOP_MECHANISM_ESCALATION`; this iteration ends with a scoped explanation, negative result or uncertainty recorded, not a new architecture.
