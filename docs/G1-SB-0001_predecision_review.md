# G1-SB-0001 独立候选设计批评

2026-09-24。独立 `gpt-6-sol` / high 只读事前提交 `f70c9e0` 的合同、阶段门/相关决定、模型资源、CAL-0006 与 PF-RNN/RIMs/EviTrack 一手边界；未实现、未训练或改文件。裁定：当前项目 Gate1 目标 **`NO_GO_BEFORE_TRAINING`**，不据此启动控制资格或正式 EXP。

决定性问题与 G1-DD 的失败模式相同：SB4 与 SC64 都具有四条按标签索引的Gaussian预测头、四条持续证据分数、按组输入和相同评分更新，**唯一干预是 recurrent mask**。因而可识别的是共同四专家滤波装置下隔离块 vs 强连通稀疏连接的结构/优化效应，而非K=4候选更新相对K=1单流。SC64图强连通不保证功能上的单轨迹。更具体地，`softmax(s_t)^k` 反馈使第k块依赖其他分数：`∂p_k/∂s_j=−p_k p_j`，通常非零；SB4本身也不满足所声称的严格独立循环历史。取消归一化反馈或改为纯本头增量可修该泄漏，但不能修复两臂共有四头四分数的主因素混同。

固定8D生成律的解析oracle在数学上可行，H标签未输入，不是直接泄漏；但监督及头索引固定候选身份，不能称自发形成。只用posterior交叉熵未必识别各Gaussian头的真实发射，需预写头校准、坍塌/冗余/持久检查。QR需固定矩阵数组/哈希、符号规范、依赖版本；该任务有无信息量和实际控制OOD余量均**尚未测**。D64有效循环边更多，是强性能护栏；标准dense全读出改变头和分数机制，只能敏感性，不能代匹配主控制。数值预算、种子、余量窗口和统计分支未冻结，首个资格数据前必须补齐。

PF-RNN已研究带权循环粒子，RIMs已有分组循环，EviTrack已有评分轨迹；这份比较未隔离项目可归属的新K操作，不能因不是逐字复制就冒充独有贡献。最强审稿拒绝理由：主对照保留了候选机制的关键部件，使SB4的可能优势只剩连接正则化；同时后验标签固定槽与共享score反馈削弱“独立假设轨迹”解释。Gate1不需要先完成Gate3的完整语义干预，但要确实比较多轨迹与强单流；本合同没有做到。
