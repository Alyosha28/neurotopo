# DIR-0001 独立方向审查：互反图空间范围搜索

2026-09-24。独立 `gpt-6-sol` / high / `fork_turns=none` 先读事前 `research/design/h1_range_direction_protocol.md`，再只读其中限定的阶段门、H1 设计/证据/决定、H3 决定及既有图 null 先例记录；未读对话、未编辑或运行图搜索/模型。审查结论为 **NO_GO_NOW**，只针对当前图搜索顺序，不否定 H1、互反因素或未来 null 家族。

最强拒绝理由是**决策后果缺失**。已有10/10图的一次局部 witness，现行 H1 决定仅保留因素候选并禁止将 witness 用于性能归因。扩大搜索即便找到更大互反范围，也没有预写联合谱/motif/路径容差和通过后可执行的任务决定；未找到也只是有限预算搜索失败。因而在 Gate 1 关闭、H3 可辨候选仍欠缺时，这项工作最容易把方法活动伪装成能力证据。`research/design/h1_null_family_review_criteria.md` 更明确要求当前不要靠继续加图搜索回避 H3 障碍；无训练不消除这一顺序冲突。

审查逐项指出：GO 条件①未给互反目标、联合容差、样本量、预算和失败线；条件②缺能改变的当下决定，是**决定性未满足项**；条件③只可称成熟方法文档没有自动保证本图族的精确自环/cross/谱约束，尚未查源码，不能声称既有方法绝对不可用；条件④未见被挤占的正式 Gate 1 运行，但限定材料不足以核实时队列，且 H3 问题更近。未来若真有独立 H1 问题，需事前固定方向/最小差异、十图样本量与成功率、尝试上限、谱等统计容差以及必保 H64/1,024边/逐点入出度16/64自环/原图cross/强连通。

主代理接受 NO_GO，但记录自己协议的一处设计瑕疵：它把“是否值得**写**数值搜索规格”的方向判断与“该搜索规格已给全部数值”合成同一个 GO 条件，导致条件①在方向阶段逻辑上难满足。此次停止真正依赖的是条件②和现存顺序决定，不把条件①的自我设限当作 H1 数学不可行证据。
