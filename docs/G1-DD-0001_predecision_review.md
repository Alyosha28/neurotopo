# G1-DD-0001 独立候选设计批评

2026-09-24，独立 `gpt-6-sol` / high 只读事前提交 `9931f51` 的合同、项目阶段门/旧失败、模型代码与 PF-RNN/RIMs/EviTrack 一手先例；没有修改或训练。裁定 **`NO_GO_BEFORE_TRAINING`**。此审查在 EVT-0001 原始模拟结果前指出论文公式风险；后来的代理实测不作为其事前裁定的来源。

主因果缺口：候选DD-MB2与强连通DD-SC64均保有两组持续评分、两Gaussian分量和混合预测，分数不反馈GRU状态。连通控制可能在其64维内保持两个解释；所以两臂比较只能测相同双专家装置中的 block vs connected recurrent mask，不能识别“有无多条假设轨迹”。两个分量读同一观测、无标签身份，分量权重也不等于真实潜在盆地概率。EviTrack的 branch accuracy依赖显式潜在轨迹；仅有x预测头不能直接复用。

外部任务风险：论文公开 `a=3,d=2` 使井±3在偶发射区`|z|≤2`之外，却有一句称吸引到井后仍在该区，下一句又称在区外；这是数学/文字不一致。区内无噪声漂移倍率1.30–1.54，作者30–170步后验消歧分层在**未筛选**总体中是否足量，审查当时只列为待测风险，未声称已测比例。分段发射边界还可能提供非对称线索。真值`z`/oracle只能做独立评价，不能进入x-only模型训练或用于看候选效果后挑区间。若以后研究该任务，须先固定独立后验oracle精度、未筛选总体和层内出现率、概率头表达误差、实际主控制的学习与余量，再训练候选；不能只用来源论文的筛选曲线证明自然任务资格。

资源方面，同一H64 GRU若两掩码每行入度32且匹配自环，可有相同分配循环权重`3×64×64=12,288`、有效循环权重`3×64×32=6,144`及稠密执行路径；须另计两个持续分数、输出/参数缓存、logsumexp、反传和时延。稠密强控制有效参数更多，只能作敏感性。资格阶段可仅跑实际DD-SC64/强控制并与正式流隔离，但它只能解决任务资格，不能补救上述**主因素未隔离**。

可保留的窄问题是固定双头/双分数时的递推连接组织效应；它不自动计项目Gate 1。若要检验多假设轨迹，须另设计真正区分候选数或候选状态功能的单流因素对照，并明确PF-RNN、RIMs、EviTrack归属。作者论文的有分数轨迹与双势阱任务已有先例，不能据复制组件或基准声称新颖。
