# EXP-0007 v1 运行前独立科学审查

日期：2026-09-23。审查对象为尚未实现或运行的 `experiments/EXP-0007/v1.md`、`configs/exp0007_v1.json` 及 `research/prior_art/cross_delay_decoding.md`，并对照原始 `task.py`、EXP-0006 已归档证据与 Gate 1 状态。本审查未拟合 EXP-0007 探针、未读取其结果、未修改实现。

## 判定

**通过，限于预注册的固定探针协议所测的跨延迟读出迁移；正式科学运行仍须以实现审查、完整验证、冻结提交为前提。** 主终点、数据流、共同标准化及判定门槛构成可执行且可证伪的新问题。当前 A/B 稳定性对照只重拟合 delay32/64 目标头，不重拟合唯一的 delay8 源头 H8A。因此它能排除较大的目标头**准确率**重拟合波动，不能排除 H8A 训练样本偶然性或逐实例预测差异。若不新增 H8B，结果措辞须严格限定于登记的 H8A 样本/固定 ridge 家族，不能声称已把“时间相关映射改变”与一般重拟合不稳定性完全分开。新增 H8B 或改变门槛须在实施前另存协议版本，不得由结果触发。

## 设计核对

主差值是每个原训练/图种子内 `D=[acc(H32A_M3→32)−acc(H8A_M3→32)]−[acc(H32A_C0→32)−acc(H8A_C0→32)]`。四项均在**同一个新 delay32 测试集**评估；M3/C0 训练好的原模型各自拟合头，不跨模型共享状态坐标。十个配对种子是推断单位，2,048 个 pair 是固定测试实例，20,000 次百分位 bootstrap 不能把 pair 当成独立训练模型。应保留每种子四项绝对分数、两个迁移损失、D、样本 SD 与区间，避免均值掩盖源头/目标头质量。

支持至少 5 个百分点额外损失要求区间**下界 >+0.05**；部分支持要求下界 >0 且未达到支持；在前两类均未命中时，区间上界 <+0.05 排除注册的最小幅度并判 FALSIFIED；其他为 INCONCLUSIVE。这个优先顺序互斥。部分支持的区间可能包含或排除 +0.05，不能一律称其已排除。所有来源、资源、数据、探针充分性、A/B 和原行为护栏须先过；任一失败为 INCONCLUSIVE，不可由 delay64 或宽 GRU 挽救。

每个头用 4,096 个独立 pair 的单份 pre-evidence 前缀拟合，validation 为 1,024，最终 delay32/64 测试各 2,048；训练 A、训练 B、validation、test 的登记 RNG 区分，模型与头在同名 split/delay 上共享原始样本。原 task 的 confirm/revise 两行在证据前相同，故拟合和测试必须只计一个前缀。实现应按前缀字节检查各 split 内及 split 间重复，并验证标签、prior 和 QUERY 时刻一致；提取状态只能消费 QUERY 及其之前的输入。完整 pair 另用于预设的原任务行为护栏与次要行为读数。测试集不得拟合均值、方差、系数或调整阈值。

每个模型/种子只从 **delay8 A train 状态**求一套均值与总体标准差（下限 0.001），所有 H8/H32/H64 A/B 的拟合与评估均使用该套变换。这个决定避免让目标头独享新的均值/尺度校准；仍不消除非仿射状态变化或延迟引起的噪声负载差异。H64→4 的 ridge 含截距共 260 个系数，λ=1 仅罚 64 个斜率，float64 正规方程和四类 argmax 应逐头一致。旧检查点字节/参数/掩码、EXP-0004 原流分数重放及原读出 logits 与提取状态全样本一致，是运行前与执行时的硬检查。

充分性门槛要求 M3/C0 的每个种子 H8A→8、H32A→32、H32B→32 在相应 validation ≥0.90，宽 GRU 的对应十种子均值 ≥0.90。0.90 可排除接近机会水平的头，但相对 0.05 的主效应仍较宽松；需完整报告 M3/C0 同域 validation 水平和差距，不能把较差的 H8A 源头拟合称为明确的跨延迟状态机制。H32A/B 的测试准确率绝对差按每模型十种子均值 ≤0.02，可量化目标头准确率重拟合稳定性；均值可能掩盖个别种子，须逐种子报告。该护栏是在固定测试集上的预定判定条件，不可用于选择 A/B 较好的头或换测例。M3/C0 原任务 pre-evidence 准确率均值 >0.10 且 M3−C0 ≤−0.01，确认本实验仍面对需解释的原读出差距。

## 解释边界

EXP-0006 已显示两模型 delay32 状态的候选值对匹配长延迟线性探针高度可读，原读出表现却有差距；EXP-0007 增加“短延迟头能否迁移”的观测，确实不同于在同延迟重新拟合。delay8→32 同时增加随机干扰输入和循环更新，不能将 D 归因于被动衰减、干扰、坐标旋转或任何单一机制。原任务头用不同目标与训练路径，新的 ridge 头不构成其因果中介。先行研究已使用跨时间/延迟解码，此处不主张方法新颖性。无论 SUPPORTED、PARTIALLY_SUPPORTED、FALSIFIED 或 INCONCLUSIVE，独立审查与一次子集复现后按登记分支结束该诊断；不改写 EXP-0004/0006，也不推进 Gate 1。
