## 注册与实现一致之处

- 五臂固定原始噪声课程 `0×2000 → 2×1000 → 4×1000 → 8×2000`、6000 更新、十个新配对种子 9101–9110；最终测试为全新固定流的 delay8/16/32/64。`study.py` 对每臂同种子重新配置模型/训练 RNG，最终测试按 `630000+delay` 生成，输出初始参数、数据与资源哈希/记录。
- 注册的主终点 delay32、稳健性 delay64 在配置和分析器中分别由 `primary_delay`、`robustness_delay` 指定；`noise_delay8` 的 M3/C0 每种子 pre≥0.90、joint≥0.50 同时作为 IID 学习充分性门槛。主终点两模型平均 joint 都低于 0.10 时判 INCONCLUSIVE；匹配失败也禁止正面结论。32/64 的配对均值效应、95% CI、confirm 退化门槛及宽 GRU 参照与注册规则一致，Gate 1 不自动推进。
- **不在 delay32/64 强加 pre≥0.90 是合理的预注册取舍。** 两模型能否跨长间隔保持表现正是被测的分布外鲁棒性；以 OOD pre 阈值筛掉下降，会把可能有信息的性能分化误判为无效。共同近地板由主终点双模型 `<0.10` 规则单独处理。若仅一方超过 0.10，仍须依靠十种子配对 CI、3pp 最小效应和 64 稳健性共同判断；该规则不保证长间隔一般可学。
