# 下一方向独立审查：先证明问题可辨，再决定是否建模

2026-09-24。范围限于当前阶段门、冻结协议、正式结果摘要、H3 设计契约与已审计先例；本审查不改 EXP-0004/0009 的标签，也不注册新实验。**结论：选择第五方向 E——对 H3 做一次可否决的纸面任务与对照审计。** E 先冻结要排除的简单解释、最小充分统计量、预算与因果预测；只有审计通过，才进入 C 中的任务和基线规格，再以独立校准判断是否值得注册实验。它不预设维度越高越好。当前 M3 线按决定 0003 停止，不能直接实施 D。

## 现有证据的边界

Gate 1 仍为 **NOT_PASSED**。EXP-0004 的 M3/C0 均学会 IID delay8；在预定 delay32，四块 M3 比匹配随机图低 9.10 个百分点，95% 配对区间为 [−14.90, −3.60] 个百分点。因此，其注册的至少 3 个百分点收益预测为 **FALSIFIED**，仅限该任务与预算。EXP-0009 的主终点 d=4 上，C0 的平均最终后验 KL 仅 0.012463 nat，低于预注册 0.07 的余量门，也小于所要求的 0.05 nat 有用改善；判定必须保留为 **INCONCLUSIVE**。d=8 只是描述性结果。两项均未测试“每条轨迹表示一个竞争假设”：M3 所有块读相同输入，没有候选身份、候选权重、候选证据评分或路由，共用读出。状态距离、线性可解码性和单个块损伤本身不能补上该构念缺口。

| **E（首选）可否决的任务—机制辨识审计** | 纸面论证不能替代真实学习与干预结果；若只写一个故事而不定量列简单解，也会成为另一轮架构辩护。 | 当前最高的单位成本信息增益：可在新增模型与搜题之前排除“少量计数就够”“对照已封顶”“候选只是已知粒子/选择模块换名”三种最直接解释。 | 产出一份可审阅的否决表：逐项写出候选身份和证据更新的可测反事实、显式 Bayes/缓存/最后线索/单流的充分统计与预算、PF-RNN/RIMs 重叠轴，以及哪项观察会使 H3 失败。不能提出独立于候选硬编码的增量预测，或无法构造单流与主匹配对照可学习且未封顶的任务，则停止 H3 实现并执行 A 的主假说重审；通过才进入 C 的预注册设计。 |

E 的关口不是要求先发明“复杂到 GRU 失败”的任务。它要求说明**什么计算在等资源单流中难、为什么多候选结构预计解决、怎样区分增量收益与已知滤波/选择性模块**。尤其应预先决定是否检验最终精度、逐时后验修订、样本效率或迁移；这些不能在结果出来后互换。候选删除与置换必须有同规模随机损伤和共享状态损伤对照，且候选身份不能仅由任务输入硬编码后再把消融的必然选择性当发现。若显式滤波或 PF-GRU 在匹配预算下同样有效，结论应收窄到任务实现或否证 NeuroTopo 的增量，而不是增加适应、通信或重采样寻找优势。

## 重复失败的策略原因与纠正

上一轮 agent 策略先把训练路径问题修好，再沿同一四块代理更换任务和难度。EXP-0003 的课程学习说明原任务可训练，却不是 M3 机制证据；EXP-0004 在有余量的匹配长延迟主比较中出现负效应。之后 CAL-0001/0002 逐步增加潜变量，但常规 GRU 仍可拟合小型充分统计；CAL-0003 固定节奏迁移失败，CAL-0004 改变训练分布后只用稠密 GRU 资格校准。EXP-0009 把有用改善定为 0.05 nat，却没有在冻结前用**实际 C0**验证该误差空间，最终 C0 只剩 0.012463 nat。两次改任务没有改掉 M3“相同输入的四块加共享读出”与 H3 候选语义不符的核心问题。严格的资源配对和复现证明结果可信，不能修复问题构念与终点可辨性。

纠正行动是把进入实验的顺序改成：先做 E 的构念与简单解否决；再按 C 写出任务、强基线与完整预算的版本化规格；只用独立流校准**实际主匹配对照**的 oracle-relative headroom，保证预定有用效应处于可改善空间内；冻结任务、阈值和假设后使用全新流注册比较，并留存失败种子。若前两关失败，停止 H3 线并重审主假说。这不是重新标注 EXP-0004 的 FALSIFIED 或 EXP-0009 的 INCONCLUSIVE，也不是提升 d=8 为主终点。

不可越过的边界：Gate 1 未过；不得以本审查启动适应、跨轨迹通信、DARC、连接组、SAE、自然语言、独立 LM 或 scaling。候选特异因果诊断不等于预测收益；合成任务收益不等于机制、跨任务一般化或生物效应。任何新机制实验须先经过新协议、先例审计、匹配预算、独立审查与阶段门流程；失败结果必须保留。
