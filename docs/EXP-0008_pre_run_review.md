# EXP-0008 v1 运行前独立科学审查

日期：2026-09-23。审查尚未实现或运行的 `experiments/EXP-0008/v1.md`、`configs/exp0008_v1.json`、`research/prior_art/final_state_decoding.md`，并对照原始任务生成器和已归档的 EXP-0004/0006/0007 证据。本审查不含 EXP-0008 模型结果或探针拟合。

## 判定

**预注册设计通过，可进入实现与工程验证；科学运行仍须先完成干净提交和源码哈希验证。** 这个诊断能回答受限问题：在原始 full-noise 延迟任务的最后 QUERY 后，用同容量、重新监督的线性头从冻结状态读取 revise 分支的最终所选标签时，M3 是否比匹配 C0 至少低 3 个百分点。它不能判断信息是否被晚到证据更新“销毁”，也不构成原读出性能差距的因果分解。

## 数据、来源与读出

三模型、十个已训练种子与 EXP-0004/0005 的冻结检查点一致；运行器须先验证复制字节、初始参数/掩码、EXP-0004 delay32/64 原测试分数，且不得更新原模型。M3/C0 各 H64、6,212 有效/15,428 分配参数及同延迟一步一事件的执行账目匹配；宽 GRU 仅为更大有效容量的背景对照。

每个 delay 的 A/B 训练各 4,096 个 counterfactual pair，验证 1,024、最终测试 2,048，四个预设 RNG 流彼此及既有实验分离。同一 pair 的 confirm/revise 两行共享晚到 selector 前的前缀，必须整体进入同一 split；训练可使用其两个最终状态和标签，主测试每 pair **仅取一条 revise**。实现须在 pair 级检查 A/B/validation/test 的共享前缀重复，核对每 pair 恰好一条 prior selector 和一条 alternative selector、标签与输入对齐、各模型种子共用原始数据哈希。不得把 4,096 pair 误报成 8,192 个独立记忆前缀，也不得把 2,048 revise 行当成 2,048 个独立已训练模型。

状态取自最终 QUERY 后；原模型 readout 作用于每个提取状态，应逐项复现原 final logits。每个模型×种子×delay 只从 A 训练的 **8,192 条最终状态**计算均值与总体 SD（下限 0.001），A/B 头及 validation/test 共用该尺度。A/B 均以相同 8,192 条标签规模、64 特征加截距、四类 one-hot、float64 正规方程和仅斜率 λ=1 拟合；每头 260 个系数。B 是独立训练流的稳定性对照，不是测试后挑选的候选头。训练、验证、测试准确率、权重/尺度/数据摘要、资源代理和实际时间均须存档。

## 主终点和决策

主量为 delay32 **revise-only** A 探针准确率的每种子 `d=M3−C0`；同一新测试 pair、同一 selector 和标签对齐于两模型。以十个配对训练/图种子为重复单位、固定 RNG1040001 做 20,000 次有放回 bootstrap，报告各种子差、均值、样本 SD、95% 区间；区间条件于固定新测试集。confirm、delay64、宽 GRU 和原模型其他指标均不能替代主量。

来源/数据/标签/资源/读出一致性先通过。正对照要求 C0 与宽 GRU 的 validation revise 准确率均值 ≥0.90，且各至少八个种子 ≥0.85；M3 不设最低分，以免用主研究对象筛掉真实缺口。M3/C0 各自的 A/B **test revise** 准确率差的十种子平均绝对值 ≤0.02，须同时报告逐种子波动；它控制准确率层面的重拟合敏感性，不证明两个头逐例预测相同。原模型在同一 test 的 revise final-answer 准确率 M3−C0 均值须 ≤−0.01，且两者均 >0.50，确保仍有可解释的原行为差距并避免近地板比较。任一前提失败为 INCONCLUSIVE，不得换 split、λ、头或终点补救。

当所有前提通过，`CI_upper <−0.03` 为 SUPPORTED（注册的至少 3 点缺口）；否则 `CI_upper <0` 为 PARTIALLY_SUPPORTED（仅支持负方向，是否排除 3 点由区间下界决定）；否则 `CI_lower >−0.03` 为 FALSIFIED（排除注册的最小缺口）；其余 INCONCLUSIVE。有序判断互斥。主 CI、正对照和原行为护栏须由实现边界测试覆盖严格不等号及等号情形。

## 科学边界与收尾

revise 要求晚到 selector 指向 prior 以外候选，避免 confirm 可直接复用旧 prior 答案的混淆。即便新探针达到高准确率，也只说明最终冻结状态中的所选标签按该线性头协议可访问；原读出可能因训练目标、延迟外推或状态映射不同而失败。探针准确率低也可能来自非线性 cue×候选绑定、容量、正则或样本效率，不能推出记忆内容在 EVIDENCE 更新中消失。既有工作已使用工作记忆状态解码；此实验不主张方法新颖性、语义分工或生物效应。无论四类判定哪一类，完成独立结果审查与一次 clean-checkout 子集复现后按 `STOP_MECHANISM_ESCALATION` 结束这一诊断；EXP-0004/0006/0007 和 Gate 1 状态不因它改变。
