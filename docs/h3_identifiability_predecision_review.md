# H3 可辨识性审计的独立预决策审查

2026-09-24。审查仅依据本次指定的阶段门、H3 审计与契约、PF-RNN/RIMs 先例边界、失败综合、EXP-0009 摘要及下一方向独立审查；未检查或重跑模型，未改动任何冻结协议或实验结果。

## 判定

**有条件接受 NO-GO：当前不应实现新的 NeuroTopo 候选轨迹架构，也不应继续给现有 M3 换任务寻找正效应。** 接受范围仅是设计与执行决定：当前候选规格没有定义足以辨别其独立贡献的状态更新、可证伪预测与控制方案。它不是“所有多轨迹架构无效”或“H3 已被实验否证”的结论。EXP-0004 的 FALSIFIED 只覆盖其登记任务与至少 3 个百分点增益预测；EXP-0009 对登记的 >0.05 nat 收益仍是 INCONCLUSIVE，不能借其接近零的观察效应改判为普遍无效。[阶段门](../research/stage_gates.md:3)、[失败综合](../research/evidence/auto_research_failure_synthesis.md:8)、[EXP-0009](../research/evidence/exp0009_posterior_transfer.md:13)

M3 四块读同一输入且没有候选身份、权重或路由，因此 EXP-0004/0009 没有直接检验“每条轨迹代表一种竞争假设”。这是构念未被操作化和测试的缺口，不能记成 H3 的负实验结果。[H3 审计](../research/design/h3_identifiability_audit.md:7)、[候选轨迹契约](../research/design/h3_candidate_trajectory_contract.md:3)

## 重开条件的可证伪性与阶段门边界

候选轨迹契约提出的任务 oracle、简单解、实际主匹配对照、PF-GRU/RIM 风格基线、候选干预和成本核算是方向正确的审查项；H3 审计也要求先冻结设计再注册新实验。[候选轨迹契约](../research/design/h3_candidate_trajectory_contract.md:13)、[候选轨迹契约](../research/design/h3_candidate_trajectory_contract.md:15)、[H3 审计](../research/design/h3_identifiability_audit.md:18)

但重开条件目前仍有可移动门槛的空间，尤其“学习充分性和大于预定最小效应的余量”没有要求把资格判据数值化。建议在任何校准数据可见前，固定主终点、最小有用效应 `δ`、置信界限和主匹配对照的合格区间：对 oracle-relative excess loss，既规定上界以排除不可学习/地板任务，也规定下界至少留出 `δ` 加预定安全余量以排除封顶；两项都须在隔离资格流上满足。资格失败就停止该规格，不据此换延迟、损失、阈值或主对照；通过后另用全新流执行已冻结比较。还应把每项候选新预测写成方向明确的主对比、失败界限和相应消融，避免“有新预测”停留在不可判定的文字要求。

这些纸面条件通过后，含义只能是允许继续评议任务/对照资格或形成新版本注册；**它本身不代表实验结果、不改变 Gate 1，也不把 Gate 1 标为通过。** 阶段门必须继续依据实际主匹配比较的冻结结果判断。EXP-0004 的局部 FALSIFIED 与 EXP-0009 的 INCONCLUSIVE 标签不得在重开时改写，也不能用重新挑选主终点来追认旧结果。[阶段门](../research/stage_gates.md:8)、[EXP-0009](../research/evidence/exp0009_posterior_transfer.md:13)

## 若继续暂不实现新架构，下一项有信息量且合规的行动

建议做一次**只用既有记录的 H1/H2 决策审计**，而不是再搜一个 H3 任务：沿 `Topology → Dynamics → Representation → Computation → Capability`，逐项列出现存 H1/H2 主张、最强未解决反例、现有证据等级，以及哪一个未来观测会改变判断；再选出信息价值最高的一项，写成不含新机制的可否证设计草案，明确简单解释、匹配要求、主要终点和停止条件。此项工作只整理已冻结证据与问题定义，不改实验协议、不启动训练，也不推进阶段门；若找不到独立可测的因果预测，就据此记录收窄或暂停该研究线。方向审查已经指出，当前 M3 停止成立，下一决策应转向主假说重审，而不是继续代理任务搜索。[下一方向审查](../docs/next_direction_independent_review.md:13)、[下一方向审查](../docs/next_direction_independent_review.md:25)

由于本次审查授权限定为指定文件，我没有打开 H1/H2 定义或其他证据包，因而不指定哪一个 H1/H2 问题胜出，也不预判其是否可辨；上述行动是下一项合法研究工作的边界与产物定义。
