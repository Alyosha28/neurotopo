# EXP-0009 独立预运行审查的主代理处理

2026-09-24。独立审查见 `docs/EXP-0009_pre_run_review.md`；审查时没有 EXP-0009 M3/C0 结果。以下修改均发生在 v1 的 `REGISTERED` 冻结之前，不变更历史实验或 CAL-0004 校准结果。

1. **最小有用效应与区间统一。** 主张明确为 d=4 的 `Δ=KL(C0)−KL(M3)>0.05 nat`。`SUPPORTED` 需要配对种子 bootstrap 95% CI 下界严格大于0.05，并通过 IID KL 与 H-准确率代价护栏；若方向显著为正但区间仍含0.05，或有护栏代价，仅 `PARTIALLY_SUPPORTED`。上界严格小于0.05 才对这个最小效应命题判 `FALSIFIED`；边界等号归入事先写明的未充分确认情形。协议已写明顺序，不能事后把“方向正”改称“实用增益已证实”。
2. **收紧 Gate 1 解释。** EXP-0009 只比较一种四分块结构与一种保度/自环的重连生成器，在一个任务和训练日程下测试结构差异。即使 `SUPPORTED` 且复现，也**不自动通过 Gate 1**。更广的轨迹主张需要新注册的强单流/RIM 风格匹配比较、独立任务迁移重复及候选特异干预。宽稠密 GRU 因有效参数更多，始终只作背景参照，不进入主因果判定。
3. **工程验收成为运行门。** 冻结协议要求对十个种子逐参数初值哈希配对、图度数/自环/强连通与跨块边、日程/数据流确定性、状态及有效/分配参数和执行代理进行无结果 preflight；任何失败禁止训练。实现后必须先有 source-hashed 全套验证与 preflight 证据，账本按 `REGISTERED → VALIDATED` 顺序推进，方可由受监督 worker 运行。`resource_account` 是前向线性代理，完整训练 FLOPs 与峰值内存未测时继续明确标为未测。

审查同时指出复合 d 迁移、特定 null 图生成器、固定测试流种子 CI 和小型合成后验任务的构念界限；v1 协议已限定，最终报告须逐条保留。主代理接受这些问题作为解释限制，不将审查通过本身当作科学证据。
