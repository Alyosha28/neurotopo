# G1-MB-0001 独立候选设计批评

2026-09-24。独立 `gpt-6-sol` / high 只读已提交 `ec7df14` 的候选合同、模型/资源/动态任务、CAL-0006、EXP-0004/0009、阶段门和 PF-RNN/RIMs 先例；没有实现或训练。裁定 **`NO_GO_BEFORE_TRAINING`**，不建议把 v0 补成正式资格协议。

MB4 相对 SC64 确有一个可测的新因素：固定分块读出后，递推跨块连接是否切断。两臂预计13,508分配、4,292有效参数的算账正确；SC64 强连通，可称“连通递推控制”，却不能只靠图连通性断言它是功能性单轨迹。MB4 仍让所有旧 M3 式状态块读同一输入、每步全更新，logit归属按答案模式固定，既无候选权重反馈，也未证明候选身份的因果保持。D64 同样受分块读出限制，虽有效参数更多，仍应有原强稠密全读出敏感性；degree64稠密初始化刻度也不能宣称与degree16两臂完全同初值。

核心拒绝理由是任务/预算选择。CAL-0006 已在相同四模式8→12任务、1200更新的冻结资格因一个强稠密种子 OOD12 KL0.06497<0.08 判 `CEILING`，决定0021关闭该配置的架构入口。G1-MB 根据已看300/1200监控把预算改600以寻找余量；那些300更新监控只有IID8，不证明OOD12在600更新可判别。新种子、预冻阈值也不能把后验任务/预算选择变成独立提出的 Gate 1 证据。EXP-0004 的有余量旧 M3 比匹配控制低9.10百分点；EXP-0009 的主 C0 d4只有0.012463 KL余量。重新给旧 M3按模式拆读出，难以视为有新动力学原理的候选。

即使 MB4 胜两控制，也只能说在已看生成器/所选预算下按监督 mode-specific 拆读出及局部连接对训练有帮助；不能直接推出“通用多轨迹 Gate 1”。最强审稿拒绝是后验选任务/预算、按标签定槽的旧分块代理和受同样读出限制的对照一起制造局部优势；性能差或来自连接正则化、读出约束或训练速度，不是独立假设轨迹能力。对当前 v0 应保存设计失败，转向**候选先行的新任务机制**，而非继续调这套模式任务难度或训练步数。
