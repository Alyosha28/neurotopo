# EXP-0011 矩阵冻结包装器独立工程审查

2026-09-24，独立 `gpt-6-sol` / high 只读提交 `288dce5` 的计时包装器、固定矩阵脚本、v3协议与决定0037；**没有执行矩阵、任务或模型**。裁定 **REVISE**，现包装器不可用于唯一冻结。

主要问题：flock在进程强杀/断电后释放，而包装器只在生成矩阵/末尾报告后才留下防重入标记；若子进程已启动但尚未写出任一文件，下一次可再次调用。elapsed与300秒状态在写报告/fsync前取值，报告写盘可超时仍标成功；半写报告和直接向最终矩阵JSON写入的部分文件可能留下不可完整核验的状态。验证没显式拒绝NaN/Inf，数组自述SHA不等于独立重推seed；超时信息/退出码不完整，已提交源码检查也没pin到审查时SHA。要严格实现一次性事务，需启动前durable journal、原子发布和完成receipt等更复杂机制。

正常路径的SeedSequence→PCG64→QR符号规范、4×8×8的0.97Q与little-endian float64摘要和v3一致。失败是**冻结过程的工程可靠性**，没有任何矩阵数值或科学效果。主代理据此审查是否应继续补复杂事务代码，或把确定性、从未基于任务表现择优的矩阵定义更简单地作为版本化任务参数冻结；任何路线须在生成矩阵前修改协议并独立审查，不能裸跑旧脚本追认0037。
