## 设计与可回答问题

`task.py` 为四个候选分配四类标签的一次随机排列。已知 prior 指向候选及其正确标签时，另外每个候选的条件猜测率为 **1/3**；无此信息时为 1/4。主终点仅计未被 prior 指向的三个候选，并按每个候选分类准确率计算，避免把 EXP-0004 已测过的 prior 值读出混入主要证据。若报告整张表全对率，当前协议规定四次独立 argmax、不强制排列；它与强制排列后的整表命中率不能混用。

EXP-0004 的 `pre_accuracy` 只衡量原读出对 prior 值的表现；EXP-0005 改变了输入分布，且 blank 对照显著退化。EXP-0006 在原始 full-noise 输入上、冻结相同权重，用额外线性读出测试未提示候选，因此有独立的**表示可访问性**问题。C0 与宽 GRU 的 validation 均值 ≥0.45、各至少八个种子 ≥0.40，均高于 prior-only 的 1/3 条件基线，是有用的正对照门槛。它们不证明 probe 完全恢复所有可用信息；门槛失败应如协议判 INCONCLUSIVE，M3 不宜另设足以排除真实缺口的最低分门槛。

4096/1024/2048 是每个 delay 的独立拟合、验证、最终测试 **pair/prefix** 数；相邻 confirm/revise 样本在晚到证据前前缀完全相同，只取偶数行作一个观测是必要的。实现应断言每个 split 内及 split 间的前缀哈希不重复，并核对全部模型/种子共享同一输入、标签和 pre-query 索引；若出现重复或不一致，停止解释并保留失败记录。三个预定 RNG 流与既有实验流分开，validation 只作预设充分性检查，test 不参与标准化、拟合或阈值选择。`v2.md` 的“full pairs retained only for secondary behavioral analysis”文字略窄；实现还必须用完整 pair 计算预注册的 delay32 行为护栏，不能把它降为可选次要指标。这是执行检查，不影响当前冻结的数值规则。

每个模型×种子×delay 单独拟合 H64→16 的闭式 ridge，含截距共 1,040 系数；训练集均值/总体标准差、0.001 下限、仅斜率施加 λ=1、float64 求解和逐候选四类 argmax 均已固定。实现核查应覆盖截距不受罚、相同容量、训练集标准化参数复用、无晚到证据泄漏、原 readout logits 与提取状态逐项相符、原 checkpoint 及旧流精确重放。共享测试 pair 不是独立训练/图重复：主 CI 应仅对十个配对种子差值重采样，并声明它条件于固定测试实例。

判定顺序在逻辑上互斥：SUPPORTED 要求 CI 上界 <−0.05；PARTIALLY_SUPPORTED 要求 CI 上界 <0 且未支持；FALSIFIED 对至少 5 点缺口要求 CI 下界 >−0.05 且先前分支未命中；其余 INCONCLUSIVE。数据、来源、容量和 validation 正对照与行为护栏先行，失败不能靠次要指标补救。最终同一新测试集上的 M3−C0 行为差距护栏旨在确认 EXP-0004 所见负结果仍是解释目标，并不独立复制其全部训练种子或使探针成为因果分解。

最强替代解释仍是状态坐标、尺度、非线性编码或固定线性头的样本效率差异。即使得到稳健缺口，也只能说这些冻结状态按此线性探针协议对未提示标签的可访问性不同；不能推出总记忆容量、后续选择步骤的因果瓶颈、语义假设分工或生物意义。相关线性状态解码已有先行工作，不可作为机制新颖性。Gate 1 保持关闭，EXP-0004 的 FALSIFIED 判定不因本诊断改变。
