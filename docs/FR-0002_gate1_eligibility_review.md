# FR-0002 项目 Gate 1 资格：独立科学审查

2026-09-24。独立 `gpt-6-sol` / high，按事前提交 `73808b1` 的 `research/design/fr0002_gate1_eligibility_audit.md` 只读审查冻结 EXP-0011 v6、四臂模型源码、项目 Gate 1 决定与 [PF-RNN原论文](https://ojs.aaai.org/index.php/AAAI/article/view/5952)、[作者源码](https://github.com/Yusufma03/pfrnns)、[RIMs原论文](https://arxiv.org/abs/1909.10893)。没有任务生成、模型训练或文件修改。按预写三分支裁定 **`FIELD_ONLY`**；这不是 EXP-0011 的效果判词。

| 臂 | 持续状态和每步更新 | 评分与读出 | 对主因素的含义 |
|---|---|---|---|
| K4_score | 4×16独立GRU，每块读同一`(u,y)`；另有4个累计logw，总68 | 4个模式Gaussian头，用观测似然更新logw，直接读logw | 同时引入递归分块、四头、累计证据和特定读出 |
| S68_sparse | 一条强连通H68 GRU，无持续score | 全状态线性4类logits | 真单流，但与K4相差整套评分/读出装置 |
| S64_score | 一条强连通H64 GRU加4个累计logw | 同形四头、似然更新、logw读出 | 对K4主要是连接组织比较；系统仍保有四条证据历史 |
| K4_unscored | 4×17独立GRU，无累计score | 各块一个logit | 同时改变宽度、头与读出，不能正交隔离评分 |

四臂使用相同`(u,y)`和早/末解析后验soft-target监督，真实H/oracle不作为输入；模式编号通过类别监督绑定。即使K4_score未来同时胜过两个诊断臂，也不能由这些非正交对比拆出K更新的主效应。PF-RNN已提出带权循环粒子和观测评分，并与普通RNN比较；RIMs已有独立模块递归。本地K4无重采样/提议噪声或RIMs的选择性更新/通信，既不是作者实现的逐项复现，也不能靠分块/带权结构主张新颖。先例新颖性不是Gate1独立硬门槛；此处拒项目资格的决定性原因是主干预混同及消融不足。

最强反对意见：用户章程Gate1只要求状态和计算匹配后的**通用**多轨迹收益；若K4击败真正单流，是否足以过门？审查认为该正差只支持PF风格**整包**的受限任务收益，无法归给多条递归候选更新。Gate3的语义候选删除仍属另一关，不能反向加到Gate1；但Gate1也不能把完整包效果改名为K因素。

EXP-0011 v6目前只有工程证据：静态资源账合格，但九组实测时延比1.4811–1.7629全部超过1.12停止线，530工程更新、零研究更新，无任务信息或效果。其`INCONCLUSIVE / RESOURCE_MISMATCH`与本资格审查正交。`research/entries/EXP-0011.json`本就为`field_reference/gate1_claim=false`。现行项目入口对`reference_k`拒绝；任何改变都必须在新架构效果前版本化。审查建议停止**以项目过门为理由**优化同一FR-0002 v7；下一项目候选应先给功能性K1主控制、K更新与评分/头/读出的可辨干预及操作诊断，不能重复双方共有四头四分数、只换mask的G1-DD/G1-SB失败设计。
