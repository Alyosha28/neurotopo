# 决定0072：G1-ALIGN-0001 设计线**停止**（v2 判 `V2_REJECTED`；分辨率上限）

2026-09-24。执行 v2 窄范围再送审的判词与**五条可机器核验的停止条件**。**本决定不注册实验、不授权训练、不改变任何阶段门状态、不追认任何既有判词。**

## 1. 判词与依据

v2 再送审判 **`V2_REJECTED`**（19 项问题；`research/reflections/G1-ALIGN-0001-DESIGN-V2/`）。审查同时给出五条**只用 packet 内冻结常数即可复算**的停止条件。**本轮已逐条独立复算**（`t` 分位用自实现的正则化不完全 Beta，自检 `t_{0.975,7} = 2.3646`、`t_{0.80,7} = 0.8960` 与标准值一致）：

| # | 停止条件（须为真才继续） | 实测 | 判定 |
|---|---|---|---|
| **S1** | 容量上界 `C_ub < δ_min/2`（给有限样本留与通道同量级的余量） | `0.0508 < 0.025` → **假** | **不满足** |
| **S2** | 支持所需点估计 `≤ δ_min` | `0.0508 + t·SE = 0.0757 > 0.05` → **假** | **不满足** |
| **S3** | 每条存在性/等价性条款在零真值点的通过率 `≥ 0.8` | `β_X` 条款：`0.328`（n=8）、`0.706`（n=16）、`0.812`（n=20）→ **假** | **不满足** |
| **S4** | 门槛是被检验量的**有效界**（须给出逐臂 `KL_trained − KL_projection` 并证明覆盖） | packet 内**无此测量** → **假** | **不满足** |
| **S5** | 判决函数在 `(I=0, CI 跨零)` 与 `sd∈(0.0434,0.0441]/n=8` 上**必须返回分支** | 当前**无分支** → **假** | **不满足** |

**五条全部不满足 → 按审查规则停止。**

## 2. 停止范围

- **G1-ALIGN-0001 不注册、不跑资格流、不启动训练**；v2 的判据架构**作废**。
- **不**以删改阈值的方式续命：审查已判定"任何 v2 内修订仍只能检出 `≳0.076` 的效应"，故对 `δ_min = 0.05` 的声明假设**没有任何 v2 内修订能救**。
- 已冻结的 `research/design/g1_align0001_control_qualification_protocol.md` **不启动**；保留为历史件。
- 可复用资产**保留**：`align0001_analytic_decomposition.py`（投影分解）、`align0001_symmetry_check.py`（自同构判定）、`align0001_sampler_crosscheck.py`、`align0001_oracle_crosscheck.py`、`align0001_axis_pilot.py`、F/X 冻结对、`gap(k)` 探针。

## 3. 决定性理由（本项目的**分辨率上限**）

容量通道（`0.0388 [0.0285, 0.0508]`）与声明的有用效应下限（`δ_min = 0.05`）**同量级**，由此：

- **可支持所需效应 `≳0.0757`（`1.51 × δ_min`）**，而 `δ_min` 处 `P(SUPPORTED)` 按精确 `t` 算为 **`0.0224`**（审查用正态近似给 `≈0.007`；两者同阶且都远低于任何可用水平）——**设计为一个它无法据以结论的效应做功效，又要求一个从未做功效的效应**；
- `MDD(δ_min, 0.80, sd=0.0298, n=8) = **`0.0344`**，而非设计所写的 `0.05`；
- **零结果与不确定的负结果没有判词**（§9 分支非穷尽）；
- 容量门槛**估计量错位**：`0.0388` 是**最优因子化投影**的 KL 差（60 projection episodes、单 seed），而 `I` 由**被训练模型**的末端差构成；逐臂 `KL_trained ≥ 投影代价` 成立，但**差之差不受同一不等式约束**，故该区间**既不是**训练表示代价的上界**也不是**下界。**最强拒绝 A 成立**——v2 的"不扣除 + 抬栏"是**改名而非消除**。

**结论（须保留为负面结果）**：**在该任务构造与冻结判据下，对齐效应与容量通道不可分辨。** 这不是"对齐无效"，也不是 H3 的一般证伪。

## 4. 本轮另查出的**我方错误**（由审查发现，已独立复算确认）

1. **"配对 bootstrap 把 MC 半宽从 0.083 收到 0.0111（7.5 倍）"为假**。正确的不配对基线是 `sqrt(sd_F²/60 + sd_X²/60)·1.96 = **`0.01123`**，与配对半宽 `0.0111` **基本相同**——**实际收缩仅 `1.011×`（约 1%）**。`0.083` 是"四个边际半宽相加"的错误基线。**该句撤回。**
2. **`MDD` 写错**：实为 `0.0344`，v2 写的 `0.05` 未按自己的公式计算。
3. **`gap(16)` 归属写反**：packet 内为 **F `0.4023 [0.3578, 0.4421]`、X `0.3853 [0.3407, 0.4411]`**；v2 §8.2 把 `0.4097` 归 F、`0.3846` 归 X，二者是**另一文件（400 episodes）**的值，两个归属都错。
4. **`gap(k)` 覆盖要求无证据**：packet 的 `k` 键仅 `{4, 8, 16, 32}`，而 v2 要求覆盖到 `k = T = 64`。
5. **§8.5 规则自毁**：第 1 档"复算 `>0.02` 即停止该 K 单元"会**杀掉唯一主单元**（K=4 成分 `0.0388`，CI 整段 `>0.02`）；第三档 `(δ_min, 0.02]` 因 `δ_min = 0.05 > 0.02` 为**空集**；K=2 落在 `(0.02, 0.05]` 时第 1、2 档**同时成立且指令相反**。
6. **难度差版本与 sha256 未在冻结文本落实**；§0 声称已给。
7. **重算工件的 `design` 字段仍指向 v0/v1**，审计链不自描述。

## 5. 审查提出的唯一可救路径（**本决定不执行，留作新设计**）

若日后仍要检验"对齐"，须**新设计**（不是 v2 的收窄）：

1. 以**逐臂训练最优性差的直接测量**作为容量通道的零假设界（替代错位的投影差）；
2. 用 **2×2 因子（划分 × 难度均衡）**以**交互项**估计难度通道，替代"CI 含 0"式过滤（未拒绝 ≠ 等价）；
3. **重新界定效应量**，使容量通道**显著小于** `δ_min`；**若做不到，则记录为"在该任务构造与冻结判据下不可分辨"**——即本决定 §3 的结论。

## 6. 不改变

Gate 1 仍 `NOT_PASSED`；Gate 2 不启动；无 EXP 注册、无训练授权；**非回归清单**（候选级 9 条 + 任务/组合级 3 条）全部保持被否、无一重开；决定0062/0066/0070/0071 的约束不变。本决定**不**产生新候选，也**不**构成"项目轨已无可注册候选"这一判断的撤销。
