# 决定0101：以完整架构候选重写现行阶段门

2026-09-29。用户明确要求“重写阶段门”，授权本次前瞻规则修订；本文件是设计决定，**不是实验结果**。现行版本为 `ARCH-GATES-v1`，权威表在 `research/stage_gates.md` 顶部。

## 原因与改变

旧 Gate 1 把“多轨迹结构相对强对照的收益”设成唯一上游门，后续适应、通信、竞争和规模研究依次等待它。这能防止用复杂组件掩盖早期负结果，却也会把候选设计锁在某一个结构因素与任务资格搜索上。EXP0027 已经提供当前读出与后续计算可分离的局部因果反例，但没有生成或验证一套完整架构；继续只围绕重整调度不能满足项目长期目标。

本次把阶段门改为**主张分级**：A0 定义完整候选，A1 验证可运行计算，A2 检验架构效应，A3 识别因果机制，A4 检验泛化与资源，A5 检验生物原则归因，A6 单独检验自然序列、语言模型和大规模竞争。A0/A1 不需要先证明旧多轨迹效应；可先做有界原型和诊断。效应、机制、泛化、生物与竞争主张仍各需相应证据。旧 Gate 1 的多轨迹问题可作为一个 A2 候选因素继续研究，不再是所有架构设计的通行证。

## 比较与历史边界

未来 A2 正式比较使用 `ARCH-MATCH-v1`：预注册候选主张所依赖的主要预算轴并以 pilot 测量核验，匹配该轴；`SUPPORTED` 还要求匹配或算子级剖析实际计算；完整披露状态、参数、样本、更新、内部步数和时延。在不同预算下声称整体效率优势时，还须比较质量与资源的曲线，单点胜出只支持该预算附近的主张。它沿用 `G1-MATCH-v3` 的透明资源原则，但明确允许**完整架构的整包效果**作为 A2 结果，且要求有效强控制；因此不能把旧实验自动换标为 A2 通过。定义性消融是 A0 中预写的机制预测，A3 再检验它；A2 不以组件归因为通过前提。若未隔离关键因素，不可称该因素的因果效应。统计单位为独立训练实例，具体阈值、任务和留出条件须在看到该候选的结果前冻结。

旧 Gate 0 已通过、旧 Gate 1 `NOT_PASSED`、其余旧门未启动的历史状态不变；EXP0004 的注册负结果、EXP0026 的局部周期结果、EXP0027 的冻结状态反例和全部旧匹配版本均不追溯改判。重写前的 `research/stage_gates.md` 已按来源提交逐字节复制到 `research/archive/stage_gates_pre_arch_gates_v1.md`，旁附 SHA-256 归档记录。旧 ResearchLoop `project_gate1` 代码与事件不自动迁移，不能将新门状态写入旧字段。`research/loop/task_spec.md` 是初始化快照，不作为本版执行准入的覆盖规则。
