# GOV-0002 决定：现存组合不足以注册新的项目 Gate 1 EXP

按事前提交 `065f3c7` 的 `research/design/gov0002_gate1_portfolio_entry_audit.md`，核对当前候选、任务、实际主控制、资源与 claim track，判 **`NO_REGISTERABLE_PROJECT_GATE1_EXP_NOW`**。可追溯矩阵见 `research/evidence/GOV-0002_gate1_portfolio_entry.md`，独立预决策审查见 `docs/GOV-0002_predecision_review.md`；当下导航和客观重开条件在 `research/loop/current_frontier.md`。此标签仅说明**目前仓库在现行项目入口下**没有可直接登记的新 Gate 1 因果比较，不是 H3 一般否证、项目停摆、独立领域研究禁令或用户原章程的永久改写。

旧 M3 在 EXP-0004 的有余量、资源匹配 OOD32 对照中低9.10百分点，且任务不要求潜在竞争假设；EXP-0009 的主控制在注册 d4 只余0.012463 nat KL，未过余量门。H3-SLOT 经 SCR-0001/0002 仍缺完整身份/更新和相对显式滤波/PF/RIM 的独有数值预测；CAL-0006 虽有动态模式 oracle，却无候选干预，且冻结六臂 OOD12 资格靠 dense seed603 的0.06497<0.08判 `CEILING`。参考 K 因素可作 `field_reference`，其项目过门资格按决定0019/0023仍未裁定。H1 局部图 witness 不提供匹配 null 或 Gate 1 的 K 因素效应。这些是**逐个现存组合**的缺口，不证明无法设计一个新候选。

因此只关闭“拿当前 M3/H3-SLOT 加新难度配置就启动项目 Gate 1 训练”的路径。新项目轨需先出现一份可核的新候选/操纵因素合同、真实主控制与资源账、独立审查，再按冻结有限任务菜单资格测试。一个另行具名的记忆/检索主张仍可研究 EXP-0004 旧任务，但不能据它重命名旧结果或声称竞争假设功能。独立 benchmark 和领域参考因素可按各自目的/预算/三分支运行；不自动计项目 Gate 1。旧 EXP/CAL/SCR 标签与 Gate 1 `NOT_PASSED` 原样保留。当前 live loop 不开始新迭代，也未训练新模型。
