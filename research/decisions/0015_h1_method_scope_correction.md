# 更正 DIR-0001：停止当前完整搜索，不一概禁止 H1 方法审计

2026-09-24。DIR-0001 任务后反思 `research/reflections/DIR-0001/` 找到五项设计/行动缺口，主代理接受核心边界：`research/decisions/0014_h1_range_no_go_now.md` 的 **NO_GO_NOW 只针对未定数值目标的完整互反范围/谱联合图搜索**。它不等于禁止任何不训练模型的 H1 方法准备。原方向协议把是否值得写完整规格和已写完整规格混成同一道门；原决定又将“方法候选状态变化”误压成“当下必须有可运行能力实验”。这些是本轮策略造成的失败，不能反推 H1 图因素不可能。

修正后的 A/B/C 层及候选状态见 `research/design/h1_method_reentry_table.md`。模型训练/生物拓扑实验仍受 Gate 1 与独立任务/匹配 null 限制。有界图空间搜索需先完成数值协议及独立审查；无新图的约束审计可单独预写，只能排除某些目标或给出 `BOUND_NONDECISIVE`，不能冒充可用 null 或能力效果。当前正式研究账本仍为已完成的 ITER-0007，没有新登记可运行的 Gate 1 迭代；OS 进程清单因 sandbox `ps` 权限无法核验，因此不作“机器上无任何进程”的声称。

本更正不改写 DIR-0001 冻结 packet/决定，也不取消其对**当前完整搜索**的 NO_GO_NOW；它给更小的、可判别且可停止的方法问题留出明确入口。H1/H2 仍 UNTESTED，Gate 1 NOT_PASSED。
