# 决定：先例可提供领域通用效应证据，不能按现行规则直接通过项目 Gate 1

2026-09-24。按事前 GOV-0001 协议与独立审查 `docs/gov0001_independent_review.md`，采纳 `research/evidence/gate1_charter_interpretation.md` 的双轨解释：

1. **领域问题 A：**用户原始章程将 Gate 1 研究问题写作资源匹配的“通用多轨迹收益”，没有把先例本地复现排除出这个**领域问题**。在未来独立注册、实际主对照有 oracle-relative 余量、总状态/参数/训练与推理计算得到严格控制、全种子报告且独立复核的条件下，PF-GRU/RIM 等既有机制的本地效果可为 A 提供证据。论文作者报告、代码阅读、单步 smoke test 或未匹配演示均不够。
2. **NeuroTopo 项目 Gate 1：**现行决定0006明确不把**纯先例复制**的正效应计成 NeuroTopo 候选通过；相对先例的特有贡献和 Gate 3 的语义专化又是不同主张。本轮不借章程解释悄悄改这条规则。若后续拟让先例复制本身替代项目过门条件，先版本化决定0006、`research/program.md` 和 `research/stage_gates.md`，只对未来实验生效，不能追认旧结果。

这不是在今天注册、实现或运行 PF-GRU：当前没有有余量的已冻结任务、具体候选、资源匹配方案或独立 PF 软件故障；决定0010/0011对“提前 smoke test 救旧 M3/H3-SLOT”的 STOP 不变。EXP-0004 限定 FALSIFIED、EXP-0009 INCONCLUSIVE、SCR-0001 NO_SPEC、H3 一般 UNTESTED 和 Gate 1 NOT_PASSED 全部保持。若将来提出正式领域先例复现，它须有自己的问题/协议/审查，不能混作 Phase B 清单完成或自动解锁适应、通信、DARC、生物图。
