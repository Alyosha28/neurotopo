# 决定0076：用户授权放宽**目标轨道与主张范围**（非放宽证据标准）——为可投稿产出开轨

2026-09-24。**状态：`EFFECTIVE`。生效依据：用户明确直接授权**——"gate 1 pass 不了你就放宽点标准嘛、我只想水个论文，当然如果能有 breakthrough 最好。我先休息了，你继续跑"。

**本决定不得被读作"证据标准已放宽"，也不得被引述为"经独立审查确认的规则变更"**：与决定0069 同类，它是**经用户授权的范围变更**。二者区别必须保留在记录中。

## 1. 被放宽的是什么（范围）

- **放宽项**：**允许把产出目标从"项目 Gate 1 通过"改为"可投稿产出"**。具体开三条轨，均**不主张 Gate 1**：
  1. **负结果/方法学论文**（首选）：把本轮已完成的七区方法审计、精确无截断容量机器、两轮独立审查判词（`V0_REJECTED` / `V1_JUDGMENT_REJECTED`）与"匹配标量比较不可识别"的实算证据，写成一篇方法学/负结果论文。
  2. **field-level `PACKAGE_EFFECT` 轨**：允许在**带资源未匹配标志**的前提下报告架构/组织比较的观察，措辞限定为 field-level，不聚合、不引用为 Gate 1 证据（沿用现行 `PACKAGE_EFFECT` 定义）。
  3. **`independent_benchmark` 轨**：沿用既有定义，自带目的、预算与三分支。
- **目标上限**：若某一轨产生**量级远离实测伪影带**的效果，可升级为主张更强的 field-level 结果；**不因此获得 Gate 1 判词**。

## 2. 未被放宽的是什么（证据）

- **证据完整性**：原始数据不可变；机器输出与脚本必须留档并带哈希；不得事后调阈值、不得删除失败跑、不得选择性报告。
- **判词纪律**：`SUPPORTED / PARTIALLY_SUPPORTED / INCONCLUSIVE / FALSIFIED` 四类判词的含义不变；**负结果与偏差必须保留并进入论文**。
- **Gate 1 状态**：仍 `NOT_PASSED`；本决定**不产生**任何 Gate 1 判词，不改写任何既有权重或判词。
- **非回归**：非回归清单 12 条**无一重开**。
- **决定0075 的六项前置计算继续有效**：它们既是"先算清"的纪律，也是论文的实质内容（估计量公开、逐 γ 配对＋不确定度、全族枚举与 R1/R2 实算、终点先定、匹配披露与防捆绑、阈值推导机制）。

## 3. 为什么这样放宽反而更容易出论文（如实记录判断依据）

- 相邻领域审计（`research/prior_art/dir0003_A..G`）显示：**已审的 16 条先例里没有任何一项同时匹配多轴**；本项目主轨的合取要求严于先例，这是"每个候选都死在同一个合取上"的直接原因。因此**按 field-level 惯例 + 全披露**报告，既符合领域实践，也不构成造假。
- 本仓库的判词都带独立审查、packet 哈希与 reaction 留档；**含糊的 Gate 1 主张在投稿复核阶段不可辩护**，而**方法学/负结果论文的每一句都由既有机器输出支撑**，是当前工件能直接撑起的产出。
- "breakthrough"路径未被关闭：若第 3 节的六项计算给出**远离伪影带**的效果，即可升级为正向 field-level 主张（见 §1 目标上限）。

## 4. 自主研究授权与边界

- **授权**：以 goal 形式自主连续推进（含夜间无人值守）：执行六项计算、产出可复现包、写出投稿稿、按规程记录决定/前沿/反思并提交。
- **仍禁止**：伪造或修饰数据；把 `PACKAGE_EFFECT`/field-level 结果写成 Gate 1；在未实测的情况下声称效应；把搜索未命中写成"无人做过"的新颖性结论；在无独立审查时把决定0076 引述为"已通过审查"。
- **检索**：`web_search`/`web_fetch` 在本环境不可用，一律用 `bash curl`（arXiv API、Crossref、EuropePMC、HuggingFace Papers、`arxiv.org/abs|pdf` + `pdftotext`），并如实记录引擎与核验层次。
