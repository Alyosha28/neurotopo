# 决定0070：G1-RS 任务寻找按决定0049 上限关闭；EXP-0014 条件轮关闭

2026-09-24。执行 `ITER-0009 / EXP-0013 v3` 判词（`INCONCLUSIVE / LEARNING_FAILURE`）中已登记、但尚未落为编号决定的收尾动作。**本决定不注册实验、不授权训练、不改变任何阶段门状态、不追认任何既有判词。**

## 1. 这是**自动关闭**，不是新裁量

决定0049 在**生成 EXP-0013 矩阵与样本之前**已前瞻写死关闭条件：

> 若固定双Q/γ、任务信息、捷径、SC64/D64学习/余量或资源资格**任一失败**，就关闭本候选的任务寻找，不再以新EXP编号换噪声、显露时间、任务维数或生成器来救它。

`ITER-0009` 的实测结果命中该条件：任务信息门**通过**，但 **SC64 与 D64_full 两个强单流、两个学习率 × 三个 seed 的 IID32 学习门全部失败**，无可冻结的 LR，RS4 任务更新 **0**。因此本关闭是 0049 条款的**自动后果**，无需、也不得再作新的宽严判断。

## 2. 关闭范围

| 对象 | 处置 |
|---|---|
| **G1-RS-0001**（现行 v1 显式四分支独立循环组织）的**任务寻找** | **关闭**。不得再以新 EXP 编号替换噪声/显露时间/任务维数/生成器来救它。 |
| **EXP-0014 v3** 条件性正式轮 | **关闭**。资格门（EXP-0013 `CONTROL_STRONG_ENOUGH`）未通过，**正式与复核根从未读取**，无 RS4 训练、无 Gate 1 效应。 |
| `research/registrations/G1-RS-0001_config_lock.json`、`_protocol_pair_v2.json` | 保留为历史冻结件，**不删除**；不得据此启动任何根。 |

`experiments/README.md` 两行已同步：EXP-0013 v3 记 `ITER-0009 COMPLETED / INCONCLUSIVE (LEARNING_FAILURE)`；EXP-0014 v3 由 `NOT_RUN` 改记 **`CLOSED_BEFORE_FORMAL`**。

## 3. 明确禁止的救法（沿用 ITER-0009 与 0049）

不得用剩余墙钟**追加更新**、**换 LR**、**降低 IID32 学习门**、把 OOD 误差余量当作"可直接比较"、或**提出 EXP-0015 任务**来救这一结果；不得重命名 EXP-0012 的失败菜单或 EXP-0013 的固定生成器。

## 4. 本关闭**不**意味着什么

- **不是**"组织无效"的一般结论，**不是** H3 的一般证伪，**不是**多轨迹收益被否定。判词只覆盖这组固定生成器、固定预算与这两个强单流控制。
- **不**否定任务本身：T32 冻结 tune 根的事后只读诊断显示历史有信息（`KL(full‖cue)` 均值 `0.396360`、`KL(full‖truncated)` `0.224584`）。该观察**不能**改冻结学习预算，但**可用于未来新的机制/训练条件问题**。
- **不**使既有判词作废：EXP-0004/0009、CAL 系列、EXP-0011 v6、EXP-0012、GPI-0001 的判词全部不变。

## 5. 重开条件

只有**新的独立架构机制或研究问题**通过事前批评后，才能提出**另一个任务族**（0049 原文）。具体要求沿用 `current_frontier.md` 的四级依赖顺序与决定0043/0044：新版本 entry JSON 与机制合同、真实主匹配控制、资源与操作账、有限任务菜单与未用于选任务的最终流。

**特别声明（针对刚生效的 `G1-MATCH-v3`）**：决定0069 放宽的是**资源匹配口径**，**不是**重开理由。G1-RS 的关闭原因是**控制学习失败**，与匹配口径无关；`state` 匹配不再必须**不**使本关闭可撤销。同理，EXP-0011 v6 的时延阻断虽因 v3 而不再单独阻断 Gate 1 判词，但该轮为 `field_reference`/`gate1_claim=false`，**仍不计 Gate 1**，不因 v3 而升级。

## 6. 不改变

Gate 1 仍 `NOT_PASSED`；Gate 2 不启动；无 EXP 注册、无训练授权；**非回归清单**（候选级 9 条 + 任务/组合级 3 条）全部保持被否、无一重开。本决定**不**产生任何新候选，也**不**构成"项目轨已无可注册候选"这一判断的撤销。
