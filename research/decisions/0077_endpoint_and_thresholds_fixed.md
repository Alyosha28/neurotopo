# 决定0077：终点先定与阈值推导（决定0075 条件④⑥）＋匹配披露与防捆绑（条件⑤）

2026-09-24。**状态：`EFFECTIVE`，`field-level` 轨（决定0076 §1.2），不主张 Gate 1。** 依据：`research/design/dir0003_spec_curve.json`（`sha256 = 见 commit`，36 行 = 12 输入权重 seed × 3 读出 γ）。

## 1. 先修的两个方法学错误（我方）

- **符号对称陷阱**：`b ∈ {±1/√N}` 时，线性容量泛函 `gᵀ C⁻¹ g` 在 `b → Db`（`D` 为任意符号对角阵）下**不变**（`C → DCD`、`g → Dg`），故按此族抽 12 个"seed"实为**同一个系统**——规格维度为空。第一版 `dir0003_spec_curve.py` 正是如此（`own_curve_ridge_band` 在 36 行里恒为 `0.06094`）。**已改为高斯输入权重** `b ~ N(0, 1/N)`，规格维度才真实（该带随后跨 `0.0569–0.0782`）。
- **枚举口径**：v1 只保留每个长带计数下的最优 rung（33 个）；本决定的口径是**全枚举**（每个 `(seed, γ)` 有 `510–1410` 个匹配分配）。

## 2. 终点先定（条件④）

**研究问题（field-level）**：在**精确无截断总容量恰好匹配**（任务分布 AR(1), `φ=0.5`）的条件下，三段固定时间尺度带上的**单元分配**是否改变该核能提供的内容？

**主估计量**：**规格曲线上的对比度分布**，而非任何单点。
- `C1`（仅匹配总容量，最大化二阶矩对比）：`max_abs_contrast_on_grid`（网格上最大绝对对比）与 `contrast_long_lag_ge_20`（`k≥20` 最大绝对对比）；
- `artifact band`：**同臂**自身曲线在 `γ ∈ {0.01, 0.03}` 间的最大绝对变化（读出选择带来的伪影上界）；
- `C2`（R1 对照：**同时**匹配总容量与对数时间尺度一阶矩，最大化二阶矩对比）。

**判决规则（事前冻结）**：
| 判词 | 条件 |
|---|---|
| `SUPPORTED_FIELD_LEVEL`（仅短延迟侧可能） | 对比度 `p10` > 伪影带 `p90` |
| `FALSIFIED_FIELD_LEVEL` | 对比度 `p90` < 伪影带 `p10` |
| `INCONCLUSIVE_OVERLAP` | 两者区间重叠（**这是可发表的正面陈述**：单点比较无法把效应与读出选择分开） |

**按此规则的实际判词（本轮已可判定，数字见 §3）**：
- 短延迟侧（全网格）：`p10 = 0.0412` vs 伪影带 `p90 = 0.0742` → **区间重叠 → `INCONCLUSIVE_OVERLAP`**；
- 长延迟侧（`k≥20`）：对比度 `p90 = 0.0143` vs 伪影带 `p10 = 0.0570` → **对比度低于伪影带 → `FALSIFIED_FIELD_LEVEL`**；
- 形状预测（首个符号翻转 lag）：在 36 个规格上取值为 `{2,3,4,5,8,10,20,24,48}` → **在该效应量级下不可识别**，故**不进入判词**，只作诊断报告。

## 4. 匹配与披露（条件⑤）

- **操纵轴（单一）**：三段固定带（`0.20–0.40` / `0.60–0.75` / `0.90–0.97`）上的单元数分配 `(n₁,n₂,n₃)`，`Σ = 64`。
- **匹配**：`N`、单元总数、输入律（AR(1), `φ=0.5`）、带边界、读出族（岭回归）、**精确无截断总容量**（比值落于 `|·−1| ≤ 0.02`，实测中位偏差远小于此）。
- **未匹配（必须披露）**：① 对数时间尺度**一阶矩**（C1 中自由，C2 中匹配）；② 谱半径（由带边界与分配决定）；③ 读出岭 `γ`（作为**规格维度**，不匹配）；④ 输入权重实现（seed，作为规格维度）。
- **防捆绑条款**：任何结论必须同时报告 C1 与 C2；**只报 C1 的短延迟对比**会被视为把"一阶矩自由度"算进"高阶结构效应"。
- **轨道标志**：`field_level = true`、`gate1_claim = false`、`resource_unmatched_flag = true`（因一阶矩/谱半径未匹配）。
