# H3 设计关口：当前规格 NO-GO，H3 本身未被否证

2026-09-24。独立下一方向审查建议先做可否决的构念审计；主代理在 `research/design/h3_identifiability_audit.md` 对低维显式滤波、PF-RNN、RIMs 和现有实验逐项列出可区分预测。第二个独立审查 `docs/h3_identifiability_predecision_review.md` **有条件接受**：NO-GO 仅用于“现在实现一个新的 NeuroTopo 候选轨迹架构”和“继续给当前 M3 换任务找正效应”，不得解释为 H3 已被实验普遍证伪。主代理已按审查把 CAL-0001/0002 的结论限定在已测小任务，把 PF-RNN/RIMs 关系改成“当前草案尚未展示可辨预测”，而非架构等价。

作出 NO-GO 的直接证据是定义缺口而非某个 p 值：现有 M3 四块同输入、无候选身份/权重/路由；EXP-0004 在有余量的旧任务负效应，EXP-0009 因主对照近 oracle 而不可判定；CAL-0001/0002 的少量显式后验权重由单流 H64 GRU 近乎精确学习。PF-RNN 已有带权粒子，RIMs 已有选择性模块；当前 Gate 1 规格没有一个区别于这些简单解释的、先验可测且能消融的增量预测。继续加隐藏变量或 DARC 机制会先增加自由度，再解释结果，信息增益低。

重开门由任务**运行前**的数值化协议控制：固定主终点、最小有用效应 `δ`、独立主匹配对照 oracle-relative loss 的下限 `δ+ε`（`ε>0`）及可学习上限 `L_max>δ+ε`、种子/流、CI 与失败条件；预先写出候选特异反事实、输入硬编码的非增量对照、PF-GRU/RIM 风格资源匹配与消融。资格失败即停止该规格，不能从最终架构结果倒选端点。纸面通过只允许形成新注册设计，**不改变 Gate 1**，更不追认旧结果。

当前合法且已完成的独立行动是 H1/H2 现存证据审计：`research/decisions/0004_h1_h2_evidence_scope.md` 证明原图对照不能识别单个拓扑原则或动力学交互，并以图存在性 witness 检查互反结构在现有度/自环/跨块约束下局部可变。它没有启动新训练或打开生物阶段。Gate 1 仍 NOT_PASSED；如将来找不到新的独立、可辨且资源匹配的因果问题，继续收窄 H3 贡献范围，而不是把当前 NO-GO 偷换成项目整体失败或默默追加机制。
