# G1-DD-0001 v0：双分数对照未隔离多轨迹因素，训练前关闭

独立设计审查 `docs/G1-DD-0001_predecision_review.md` 对事前提交 `9931f51` 的外部延迟消歧候选判 **`NO_GO_BEFORE_TRAINING`**。首要理由与任何任务模拟结果无关：DD-MB2和DD-SC64**都**保有两组持续证据分数、两个Gaussian头与混合预测；证据分数不反馈循环状态。两者即使出现差异，主对照只能识别相同双专家装置下的分块连接组织效应，不能识别“有无候选轨迹”；强连通图亦不等于功能性单假设。Gaussian分量权重不能直接当潜在盆地后验，EviTrack的盆地准确率依赖显式潜在轨迹，不能照搬到只有x预测头的神经模型。

任务侧还有独立的预运行风险：一手论文的参数/叙述内在矛盾，EVT-0001按事前规则发现未筛选路径几乎均在30步前首次出偶发射区，但这并**非**真正的后验消歧时刻；它只禁止把30–170层自然常见当未经验证前提。即使任务后验资格后来通过，也不能补救当前候选/控制的因果辨识。故保留论文作为已知的轨迹选择先例及这份设计为失败记录，**不注册 EXP、不实现或训练神经候选、不改生成器参数来救该设计**。

可独立研究的窄问题是同双头/双分数下的 recurrent 分块与连通结构效应，但它不能自动计项目 Gate 1。若目标仍是原 Gate 1，多轨迹因素须相对强单流有真正不同的候选状态/更新操作，且对照在总状态、有效/分配参数、训练/推理计算和输出能力上匹配；先例PF-RNN/RIMs/EviTrack归属须事前分清。EXP-0004 `FALSIFIED`、EXP-0009 `INCONCLUSIVE`、CAL-0006 `CEILING` 和 Gate 1 `NOT_PASSED`均保持原判。
