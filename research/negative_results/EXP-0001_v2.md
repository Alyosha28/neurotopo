# EXP-0001 v2 — Learning floor prevents architectural inference

Decision: **INCONCLUSIVE**. All 50 registered model×seed runs completed, and primary resource matching passed. At IID delay8, pre-answer accuracy averaged 25.17% for block GRU and 24.97% for matched random GRU, against a prespecified 90% learning gate. Dense H64 GRU was also near chance (25.31%).

Joint pair accuracy was 0.40% vs 0.26% (block minus random +0.137 percentage points, paired-seed 95% bootstrap CI +0.029 to +0.244 pp). This tiny floor-level difference is below the registered 3 pp minimum and does not repair the failed learning gate. At OOD delay16 the effect was −0.020 pp, CI −0.098 to +0.059 pp. The different joint-success chance structure must not be confused with the 25% single-answer baseline.

The evidence establishes failure of this 400-update training regime to learn the task, not absence or presence of useful multi-trajectory computation. Tiny fixed-set overfit passed, demonstrating only that the model and optimizer can memorize those examples. The generator-level learning failure remains an engineering/scientific adequacy issue.

Full records: `artifacts/EXP-0001/v2/manifest.json`, `analysis.json`, `report.md`, and every `seed-N/model/result.json`. No seeds were replaced, no outcomes selected, no original protocol overwritten. Stage Gate 1 stays closed. EXP-0002 separately tests reference-baseline learnability; it cannot retroactively change this decision.
