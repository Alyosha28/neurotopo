# SCR-0001：H3-SLOT 零训练候选筛查结果

2026-09-24。按事先保存的 `research/design/h3_slot_candidate_screen_protocol.md`，只检查一个身份条件化、证据评分的多槽候选；不写模型、不运行训练、不挑新任务。以下是**规格辨识**，不是性能实验、先例完整复现或 H3 普遍否证。最直接的机制先例为 [PF-RNN 原论文](https://ojs.aaai.org/index.php/AAAI/article/view/5952)的带权粒子/观测更新和 [RIMs 原论文](https://arxiv.org/abs/1909.10893)的选择性循环模块；二者与此候选并非架构等价。PF-RNN 论文明确指出粒子有共享参数、额外计算且其 learned latent vectors 未必可解释；因此不能把“有 K 个状态及权重”本身当作假设语义或新颖性。

## 受限候选的示意单步定义

令 `e_k` 是预设的第 `k` 个解释身份，`C_t` 是共享上下文，`Z_t^k` 是槽状态，`l_t^k` 是未归一化对数权重：

```text
C_t       = f_C(C_{t-1}, x_t)
Z_t^k     = f_shared(Z_{t-1}^k, C_{t-1}, x_t, e_k)    for all k
s_t^k     = score_shared(Z_t^k, C_t, x_t, e_k)
l_t^k     = l_{t-1}^k + s_t^k
w_t       = softmax(l_t)
y_t       = sum_k w_t^k readout_shared(Z_t^k)
```

所有槽每步更新、共享 `f/score/readout` 参数；无随机噪声、重采样、跨槽消息、适应或额外内部步。训练若只有相同的全局输出损失，不提供 `e_k` 的真实语义监督；若直接把真实假设身份或逐槽标签作为输入/监督，候选语义的部分效果会被任务专门编码解释。必要动态状态至少为 `dim(C)+K×dim(Z)+K`，还未计 GRU 门工作区、身份嵌入、评分与读出成本；不能拿 `K×dim(Z)` 单独与 H64 单流比较。
此式仍未规定 `e_k` 的具体编码、`C_0/Z_0/l_0`、完整训练损失和任务生成过程，故不满足协议所要求的可实现完整规格。

## 反事实筛查

| 比较 | 同输入下应有的候选独有预测？ | 失败原因或缺口 |
|---|---|---|
| 解析离散滤波 | **没有独有预测。** 仅在静态已知假设、`l_0` 为正确先验且 `s_t^k` 等于正确对数似然时，`l` 的递推才是精确贝叶斯权重更新。 | CAL-0001/0002 的已测四/八状态任务在既定指标与预算下只有少量充分权重，强单流 H64 GRU 已近解析后验；不能把显式滤波的正确更新当作新架构增量。 |
| PF-GRU/带权粒子 | 该受限候选不重采样、各槽身份固定，形式不等同 PF-GRU 的随机共享粒子更新。**未覆盖的定性反事实：**在长期误导证据后，低权重但未删的槽可能比重采样粒子更易在晚到反证时恢复。 | 精确离散滤波同样保留低权重静态假设；PF-GRU 的无重采样消融也可检验重采样本身。当前没有指定任务、输出损失、收益阈值、资源匹配或失败消融，不能把这个方向升级为独有预测。 |
| RIM 风格选择更新 | 本候选每步更新全部槽，RIMs 只更新相关模块；这只是定义性操作差异，**没有可测的新增能力预测**。 | 若改为 top-k 输入路由，就进入 RIMs 直接先例；若坚持全更新，不能靠模块数量证明假设竞争。 |
| 等状态单流 GRU | 预设身份删除第 `k` 槽可能影响同名假设，但没有固定的非硬编码任务收益预测。 | 等状态单流可能编码这些 logit 和槽信息，不能预设它做不到；此前 H64 GRU 近 oracle 仅约束已测四/八状态任务、指标与预算。未定义可校准 headroom 的新任务族。 |

任务族仍未指定一个同时满足“强单流有可学习余量、解析滤波不直接解释候选收益、PF/RIM 相关对照可匹配”的生成过程。因而无合法的最小有用效应数值 `δ`、`ε`、主终点或失败消融；不能用后续任务搜索来填空。槽删除是对硬编码身份的结构性检验，不是已学到功能分工的因果证据。总状态、参数和计算只能给出上面的符号账，尚不能完成数值公平性审核。

## 判定

`NO_SPEC`：协议要求的独有且数值化的任务输出预测、指定 oracle/充分状态任务、完整初始化/损失/身份规格和可否定的差异消融均缺失。上述低权重假设恢复方向被明确保留为**未覆盖的候选反事实**，不是已完成的独有预测。该结论只针对 **H3-SLOT 这一最简单、无适应/通信/重采样的规格**。它不等于证明所有多候选架构与 PF-RNN、RIMs 或显式滤波等价，也不改 EXP-0004/0009。当前 H3 实现 NO-GO、Gate 1 NOT_PASSED；不授权为救此规格加入后续阶段机制。
