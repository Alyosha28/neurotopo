# DIR-0003 领域方法审计综合：相邻领域如何解决本项目的识别问题

2026-09-24。本文综合同批 `research/prior_art/dir0003_A..G` 七份**真实取回**的审计（A 比较方法学、B 可证明的结构收益、C 优化/容量分解、D 连接组 null 纪律、E 模块化与任务结构、F 因果设计工具、G 拓扑→容量定量预测）。**无本地复现**；本文只做跨区归纳与对 NeuroTopo 的转移判定，不新增文献主张、不产出新颖性结论。

## 1. 要解决的识别问题（本项目现状的形式化）

目标命题：组织/结构机制 `M` 在资源匹配下带来可归因的收益。
历史记录显示杀死候选的**不是效应大小，而是识别**，且只有六条通道：

| 编号 | 通道 | 本项目的具体死法 |
|---|---|---|
| P1 | **可模拟性** | 资源匹配的稠密单流可内部模拟组织（决定0043），故"能表达"不构成证据 |
| P2 | **优化/容量不可分** | `β = Δ + (e_U − e_S)`；G1-ALIGN 因容量通道与效应同量级停止（决定0072），G1-BOUND 的界被审查判为无效（决定0073） |
| P3 | **任务可供性/选取** | 任务是否"给得起"效应本身是选择；同族放大已被实测关闭（CAL-0008） |
| P4 | **对照天花板** | 匹配对照触顶 → `INCONCLUSIVE`（EXP-0009、CAL-0001/0002/0006） |
| P5 | **身份硬编码** | 候选语义由输入/定义给定 → "消融第 k 槽只影响 H_k"是定义后果 |
| P6 | **读出/探针容量** | 探针能读出信息 ≠ 机制编码了信息 |

## 2. 七个领域各自给出的"怎么解决"

### A 比较方法学（`dir0003_A`）
最佳实践（多轴披露、调参平价、种子分布）**本项目大部分已经采用**，故 A 区不构成新问题来源。唯一真空缺：**决定0069 之后 Gate 1 文本里的 `Generic` 失去可核验操作化**——0068 曾定义"≥2 任务族或 1 留出族"，随 0068 被取代而消失。另：A 区证据（Efficiency Misnomer、Benchmark Lottery、Show Your Work、Deep RL that Matters 等）说明**水平差可被调参预算与任务抽样伪造，而"性能随预算的曲线"与"任务电池上的排序一致性"不能**。

### B 可证明的结构收益（`dir0003_B`）
- **抗混杂的形态是形状预测，不是水平预测**：可证伪的预测只有四种形态——维数指数 `d^θ`、非单调临界线、平台/相变的**个数与位置**、布尔谓词分侧；**没有一条是"A 的标量 > B 的标量"**。
- **P1 在理论里有正式对应物**：无约束架构可 emulate 任意高效 PAC/SQ 算法，故下界只对带**正则性/等变假设**的算法类成立；任何"结构收益"主张若不写明该假设，**理论上不可证伪**。
- **重要否证**：CSQ/SQ 下界**不约束 ERM**（作者自陈）→ **现有下界工具并未解决"匹配对照会混淆"这一处境**。理论路线不能单独救本项目。
- **预警**：幂律缩放指数本质上是学习效率终点 → 与决定0062 B 冲突；`iterative reweighted kernel` 也能学到有限 leap 的层级多项式 → 结构收益**非神经专属**。

### C 优化/容量分解（`dir0003_C`）
- 可用的**非时间量**终点：α 尺度旋钮（懒↔丰富）、随机标签/加噪**拟合探针**（"近似误差≈0"的实证证书）、restricted/excluded loss 进度量、LMC barrier 高度、Deep Bootstrap 的理想/现实分解。
- **同臂设计（within-arm）不产生需要匹配的第二臂**，因而与单轴匹配口径天然兼容。
- **硬约束**：任何 steps-to-threshold / time-to-accuracy / "optimize faster" 措辞都是学习效率终点，**与决定0062 B 直接冲突**；注册时终点必须逐字写成非时间量。

### D 连接组 null 纪律（`dir0003_D`）
- **分层 null 阶梯**：把 null 排成单调严格化的序列，报告效应随约束增强的**衰减曲线**而非单点 Δ。直接先例（arXiv:2604.04033，作者报告）：消除 checkpoint bias（共享初始化）＋度保持重连后，"连接组优势不再持续"——**与本项目的历史结论同形**。
- **结构性 vs 实践性不可辨识**（sloppy 谱/profile likelihood）：区分"图族内不存在可区分该机制的终点"与"训练预算不足"。
- **解退化三层量化**（行为/动力学/权重空间），把"多对一"从障碍变成设计变量。
- **N1 硬结论**：在本项目四等大分区 + 逐节点固定入/出度下，度保持重连**不可能**在保持 `Q` 的同时改变 crossEdges（`Q = 0.75 − crossEdges/1024` 是恒等式）→ 只能改换**不变量集合**。

### E 模块化与任务结构（`dir0003_E`）
- **Oracle 臂**（Is a Modular Architecture Enough?, arXiv:2206.02713，作者报告）：增设"激活概率由真值 `c` 直接设定、不经反传"的臂作为上界，把裸臂差拆成**潜力缺口**与**优化缺口**。
- **共享 I/O vs 分离 I/O 的受控操纵**（Are Neural Nets Modular?, arXiv:2010.02066）直接反驳"看似任务驱动的分离只是平凡接口产物"。
- **尺寸匹配随机零假设 + 预注册选择性判据**（arXiv:2606.25092）：效应须击败"同数量随机专家"零假设；选择性 = 最差 off-target ≤ on-target 的 1/3；点规则 + bootstrap CI 双判决。
- **警告**：task affinity / 梯度冲突**不能跨设定搬运**（r = −0.14/−0.153；冲突与优化受损相关但**与泛化几乎不相关**；LLM 尺度上冲突极小）→ 以"任务侧指数"作剂量前必须先测该剂量的动态范围。

### F 因果设计工具（`dir0003_F`）
- **F-03 TOST 等价检验**：把"无效应"从"不显著"变成**可拒绝的假设**；等价于 `(1−2α)` CI 完全落入 `(−Δ, +Δ)`。
- **F-06 事前冻结判决函数 + 穷尽分支**：`INCONCLUSIVE` 必须由事前条件**机械触发**（直接补 G1-ALIGN 的 S5 缺陷）。
- **F-11 对照任务 + selectivity**：同输入分布、同预算、随机目标的控制任务，报告 `主任务 − 控制任务`。
- **F-12 从零重训/重初始化基线**：把 `(e_U − e_S)` 从残差变成**可观测量**。
- **F-08 部分识别界**：要求 `C_ub < δ_min/2`（与停止条件 S1 同构），但**界必须是有效界**——G1-ALIGN 的 S4 正是死在"门槛不是被检验量的有效界"。

### G 拓扑→容量的定量预测（`dir0003_G`）
- **总容量守恒 + 按基函数分解**（Information Processing Capacity, doi:10.1038/srep00514，作者报告 Theorem 7）：`ΣC` 的上界**与结构无关** ⇒ "某拓扑更好"只能表现为容量在基函数空间的**再分配**，不能是总量增加。
- **解析记忆函数**（White/Lee/Sompolinsky 2004，经 G 区正文取回）：`m(k) = α^k/(α^k + ε_e(1−α^{k+1}))`，`k_C ∝ N`。
- **符号反转交互**（Rodriguez 2019, doi:10.1162/netn_a_00082）：固定度分布/总边数/谱半径只扫桥接比 μ，threshold 单元下倒 U、tanh/linear 下模块化**降低**容量。
- **未解张力**：Milisav 2026（层级模块 tanh 占优）与 Rodriguez 2019 符号相反，任务/读出/生成器不同，**原领域未做归一化对照**。
- **结构保持 null 系综**（Milisav 2026）+ 主动收窄机制主张；**预警**：总 IPC 与任务特定性能**相关性很差**（Hülser 2023，摘要层）⇒ IPC 只能作中介通道，不得当终点代理。

## 3. 把装置映射回六条通道

| 通道 | 可用的装置 | 出处 |
|---|---|---|
| P1 可模拟性 | 把主张从"能表达"移到**容量再分配**（总量守恒，故"更多容量"不适用）；或写明算法类的正则性/等变假设 | G-D2、B（含"下界不约束 ERM"的否证） |
| P2 优化/容量 | 构造性移除优化通道（冻结核 + 凸读出）；或同臂探针（随机标签拟合、α 旋钮、barrier）；或 oracle 臂分解潜力/优化缺口 | F-12、C、E1-D2 |
| P3 任务可供性 | 剂量取自生成器参数；预测写成**形状/位置**；预注册任务电池与留出族 | E1-D1、B、A2 |
| P4 天花板 | 不再依赖"对照未饱和"——改用**总容量匹配**，使余量问题不存在 | G-D2 + 本设计预检 |
| P5 身份硬编码 | 共享 I/O vs 分离 I/O 对照；尺寸匹配随机零假设 | E2-D4、E2-D1 |
| P6 读出容量 | 对照任务 + selectivity；负对照结局 | F-11、F-01 |

## 4. 由此得到的新问题形态（三种备选与取舍）

| 备选 | 形态 | 判定 |
|---|---|---|
| **NQ-1 组织 vs 信息等价** | 把任务的结构信息以等尺寸通道供给两臂，用 TOST 判"组织能否被信息替代"；附 oracle 臂分解潜力/实现缺口 | **有力但前置未满足**：需要"可学但未饱和"的任务——正是本项目反复失败的前置（EXP-0013 学习失败、CAL-0008 饱和）。列为**后续**问题，其 oracle 臂装置已归档备用。 |
| **NQ-2 表示界是否被兑现** | 逐臂测 `KL_trained − KL*_arm`（架构级 oracle） | **不可用**：与已停止的 G1-BOUND 方向同形（决定0073 明确不复开），且需 BPTT，重新引入 P2。 |
| **NQ-3 容量分布是否预测能力**（选中） | 在**总记忆容量被构造性匹配**的条件下，检验任务曲线是否在**事前可算的交叉位置**换号：带匹配模型 vs 总容量模型 | **选中**。它同时处置 P1（总量守恒→"更多容量"不可能）、P2（冻结核+凸读出→无优化通道）、P4（不需要未饱和对照）、P6（阴性对照任务）；P3 由"剂量=生成器延迟参数 + 形状预测"处置；P5 不适用（无身份语义）。 |

**NQ-3 的取舍理由（如实记录代价）**：(i) 它定位在因果链的 **Representation** 环节，**不主张能力或 Gate 1**，因此**不能**替代项目轨的 Gate 1 需求；(ii) 冻结核 + 凸读出意味着"没有学习"，这与项目最终关心的"训练后的组织收益"之间仍隔着一步；(iii) 它**接受**"这只是把记忆容量测了两遍"这一最强拒绝作为可被数据判定的风险（预注册 S6 强制任务输入分布与探针不同）。
