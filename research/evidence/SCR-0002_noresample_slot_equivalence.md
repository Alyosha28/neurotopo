# SCR-0002：保留低权重固定槽不是可注册的独有机制预测

2026-09-24。按事前提交 `1d3ad58` 的零训练协议，只读 SCR-0001/PA-0001、[PF-RNN 原论文](https://ojs.aaai.org/index.php/AAAI/article/download/5952/5808)、[作者固定代码 `pfrnns.py`](https://github.com/Yusufma03/pfrnns/blob/0a76d52a857f06d4128bbc7601c616d714b25734/pfrnns.py)与[固定 `model.py`](https://github.com/Yusufma03/pfrnns/blob/0a76d52a857f06d4128bbc7601c616d714b25734/model.py)、[RIMs 原论文](https://arxiv.org/abs/1909.10893)，未安装/复制/运行外部代码。主判 **`NO_DISTINCT_SPEC`**：当前 H3-SLOT 示意式没有一个相对显式滤波、无重采样加权粒子和等资源单流都独立、数值化、可消融的任务输出预测。这不是 H3 一般否证，也**不是**“作者 PF-GRU 与任意固定槽严格等价”的证明。

## 源到命题：已实现、作者报告、理论改造三层

| 层级 | 可直接确认的操作 | 不能越过的边界 |
|---|---|---|
| SCR-0001 的 H3-SLOT 示意 | `C_t=f_C(C_{t−1},x_t)`；全部固定索引槽 `Z_t^k=f_shared(Z_{t−1}^k,C_{t−1},x_t,e_k)`；共享评分累加 `l_t^k=l_{t−1}^k+s_t^k`，softmax 权重，`Σ_k w_t^k readout_shared(Z_t^k)`；无重采样/适应/通信。 | `e_k`、初值、完整 `f/score/readout`、任务和损失均未定义，因而不能量化资源、候选语义或收益。 |
| PF-RNN **论文方法** | K 个共享参数的潜在粒子、随机转移、观测权重的乘法/归一化更新、软重采样；论文主读出为对加权**平均粒子**应用预测函数。Table 3 的 `NoResample` 是 **PF-LSTM** 汇总消融。 | 论文不是一个“固定身份无噪声 PF-GRU 在晚到反证任务上胜负”的结果，也未证明同一低权重粒子一直存活。 |

一个实现层注意：固定 PF-GRU 源码使用 `BatchNorm1d(num_particles)`，输入 reshape 为 `(batch,K,hidden)`；按 [PyTorch `BatchNorm1d` 文档](https://docs.pytorch.org/docs/stable/generated/torch.nn.BatchNorm1d.html)，中间 `K` 维被当作通道，默认有**K个增益+K个偏置可训练值**及**K个运行均值+K个运行方差**，训练时统计还跨 batch/同通道位置汇总。这意味着作者代码的粒子**索引可能带有不同 BN 参数/统计**，即使主要 `fc` 权重共享；但每步重采样又改变索引所承载的祖先状态。它既不能当“严格粒子置换等变”的现成控制，也不证明稳定的语义身份。此处是对源码布局和 API 的推论，未运行原项目。

## 低权重恢复的共同代数

在没有删除/重采样/权重裁剪、有限 logit 且所有初始权重为正的任一加权候选滤波器中，令槽/粒子 `k` 与当时主导者 `j` 在时刻 τ 的 log 权重差为 `L_τ^{k,j}=log(w_τ^k/w_τ^j)<0`。若之后评分递增为 `s_t^k,s_t^j`，则：

```text
log(w_T^k/w_T^j) = L_τ^{k,j} + Σ_(t=τ+1..T) (s_t^k − s_t^j).
```

若后段累计差超过 `−L_τ^{k,j}`，`k` 仅重新超过**这个** `j`；要成为全体最大权重，还须对**每个**其他候选 `r` 都有 `L_τ^{k,r}+Σ_(t=τ+1..T)(s_t^k−s_t^r)>0`。这是 SCR-0001 H3-SLOT 的 logit 累加、一个**拟另行实现**的无重采样 PF-GRU 权重更新，以及已知静态假设的精确 log-likelihood filter 共有的性质；不是固定身份槽独有。相反，作者的软重采样从 `q_i=αw_i+(1−α)/K` **条件独立且有放回**地采 K 个祖先；在某个低权重候选只有一份粒子的条件下，该**特定祖先粒子**一次重采样没有后代的概率为 `(1−q_i)^K`。同一假设若由多粒子表示，应使用这些祖先的**总 q 质量**计算全部无后代的概率，且随机转移也可能再次产生同类状态。上述单粒子式只说明“保留还是抽掉”影响特定路径的存活机会，不证明假设灭绝或任务输出收益。重采样与 `NoResample` 本就属于 PF-RNN（论文的 PF-LSTM 消融）的已研究因素。

## 受限共同子族及其不能消除的差异

可以**定义**一个 PF 风格的自有无重采样加权专家参考模板，而非声称复用作者 PF-GRU：把第 k 个状态扩为 `(Z_t^k,e_k)`；让另设的共享前处理网络计算并广播 `C_t`；两边都**限制为同一个预先选定的**转移函数和评分函数，并都不加 proposal 噪声/重采样。若两边采用同一个**仿射**逐槽读出，`Σ_k w_k readout(Z_k)=readout(Σ_k w_k Z_k)`。这只说明抽象加权状态滤波与 H3-SLOT 有一个**按定义同构的受限交集**，不能当作作者固定 PF-GRU 的包含证明，也不自动提供科学上有用的反事实。对作者实现不存在已证明的任意 H3-SLOT 函数包含关系。

映射之外至少有四项真实差异或成本：① `e_k` 若被硬编码，候选标签/删除效果带先验语义，必须用去身份、置换和同监督对照；②共享 `C_t` 若逐粒子复制，会增加 `K×dim(C)` 存储，若保持独立共享子网又超出原 PF-GRU cell；③作者代码的 `softplus` proposal 噪声在有限参数下不为精确零，零噪声只是一个极限或新实现，其门控/线性 `fc_obs` 也不保证能精确实现未指定的任意 `f_shared/score_shared`；④H3 的 `Σw·readout(Z)` 与论文的 `readout(Σw·Z)` 对**非线性**读出一般不相等，例如两状态`−1,+1`、各权重0.5、`readout(z)=z²`时两式分别为1与0，需限制仿射读出或增加每粒子的读出特征/计算。作者 `model.py` 的主预测先合并粒子后过输出层，逐粒子预测另供辅助损失，不能混称两种主读出。对完整比较还需匹配 `dim(C)+K dim(Z)+K`、身份 embedding、评分/BN/随机数/重采样、有效与分配参数、执行 FLOPs/时延，不能拿单一 K×h 账代替。

## 判定、最强拒绝和停止边界

**`NO_DISTINCT_SPEC`。** 现行 H3-SLOT 只提出被低权重后重新恢复的宽行为；在静态已知假设下，显式滤波已有无损解，旧 CAL-0001/0002 又被 H64 单流近 oracle 学会。相对重采样 PF 的差别首先是**是否重采样**；相对拟独立验证的无重采样 PF-GRU，当前没有已固定的另一更新算子、任务输出主端点、最小有用差、主控制余量或失败消融。固定身份可能改变归纳偏置，proposal 随机性/BN/读出也可能产生差距，但每一项都需单独固定、消融和计资源；不能在任务结果后挑一项当 NeuroTopo 新机制。故不启动 H3-SLOT 训练或新 headroom CAL，维持 SCR-0001 `NO_SPEC` 与 Gate 1 `NOT_PASSED`。这只否定当前受限候选的**独有规格可注册性**，不是证明固定身份机制在所有任务上无益，也不排除未来写出不同候选。

最强反驳是上述“PF 风格参考”被我们加了身份与零噪声，不是作者已发表的无重采样 PF-GRU；本文件已明确为**受限交集构造**，并未把它当作作者的实证先例或等状态/计算完成的基线。若要重开，须先写出一个不依赖新增适应/通信或隐形资源的明确操作差异，以及相对显式滤波、PF-GRU 重采样/无重采样、RIM 与单流的方向性、数值化、可失败任务预测；其中读出、身份与噪声各自控制。没有这样的合同就停在零训练候选筛查，不靠新任务参数搜索恢复它。
