# EXP-0010 v1 在 Gate 1 障碍前的决策价值

2026-09-24。审查对象是已提交 `d0c2da2` 的**未运行设计**，不是实验结果。原设计的唯一操纵是两个 K2 模型的软门控温度；主比较没有 K1/强单流。独立预运行批评见 `docs/EXP-0010_pre_run_review.md`。

| 预想结果 | 可合法改变的决定 | 对 Gate 1 的增量 |
|---|---|---|
| 资格失败 | 关闭这个固定温度/旧任务规格；保留失败 | 无：项目候选、实际单流主控制仍缺 |
| 资格过且 low 胜 high | 仅保留旧任务上的温度 package 领域候选；须另做中介干预 | 无：没有 K 因果对照或竞争假设证据 |
| 资格过且未达+3pp/负差 | 证伪此有用温度收益预测 | 无：不能否定 K 机制或 Gate 1 一般命题 |
| 边界/超时 | 本规格不可判，保留全部尝试 | 无 |

因四分支都不缩小当前 Gate 1 的候选—对照缺口，本轮若继续消耗156,000更新，主要满足旁支好奇心，与用户要求“反思策略是否造成障碍并优化至过门”不符。主代理原策略错误是：已有多次任务资格和旧 M3 负/封顶记录后，仍把“容易写出对照的 K2 温度因素”误作当前最高信息增益方向；科学上合法的独立问题不等于项目阶段门的优先任务。直接停止在实现/训练前，可避免又一个无法计入 Gate 1 的正结果或不可判结果。

停止不等于把温度 package 判无效，也不否定独立 benchmark 轨。下一项目任务的**事前**研究问题必须直接操纵 K/候选轨迹相对于真实单流主控制，先给身份/状态/计算和可否定预测，再校准该主控制余量；不能先训温度两臂再把胜者加进项目比较。现行项目参考 K 因子资格仍未解决，若选该路须在任何性能结果前裁定，而且不能用门槛修订替代候选、控制或任务资格。
