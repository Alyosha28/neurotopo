## 1. 三条张力：条件性命题，前件可机械判定（收窄 v1 审查 I4）

- **T1（表征内容与可达集之差）**。对固定对照臂的可达集 `R_c` 与候选臂的可达集 `R_m`，**类型判定规则（可机械判定）**：若能给出一个落在 `R_m \ R_c` 中的可构造函数，则属**扩张/重构型**；否则 `R_m ⊆ R_c`，属**限制型**。两类的**符号与举证标准对称化**：
  - **扩张/重构型**：可达集之差**可能利于候选**，故须给出**通道量的单侧上界**（含样本量与置信水平），并证明界 ≪ 待检效应；否则不可归因。
  - **限制型**：可达集之差**对候选不利**（候选的最优可达损失 ≥ 对照）。因此一旦在冻结预算下观察到**正向水平差**，通道项**不能**解释它——**归因问题反转**，最强拒绝随之转为"该约束只是已知的正则化/归纳偏置效应（K7 新颖性）"。此类候选须给出可达集之差的**幅度上界**（证明它不是效应的来源）。
  - **v1 的错**：把"先判定类型"留给口头分类，且在 §3 预填 C8/C9 为"限制型"。v2 给出上述机械判据，并把 C8/C9 的类型标为**未判定**。
- **T2（容量型效应与 v3）**：`G1-MATCH-v3` **不含**"匹配声明轴后优势必然消失"的条款；故这是**可证伪预期**而非规则推论。**检验**：在按 v3 匹配声明轴的控制臂上**实测**优势是否消失；若仍在，此类效应可入，排除失效。
- **T3（头寸与任务退化）**：为制造"精确解不可用低维平滑近似"的头寸而构造的信息受限任务，会让**信息**而非组织成为约束（CAL-0008 实测 ＋ DIR-0004 审查 I7）。**范围**：锚点是单一构造，不得外推；逐构造实测观测信息量与可归因性。

## 2. C7：正面规格 ＋ 显式非主张（同 v1，未改）

一个候选属此类，当且仅当同时给出：(i) **同容量**（按 v3 声明轴匹配；`state` 匹配不再必须，其余轴按实测比值披露）；(ii) **表征可达性证明**（两臂可达同一最优，或以有效界证明通道 ≪ `δ_min`；限制型候选按 §1 的"对候选不利"方向给界）；(iii) **水平终点**（冻结预算下的水平量；不用时间/效率量，见 U1）；(iv) **无架构基线**（参考臂定义与求解方式；oracle 臂只作诊断）；(v) **具名机制与方向性预测**。
**显式非主张**：本类**未被证明非空**，不是"现行判据下仍可过门"的证据，只是候选自检清单。

## 4. 余量与构造效度：更正须连同原件的条件读（收窄 v1 审查 I6）

`research/evidence/gate1_benchmark_baseline_audit.md` 逐字给出：EXP-0004 的**预注册主对照**（随机掩码 GRU H64，同 64 状态值、6,212 有效参数、度/自环与稠密执行计算与 M3 相同）在 IID8 `100.00%`、OOD32 **`67.04%`**，并写明 *"Substantial primary-endpoint headroom"*。

**但同一原件同时写明该任务的结构性弱点与前置条件**：`make_batch` 存在 cache-and-select 简单解，故它**不能单独检验**四个循环块是否为四个竞争解释；"A future, separately registered benchmark must first specify latent hypotheses and evidence updates with a nontrivial full-information oracle, plus a simple cache-and-select oracle…"（并须分离校准/最终流、事前选定难度切片、强常规基线可学而仍留余量、逐片报告基线与 oracle 分数）。

**因此正确的诊断（更正 v1 §4 的结论句）**：**实测余量在某个已存在配置上确实存在，但它尚不可用**——按原件自己的要求，要用它必须先另立注册、补齐 oracle 与流程要件。缺的是"**可用**的余量配置 ＋ 具名机制（K7/方向性预测）＋ K2/K3/K9 装置"，而不是"缺余量"或"余量已就绪"。

## 5. 重开条件（收窄 v1 审查 I2/I6：与 v3 一致，且每条可机械判定）

1. **具名操纵与方向性预测**：具名被操纵量、其在 §1 意义下的**类型判定**（扩张/重构 vs 限制，按机械判据）、预期符号与幅度。
2. **匹配口径（v3 一致）**：主对照**只在声明的消耗轴上被要求匹配**；其余各轴按**实测比值披露**（不得写成"除该量外全部相同"）。
3. **余量实测**：控制侧资格流给出**水平量实测**（非解析量）＋ `δ_min` 推导来源（脚本与 sha256）；若沿用既有任务，须先满足 §4 的 oracle 与流程要件。
4. **通道**：按 §1 类型给**单侧界**（扩张/重构型给上界；限制型给幅度上界并说明归因反转），附样本量、置信水平与判定阈值；族内投影代价 `Δ` 不得充作通道界。
5. **无架构基线**：参考臂定义与求解方式。
6. **闸门功效（可复算）**：每级的样本量/功效算法、`MDD`、判定阈值；探针须论证监督不泄漏被操纵因子（K9）。
7. **统计与留痕**：多重性/族错误率、**选择零**、有效自由度与配对结构披露；自缚通用谓词；并注明 U2 未决使第三方**不可核验**通用性成分。
