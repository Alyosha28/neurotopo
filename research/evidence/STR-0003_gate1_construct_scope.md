# STR-0003：项目首门的结构效果与后续语义条件

2026-09-24。按事前 `research/design/str0003_gate1_construct_scope_protocol.md` 只读核对用户章程摘录、阶段门及本项目自加规则；不训练、不看新效果、不改旧结果。

| 来源/现行做法 | 明示要求 | 对首门的含义 |
|---|---|---|
| 用户§34/§40（`research/design/gate1_user_charter_evidence.md`） | Gate 1 名为“Generic Multi-Trajectory Effect”，要求状态/计算匹配后的多轨迹收益；正式问题比较多条 recurrent latent trajectories 与单轨迹，匹配参数、状态、训练和推理计算。 | 主效应是**结构干预→任务表现**，不能由仅有K个状态或不同向量证明；但原句没有要求此时证明每块是语义独立假设或比PF/RIM新。 |
| 用户§26/§3.5及§34 Gate 3 | 多隐藏状态不足以推论假设轨迹；要求候选解码、删除、功能专化，与RIMs比较；Gate 3独立要求轨迹特异的因果效果。 | 完整**语义“竞争假设”主张**需Gate3因果专化；但§26也要求持久性、冗余/坍塌等诊断，不能全部推迟。Gate1至少核实所称多轨迹的操作定义，而非仅数K个向量。 |
| 用户§2/§9、决定0006/0012/0019/0023 | 多模块/粒子/路由本身不是新颖性；纯先例复制在当前项目规则下不能单独过门，具名参考K项目资格未裁定。 | **新颖性与归属**独立于结构效果；本审计不放行先例作者结果或纯复现，不解决参考K项目计分。具体候选仍需先例边界及独立审查。 |
| 当前 H3-SLOT合同及两次候选拒绝 | H3-SLOT要求解释身份、权重、因果干预；G1-MB因旧任务/预算后验选择且读出按标签固定被拒；G1-DD因外部任务资格风险及双头分数对照难归因被拒。 | 这些 NO-GO 适用于各自的**具体设计/通用假设语义**；不能把“强单流有能力内部模拟K解释”当任何结构K对照都不合格的理由。公平强单流本就应尽量有此能力。 |

独立预决策批评（`docs/STR-0003_predecision_review.md`）接受**“Gate1不必先完成Gate3的完整语义专化”**这一窄事实，却指出原设计的判定规则遗漏中间情形：实际比较可能只隔离连接组织或读出，而没有隔离K轨迹因素。按预写第三分支，对“当前可否据此放行结构分组作为项目Gate1因素”的综合问题判 **`INCONCLUSIVE`**，不把草稿的 `GATE1_EFFECT_GATE3_SEMANTICS_SEPARATE` 扩成新项目计分规则。Gate1候选仍必须事前定义独立循环历史/更新如何构成因素、它与实际强单流在哪些操作不同、哪些读出/稀疏/输出能力/资源完全相同，并用持久/坍塌/冗余诊断确认操作对象存在；“不同潜在解释”的因果语义留给Gate3。

最强反驳得到保留：一个 block mask 的性能差可能仅是稀疏正则化或优化，且适当强的单流能够显式/隐式维护多个解释。若正式注册**结构K**因素，要把估计对象、状态操作和实际对照逐项定义；仅block-vs-random拓扑时就只能称连接组织效果，不能偷称K因果。还需同等状态/参数/执行计算的主对照、稠密强单流与未限制读出敏感性。若只赢弱稀疏对照不赢稠密强控制，不能写“优于强单流”；若轨迹坍缩，也不能在 Gate 3 说竞争假设。数据/任务须在候选效果前固定且主控制确有可测余量，不能像 EXP-0009 用背景稠密臂替实际对照定难度。两个已拒设计的任务选择/来源缺陷不会因这项分层消失，原NO-GO保持。

这项审计只留下一个范围澄清：完整Gate3语义不能单独作为Gate1入口否决理由，**但**项目K因素是否被隔离仍须逐候选事前审查，不能被“结构分组”四字代替。实际下一轮可因任务选择、因素混同、前向泄漏、未匹配资源、主控制封顶/地板或先例归属未定而被挡。它不产生数值效果、不使Gate1 PASS、不启用Gate2；本轮不修改 `entry_policy.py` 或阶段门。
