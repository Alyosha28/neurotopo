# INV-0001：从状态差异转为反演稳定性约束

2026-09-28。只读EXP0019全部已存snapshot，0新样本、0模型执行、0训练。设计在新派生指标计算前单独提交；原距离结果早已暴露，故这是一项**事后反问题敏感性刻画**，不是新的未暴露集机制验证。

## 1. 已完成的反问题分析

逆问题为：给定模型、共同后缀u和晚期观测hidden y，反推前缀结束时的h0或其b。完整前缀不提供给逆算法。当前计算的是有限配对的必要稳定性界，没有实现逆求解器、没有计算Jacobian/SVD，也没有测量真实观测噪声。

设一对前缀末态相差d0，晚期状态相差dt。任何能同时精确恢复它们的逆映射，必须在这对观测上具有至少`G=d0/dt`的L2放大率。它是**割线下界**，不是全局条件数或局部奇异值谱。只报告条件数可能漏掉绝对敏感性：`F(h)=1e−8 h`的相对矩阵条件数为1，但绝对逆增益为1e8。

若假定晚期观测允许L2扰动不超过eta，且`dt<=2eta`，两个候选的误差球相交。相交观测下，任何h0重建器对至少一条候选的误差>=d0/2；对于b相反的两候选，也不能保证两者都判对。若在本批均匀加权的配对数据上允许逐样本有界扰动，稳健准确率上界为`1−重叠比例/2`。这是最坏情况界，不是随机噪声实验准确率。

## 2. D64：反演放大下界迅速增加

下表先对每seed的384对反b历史分别求G的中位数，再报告三个seed中位数的范围；不是旧距离表的中位数之比。全部在所存hidden坐标与L2度量下。

| 后缀操作数 | float32逆增益下界中位数范围 | float64逆增益下界中位数范围 |
|---|---:|---:|
| 0 | 1 | 1 |
| 16 | 1.27e2–1.29e3 | 1.27e2–1.29e3 |
| 32 | 6.98e3–6.85e5 | 6.98e3–7.70e5 |
| 64 | 3.23e6–4.56e6 | 2.62e7–2.90e11 |
| 128 | **4.44e6–4.55e6** | **2.09e14–2.43e15** |

即使最终hidden仍不完全相同，精确区分该批候选所依赖的间距已经很小。float32的下界更小，不表示它比float64更能保留任务信息：两种数值实现不同，float32中更大的尾部差异可能与舍入行为有关，本轮没有证明这些差异承载可用b信息。

## 3. 有界扰动场景

eta是人为声明的绝对L2预算；不把它等同于float32/64机器epsilon或实测误差。表中只是该预算下的两候选球重叠判据，边界不确定项没有算成重叠。

| D64，后缀128操作 | 假定eta | 反b配对重叠比例 | 配对集最坏情况下可保证准确率的上界 |
|---|---:|---:|---:|
| float32 | 0 | 0% | 100%（界无约束，不代表存在可用逆算法） |
| float32 | 1e−6 | **100%** | **50%** |
| float64 | 1e−14 | 85.07% | 57.47% |
| float64 | 1e−12 | **96.53%** | **51.74%** |
| float64 | 1e−10 | 99.83% | 50.09% |

在float64、eta=1e−12的场景中，重叠pair的初始重建误差下界d0/2仍是正常状态尺度；它不是“末态误差也只有1e−12”的承诺。完整逐seed值、所有7个eta与9时点结果见`analysis.json`。本轮没有报告未扰动分类器实际达到或跌到这些上界。

同b不同历史也表现出类似反演困难；D16还存在dt=0、d0>0的pair，对这些初态已经不存在同时精确恢复的单值逆。完整记录保留无限增益和undefined，不将它们丢掉再只报有限中位数。上述结果不建立b特有的遗忘机制。

## 4. 对设计的实际约束

这项分析把“状态还差一点点”转换成了“允许多大的观测误差仍有希望反推”的问题。对于需要稳健恢复b的状态表示，在明确误差预算下，让相反b候选保持`dt>2eta`是必要条件；它并非充分条件，也不保证模型能学到这样的表示。正则化可以选择稳定或偏好的解，但在两个候选误差球已经重叠时，不能保证对两种历史都正确。

因此，目前可以约束的是**给定坐标、已测路径及假定误差预算下的稳健可恢复性**。不能据此声称实际b已从所有hidden丢失、推断哪个神经元专门编码b、证明某种拓扑更好，或宣称找到了新的逆方法。
