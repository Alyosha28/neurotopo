## 狭义解释与最强反驳

本轮的有界解释是 **`REFERENCE_EVIDENCE_SEPARATE_FROM_PROJECT_GATE`**：章程未强制在研究领域的通用效应问题前先有新颖架构，一个真正维持多候选轨迹的既有机制，若经**本地、任务相关、完全注册且资源匹配**的实验，可为领域问题 A 提供证据。这是从“generic effect”措辞和 Gate 3/新颖性独立要求作出的**推论**，并非用户明确授权“PF-GRU 使 NeuroTopo Gate 1 通过”。现行决定0006反而明确禁止把先例复制的正效应直接记成 NeuroTopo 候选过门。若未来希望改变这种项目 Gate 1 计分规则，必须在任何实验结果前正式版本化决定0006、`research/program.md` 和 `research/stage_gates.md`，写清被测模型归属、主对照、任务、阈值、匹配容差和复核规则；不能结果出现后改称“NeuroTopo 候选”。

最强拒绝理由是先例结果洗白：允许一个已知 PF-GRU 赢过弱单流，就解锁适应/通信并声称 NeuroTopo 有优势。防线是：①作者论文或单次 smoke test 永不算本项目 Gate 1；②主对照必须强、实际主控制在独立流有 oracle-relative 余量；③匹配总状态与**实际执行计算**，不仅参数；④所有失败预算/种子/任务保留，不选有利 slice；⑤通用效应与特有贡献分栏报告，前者不使后者成立；⑥Gate 3 语义仍待独立干预。若这些条件不能同时满足，就维持 Gate 1 `NOT_PASSED`。

§21 的 Phase B 是在生物拓扑前最小验证代表先例；仓库当前把更完整的先例复现放在合格通用效应后。GOV-0001 不整体前置 Phase B，也不把 Gate 3 的语义专化提前当 Gate 1 条件。决定0010停止的仍是**无任务/无候选时先做 PF-GRU 工程 smoke test 来救旧 M3/H3-SLOT**；它不是一个符合上述条件的正式先例机制效应实验。因此本解释不追溯撤销0010、不授权今天实施 PF-GRU，也不改 EXP-0004 的限定 FALSIFIED、EXP-0009 的 INCONCLUSIVE 或 SCR-0001 的 NO_SPEC。尚无已资格的任务或匹配实现，项目 Gate 1 当前仍 NOT_PASSED。
