## 任务族与参照

`DELAY-d`：命令 `u_t` 为 i.i.d. Bernoulli(0.5)，读出头索引 `r=1..T` 必须输出 `u_{r−1−d}`（越界为 0），即"上一条命令再往回 d 步"；`d=1` 要求记住并输出上一条命令。环境沿用 ARCH-0001 冻结生成器的扰动接口（共同旋转 π、leak0、σ0）。反事实分支标签为 `branch_targets[:,r,v] = y_{r+1}`（不依赖 v，全部来自过去命令，无未来泄漏）。两个不训练参照：**无记忆直通**（输出刚施加的命令）与**显式移位寄存器 oracle**。

## 结果

扫描：6 个配置（`d∈{1,2,3}`×监督 `{PLAIN,BRANCH}`）×2 seed（29101/29102），每条件 2000 次固定课程更新；主评估 `T=12`（训练范围内），次评估 `T=64/256`（外推，仅报告）。确认：首个合格条件在独立 3 seed（29111–29113）上复跑。

|---|---|---:|---|---:|---:|---|---|---|
| 1 | PLAIN/BRANCH 并列 1.0000 | 1.0000 / 1.0000 | 1.000 / 1.000 | .5373 | 1.0000 | 是 | **否（封顶）** | 否 |
| 2 | PLAIN（并列 0.6916） | 0.6967 / 0.6864 | 0.538 / 0.509 | .5379 | 1.0000 | 是 | 是 | **是（首个合格）** |
| 3 | PLAIN（0.7306） | 0.7343 / 0.7269 | 0.546 / 0.511 | .5409 | 1.0000 | 是 | 是 | 是（次序在后，未选） |

**合格条件＝`D2_PLAIN`（d=2，只用实际序列损失）**：独立确认 seed 29111/29112/29113 的准确率为 **0.6922 / 0.6979 / 0.7009（均值 0.6970，min 0.6922，max 0.7009）**，全部落在预注册带宽内，`reproduced=true`。即强控制 `INV_COMP(w32,b1)` 在冻结预算下可学（远高于 0.50 随机与 0.54 无记忆参照），但离 oracle 1.0 仍有约 30 个百分点的余量——这是本项目第一次得到"控制非封顶且任务可解已知"的合格条件。

其他记录：`d=1` 上两种监督都到 1.0000（封顶，按判词表不合格，保留为对照）；`d=3` 也合格但按预注册顺序未选；次评估显示模型在 `T=64/256` 上退化到 ≈0.51–0.55，说明长度外推本身是独立问题，A2 端点应固定在训练范围内的长度（或把长度外推另立为 A4 问题）。

## 边界

- 本轮支持的是**任务资格**：该任务对强控制可学、非封顶、无记忆解法无效、oracle 已知。它不是候选效果、不是 A2 通过，也不改变 A1（仍缺候选侧在该任务上的学习/比较）与旧 Gate 1。
- 候选 `SC-REL-v3` 的 A0 合同把分支监督写死为一比特任务的 `q_t xor v`；本任务族需要把它推广为"任务自身的反事实下一目标"。按决定0103 第 1 条，任何此类改动必须命名 `v4` 并保留 v3 记录，因此**本轮没有候选结果**；候选侧比较只能在 v4 合同冻结后另立协议。
- 扫描中 `d=2` 的 PLAIN 与 BRANCH 两变体准确率并列（0.6916），预注册规则取字典序首个（PLAIN）；两者权重哈希不同、损失不同，属并列而非同一模型。
- 已暴露的 `d`、seed、长度与带宽不得用于反向挑选后续 A2 端点。
