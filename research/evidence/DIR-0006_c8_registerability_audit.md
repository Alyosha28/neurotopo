## 2. 为什么是 `NEEDS_NULL_DESIGN_FIRST`（①②的具体状态）

**① 可分离性——一半已被证明不可分离。** `research/evidence/h1_h2_existing_evidence_audit.md` 与决定0004 记录：在该图族（64 节点、1,024 有向连接含 64 自环、逐节点入/出度 16、四个等大块）内

```text
Q = (1024 − cross − 256) / 1024 = 0.75 − cross / 1024
```

是**精确恒等式**（40 张正式重建图最大残差 0）。因此"只改跨块桥而保持固定划分 modularity 不变"在本族内**不可能**——**操纵 cross/modularity 的方向结构性关闭**，这不是证据不足。

**另一部分只有存在性。** `h1_reciprocity_feasibility.md`：十张 C0 图**各**找到一次合法双边交换，同时保持 1,024 边、逐点入/出度 16、64 自环、原跨块边数（717–747）与强连通，故也保持上式；去自环互反比例每次变 ±0.002083（个别 −0.004167）。该记录**自己写明**：这解决的是**存在性**问题，**没有**证明可生成足够宽、均匀、独立于谱/路径/motif 的互反变化分布；一次交换太小，**不能拿来测试任务能力**；该脚本**不是**成熟 null。

**② null 族四条件只能靠设计判定。** `h1_null_family_review_criteria.md` 要求在**搜索与任务分数之前**固定：目标差异的数值与方向、可接受范围、每张源图的采样目标、独立图样本数、搜索预算与失败处理；要精确保留的逐点入/出度、自环、跨块边数、强连通；要匹配或显式视为混杂的谱/motif/路径/聚类统计量**及各自数值容差**、联合满足计数；采样算法/版本/许可证/固定 RNG/混合覆盖诊断；并明写**图空间可行性本身不推进 H1/H2/Gate 1**，随后仍须另行预注册任务、主匹配对照余量与因果判定规则。这些量的取值**不可能**由现有记录读出——它们正是 null 族设计评审要产出的东西。

## 3. 最强反驳 P1 的正面回答：自决定0014 以来"新"了什么

P1 的原话是：本审计是已被判 `NO_GO_NOW` 的互反图搜索换名，而 0014 的决定性理由是"**没有可被此次搜索改变的当前可执行决定**"，且此后**没有新证据**。逐项核对：

- **图证据侧：没有新东西。** 自 0014 以来本条线未产生新的图空间或任务证据；BND-0001（`BOUND_NONDECISIVE`）、witness 的存在性结论与 0014 时相同。**P1 在图证据意义上成立。**
- **入口规则侧：有一项结构变化。** 决定0080 允许项目 Gate 1 轨申报 `architecture_organization` 因子。**此前**"图拓扑类"因子在项目轨**结构上无处可放**（入口策略强制 `h3_candidate`），因此 0014 的"没有可改变的可执行决定"至少部分来自**入口封堵**而非纯证据。0080 使"若证据齐备则可注册候选"成为**可能**，但**不提供**证据。
- **方法侧：有一批新工具但要自己挣。** DIR-0005 v2 给出：单轴匹配（v3）＋全轴披露、**可机械判定**的操纵类型判据、限制型操纵的**归因反转**、`NOT_EVALUATED` 读表纪律。它们是**方法**，不是图证据。

**结论**：P1 **部分成立**——不该以"规则变了"为由重启搜索；但"入口彻底封堵"这一条已被 0080 改变，故正确的处置既不是直接搜索，也不是永久关闭，而是**把唯一的门（null 族设计评审）先修好**。

## 4. 与 DIR-0005 的关系（C8 在候选表中的位置）

DIR-0005 v2 §3 把 C8 整行标 `NOT_EVALUATED`，并把 C8/C9 列为下一步优先取证方向。本审计是那一步的**第一次**执行：它**没有**把 C8 变成候选（N1 PARTIAL、N2/N3 FAIL、N7 BLOCKED），只是把"缺什么"从"未评估"精确化为"**缺一份通过审查的 null 图族设计**，其后仍缺可用余量任务与通道界"。因此 DIR-0005 v2 的读表规则不变：C8 **仍不是**候选，`NO_REGISTERABLE_CANDIDATE_NOW` 仍只覆盖 C1–C7。

## 5. 下一步（唯一合法动作，且不得越界）

1. **null 图族设计评审**：按 `h1_null_family_review_criteria.md` 四条，把目标差异方向/幅度、每图采样目标、图样本数、搜索预算、失败处理、全部保度量与匹配量及其**数值容差**、采样算法/版本/许可/固定 RNG/覆盖诊断逐条写死；**在通过独立前瞻审查之前不写、不运行任何搜索器**（决定0014 的禁令继续有效）。
2. 设计评审通过后，才谈"运行搜索以**判定图空间是否存在可用处理强度**"；即便判定为是，仍须另立注册补齐 N2（可用余量任务）与 N3（通道界），并受 U1–U3 约束。
3. **不得**在此路径上引入训练、模型或能力分数；**不得**把存在性 witness 当作效应证据；**不得**把 C8 记作"已核查并拦住"。
