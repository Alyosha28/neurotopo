# TH-0001：等总状态下，增加假设数不能单凭容量计数使多轨迹必胜

## 现有任务的构造性滤波状态

CAL-0001 的静态真值 `H∈{1,2,3,4}`，证据 token 给出 cue `c_t` 与可见可靠度 `p_t`。令 `q_t=(1−p_t)/3`，则对四个候选的未归一化 log 权重更新为：

```text
ℓ_t(h) = ℓ_{t−1}(h) + log q_t + 1[h=c_t]·log(p_t/q_t)
π_t(h) = softmax_h(ℓ_t(h))
```

均匀先验令 `ℓ_0(h)=0`。被明确标记的 distractor 不更新权重，pre/final query 时各读出当前 `π_t`。这正对应 `belief_task.py::_posterior` 的 `log_weights += log(wrong)` 与被 cue 命中列的 log 比值增量。**四个 log 权重**足以按所有新证据递推完整后验；共同加常数不变，因此可用三个相对 log 权重表示同一时刻后验。这是构造性上界，未证明在本生成器的有限可达序列上必须有三维连续状态。

CAL-0002/EXP-0009 的真值是静态联合 `(H,R)`，`H∈{1..4}`、未观测可靠来源 regime `R∈{0,1}`；观测 token 提供 cue `c_t` 与来源 ID `s_t`。对每个联合候选 `(h,r)`，若 `s_t=r` 则 `p_t(r)=0.8`，否则 `p_t(r)=0.4`，`q_t(r)=(1−p_t(r))/3`：

```text
ℓ_t(h,r) = ℓ_{t−1}(h,r) + log q_t(r)
           + 1[h=c_t]·log(p_t(r)/q_t(r))
π_t(h,r) = softmax_{h,r}(ℓ_t(h,r))
```

这与 `source_belief_task.py::_joint_posterior` 的两层循环和最终归一化一致。来源序列、cue 与可靠度以外的过去历史不需另存；标记的 distractor 不进入更新。**八个联合 log 权重**足以递推完整联合后验，共同平移后有至多七个相对权重。这里也只给构造性上界，不声称实际可达后验集恰有七维。

该生成器还施加一个更紧的**查询时刻**约束：`_balanced_sources` 在早期四条证据中让每个来源各出现2次，最终八条中各出现4次。令 `n_{s,h}` 为来源 `s` 给出 cue `h` 的计数；查询时八个计数按每来源固定总数满足两条线性约束，连续放松后有六个自由计数。每个候选 logit 是这些计数的仿射函数；cue 命中的两个可靠度系数为 `β_good=log(0.8/(0.2/3))=log 12`、`β_bad=log(0.4/(0.6/3))=log 2`，其来源×regime 系数矩阵 `[[β_good,β_bad],[β_bad,β_good]]` 行列式非零。故三组独立 cue 对比各给两个非平凡 logit 方向，连续放松后扣公共平移的**查询时 logit 仿射秩恰为6**；独立数学审查另以数值矩阵复核。处理中途前缀仍可用八权重在线更新。实际固定长度离散 cue 序列只产生有限多个后验点，不能把这个连续放松秩说成其最小连续状态维数。

`RecurrentModel.forward` 每 token 的后续更新只接收当前输入和 `h∈R^64`；固定权重/掩码不是每例可变的假设存储。但在早期 query 时它还暂存 `pre=self.readout(h)`，对 EXP-0009 为**每例8个不反馈的输出 logit**，直到最终返回 `(pre, final)`。旧正式结果的 `hidden_state_floats=64` 是递推状态账，未单列这项输出缓存；两主模型都以相同方式缓存，故旧匹配结论不变。当前 `resource_account` 现在新增 `pre_readout_cache_floats_per_example` / bytes 字段以避免未来把“递推状态”误报为整个 forward 生命周期的全部活跃数据；字节数沿项目基准环境使用 float32=4 bytes/值，非任意 dtype 的通用量，峰值激活/反向内存仍未测量。旧 EXP/CAL 产物不可被这一事后字段追写。

## 任意完整后验的有条件下界，不是本任务的下界

另设一个比上述离散有限任务**更强**的要求：K 类后验的内点含一个 `K−1` 维开集 `U`，模型需以可微 `f:U→R^H` 编码，且有可微读出 `g:R^H→U` 在 U 上**精确恢复每个完整后验**，即 `g(f(p))=p`。微分得到 `Dg(f(p)) Df(p)=I_{K−1}`，而左边秩至多 H，所以必要条件 `H≥K−1`。单流 H 维状态与总状态同为 H 的多轨迹状态都受同一个维数限制；仅把 H 切成 K 段不会增加连续坐标总数。额外显式权重、上下文、粒子索引或其他持久缓存若不计入 H，就破坏了“等总状态”前提，必须纳入资源账。

该秩论证**不能直接施加到现有 CAL/EXP 生成器**：固定长度、离散 cue/来源/可靠度产生的可达后验集合可为有限集，未证明含单纯形内点开集；模型若只输出 MAP 标签或某个低维任务函数，也不必精确恢复完整后验。不连续或无限精度编码另不符合可微条件。反过来，当 H≥K−1 时，维数条件只是**不排除**精确表示，完全不保证 GRU 可以在有限样本、有限更新和给定优化器下学到对数似然递推。

## 策略判定

`CAPACITY_ARGUMENT_UNSUPPORTED`：两个源码生成器均有 ≤4/8 log 权重的构造性滤波器，且正式比较的单流与分块模型总动态状态同为 H64。继续提高 K 即使让任意完整后验的维数超过 H64，也会同时给等 H 的两类模型带来容量压力；它**不能单凭状态维数**制造“单流不够、多轨迹够”的结构性必胜。若要研究多轨迹归纳偏置，应改问固定预算下的学习效率、转移/组合泛化或稳健性，并先定义能区别简单滤波、额外状态/计算和任务选择的可证伪预测与真实主对照余量；本审计本身不启动这些实验。CAL-0001/0002、EXP-0004/0009 与 Gate 1 的旧判定全部保留，Gate 1 仍 NOT_PASSED。
