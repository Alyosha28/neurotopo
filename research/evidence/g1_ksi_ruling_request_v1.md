# G1-KSI-0001 两项前瞻规则裁定请求 v1

2026-09-24。**性质：前瞻规则裁定请求。** 本文件不注册实验、不授权训练、不改变 Gate 1 `NOT_PASSED`、不追认任何既有冻结判词。送审对象是 G1-KSI-0001 v3（`research/design/g1_k_structure_learning_efficiency_v3.md`）。

请求来源：决定0054（DIR-0002 判 `RULE_CHANGE_FIRST`，留下两个须结果前裁定的问题）。v0 版本的两项请求曾获独立评审，结论为请求 A **未通过**（缺具体矩阵、机制论证与决策规则）、请求 B **需收窄**；本 v1 按该评审的收窄条件重写。

## 请求 A：决定0049 适用性

### 拟议裁定

G1-KSI-0001 的 F/X 是**同一新注册生成器中的两个预定结构条件**——两者只差一个在任何资格样本前固定的耦合矩阵；且其研究问题相对已关闭的 G1-RS 任务寻找构成决定0049 所称的"**新的独立研究问题**"。因此可依 0049 保留的路径作为新任务族提出，但**不得**借此重开 EXP-0013 阶段显露生成器。

### 支持论据

1. **冻结先于数据**：`J_F=0`、`J_X=0.25`、`β=0.8`、`λ=0.7`、`T=16`、`E=四环`、`z∈{−1,+1}^4`、无外场，全部在任何资格样本前以数字固定（v3 §2），**不搜索耦合值**。
2. **仅耦合不同**：两条件的**边缘先验精确均匀**（机器核对：F、X 各维边缘均为 `0.5`，偏差 `<3e-16`）；变量、观测模型、长度、同步时点、状态字母表与先验族相同。核的平稳律在 `J>0` 时**不等于** `p_J`（实测最大偏差 `0.0596`），本请求**如实报告**该差异，不声称"完全匹配"。
3. **相对 EXP-0013 的四条差异轴**：(i) 潜过程由静态 `z` 改为时间演化 Markov 链；(ii) 主终点由末端性能/OOD headroom 改为学习曲线 `AUC_B`（＋终端非劣）；(iii) 估计对象由"候选对控制的性能差"改为 **K 剂量 × 耦合结构交互**（`I` 与 `I_flat`）；(iv) 不复用任何样本、权重、种子、阈值或 oracle。
4. **机制论证已给出**：`J=0` 时核精确按维分解，精确解是四条独立两状态时间递归（检查 B/C）；`J>0` 时联合后验与逐链边缘乘积的 TV 距离 `0.951`（检查 D），不可分解。
5. **机制论证的边界**：上述都是 **oracle 侧**事实，只说明两条件的最优计算在可分解性上不同。是否在有限预算训练中表现为学习效率差异，是本设计的**假设**，不是这些事实的推论；本请求不作"因此必然有效"的表述。

### 最强反驳（须正面处理）

决定0049 的封顶理由之一是"**连续更换合成任务本身也有选择偏差**"。G1-KSI 是 EXP-0012、EXP-0013 之后同一研究方向上的**第三次**合成任务替换；三者都是"K 个独立递归块 vs 资源匹配稀疏控制 + 合成后验任务"。若 0049 的封闭对象是**研究问题**而非生成器，则本请求应被拒绝，因为"多轨迹组织是否有益"这一宽问题自 EXP-0004 起未变。

### 判定规则与各结果的作用

| 判定 | 含义 | 改变什么 |
|---|---|---|
| `ACCEPT` | 同一生成器两条件 + 独立研究问题 | 该方向可继续走**项目轨**设计批评与数值协议（仍须独立资格校准与实际主控制余量） |
| `NARROW` | 认定为新生成器，但问题独立性不足 | 只允许作为 `independent_benchmark` 类**非项目轨**研究，不计项目 Gate 1 |
| `REJECT` | 认定为已关闭生成器的再参数化或同一问题 | 该方向在项目轨终止；设计可保留为独立 benchmark 记录 |

## 请求 B：学习效率能否作为 Gate 1 主终点

### 拟议裁定

Gate 1 允许把**有限预算学习效率**（`AUC_B`，配终端损失非劣 `τ_term`）作为主要行为终点类别，条件是：`δ_min` 在效果轮前由**八个单元（2 K × 2 条件 × 臂）的配对功效计算**预注册；且资格门展示的是该估计量的**余量与分辨力**，而不只是可学性。

### 支持论据

1. **规则从未禁止**：`research/open_questions.md` 的 TH-0001 条明示"另行注册的 K×模型学习效率交互在任务有根据、资源匹配、主控制有余量时逻辑上可测"；MON-0001/决定0009 明示不排除新注册的样本效率问题。TH-0001 只封闭"以 K 增加容量论证"。
2. **最终性能终点在本项目已四次不可用**：CAL-0001（0.0003–0.0005 nat）、CAL-0002（0.0018–0.0023）、CAL-0006（0.06497 < 0.08 失败线）、EXP-0009（C0 的 0.012463 对 0.07 余量下限）——匹配的稠密控制都达到精确后验，任务因此无余量。在学习效率终点下，"控制最终也能解出"是**必需 regime**，不是取消资格。
3. **不降低任何资源或控制标准**：状态、有效／分配参数、样本、更新、执行计算与**实测**时延的匹配规则全部不变；决定0044 的"控制不得被弱化"要求保留——实际主控制必须达到 ε（有意义的学习），否则不启动效果轮。
4. **不追认旧结果**：MON-0001 关闭的"用 EXP-0009 既有监控追认样本效率"路径**仍然关闭**；本裁定只适用于前瞻注册的新实验。
5. **主张类别受限**：只支持决定0043 允许的**有限预算组织／归纳偏置**效应；不支持状态容量、能力优势、普遍计算优势或候选语义。

### 最强反驳（须正面处理）

- (i) 效率终点比能力终点**更易满足**，可被"更快但收敛到更差平台"游戏 → 已加 `τ_term` 终端非劣条件，违反即判 `INCONCLUSIVE` 并报告权衡；
- (ii) 学习速度差可能来自**优化伪影**（学习率、初始化、batch 顺序）而非被操纵因素 → 已用配对种子、每臂预注册 LR、同 kernel 与交互设计（条件依赖的斜率差难以由伪影产生）；
- (iii) 效率效应可能**极小、注定不确定** → §5 不可行性前置声明：若可行种子数内 `δ_min` 处功效不足，判定设计不可行并停止，不得事后降低 `δ_min`。

### 判定规则与各结果的作用

| 判定 | 含义 | 改变什么 |
|---|---|---|
| `ACCEPT` | 可作为 Gate 1 主终点类别（须满足上述条件） | 数值协议可按效率终点冻结 `δ_min`、`τ_term` 与功效计算 |
| `NARROW` | 可作主终点但须附加条件（须写出条件） | 按附加条件重写终点与资格门后再送审 |
| `REJECT` | Gate 1 仍须以最终性能／能力终点判定 | 停止本设计在项目轨的推进，**不换终点救结果** |

## 禁止推论

两项裁定均不得被读作：实验许可、训练授权、Gate 1 或任何阶段门状态变化、候选有效性、先例新颖性、或对 EXP-0004/0009、CAL 系列、EXP-0011 v6、EXP-0012、EXP-0013 既有判词的追认。裁定结论不改变 `NOT_PASSED`，也不使 Gate 2 启动。
