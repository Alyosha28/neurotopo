# STR-0002：候选缺席时继续 Gate 1 难度筛查的决策价值低

2026-09-24。按事前提交 `79f07ed` 的协议，只读累计 CAL/EXP、阶段门与工作流。判 **`CANDIDATE_FIRST_FOR_GATE1`**，范围仅是“为了 Gate 1 找有余量任务而继续筛基准”的策略；不是禁止具有独立问题和预算的基准科学，也不是新的模型实验或四分类效果判定。

| 证据阶段 | 实际观察 | 对下一次筛查的含义 |
|---|---|---|
| EXP-0004 | 已有度/自环/状态/执行代理匹配、主控制在 OOD32 有余量的比较；四块 M3 比随机掩码低9.10百分点，注册预测在此任务上 FALSIFIED。但任务的四个绑定加晚期直接 selector 可由缓存/检索解，不要求候选解释。 | 仅寻找另一个“更难任务”不能补全 M3 的候选构念；当前结构没有候选身份、权重或路由。 |
| CAL-0001/0002 与 TH-0001 | 四/八个 log 权重足够作精确静态信念更新；H64 稠密 GRU 在1500步下 KL 约0.0003–0.0023。TH-0001 还证明等总 H 的单流和多流同受一般完整后验的维数约束。 | 加噪声、来源或 K 不自动产生有利于多轨迹的计算瓶颈；先要写任务级算法与归纳偏置预测。 |
| CAL-0003/0004 → EXP-0009 | 固定 d=1 训练的长干扰地板被匹配预算的可变 d=0/1/2 分布修复；但 CAL-0004 只校准了稠密背景臂。EXP-0009 实际主随机控制在唯一 d=4 主端点 KL0.012463，低于0.07余量门，故正式效应 INCONCLUSIVE。 | 任务资格必须针对**实际主匹配控制**和预定有用效应；背景模型的非封顶不能替代。 |
| CAL-0005/0006 | 固定 d=2 对照在同样样本/更新下无法匹配混合日程 token；随后动态四模式任务虽然有持续条件状态，但显式滤波只需至多8个二维状态数+4权重。CAL-0006 六单流中五个 OOD12 KL 在注册窗口，dense seed603 的0.06497<0.08使全臂资格 `CEILING`。其自然修订切片0.09819并非主端点。 | 一次事前固定的领域筛查有独立负信息；它仍不能证明某个未定义多轨迹候选有益，且再次出现近余量边界。不能据事后切片重写主问题。 |

这里有一个**我方策略造成的障碍**：先选择任务并训练单流，再问“哪种多轨迹候选可能受益”，使 CAL 的成功只表示某个预定基准有可用余量，却不能指定真正的主匹配控制、候选的状态/计算成本或相对 PF/RIM 的可证伪机制；失败则关闭该配置。CAL-0006 事前确有独立的领域筛查用途和明确停止分支，故不追认它为无效或违规；但把相同模式重复用作 Gate 1 搜索，会在没有候选干预的情况下累积任务选择自由度。

| 下一次**候选缺席**的 Gate 1 动机筛查若…… | 可直接改变的现行项目决定 | 研究价值边界 |
|---|---|---|
| 所有单流护栏通过，留下余量 | 仍没有 H3 更新规则、K 因子或实际匹配主控制；不能注册**项目 Gate 1**架构效应。 | 若事前另有独立领域目的，可通过它自己的 benchmark 资格；不自动解锁项目过门。 |
| 任一护栏失败 | 关闭该任务规格的资格；现有 M3 负/不可判别结果和项目 Gate 1 不变。 | 保留独立领域负信息，但不约束未定义的候选机制。 |
| 像 CAL-0006 一样靠近阈值 | 按原规则仍判失败；Gate 1 不变。 | 只引出条件不确定性和次级端点解释，不授权调阈值/长度。 |

因此没有一个分支能在**当前缺 H3 候选或参考 K 因子、缺真实主控制**的状态下改变**项目** Gate 1 或允许下一次正式架构比较；“为 Gate 1 再跑一个 CAL 寻找 headroom”低于先定义操纵因素及其对照的决策价值。已有 EXP-0004 的有余量结果还说明纯余量本身不是缺口；核心是构念和因果干预。下一次**以项目 Gate 1 为目的的任务资格训练前**，先写版本化 H3 候选更新或参考机制 K 因子、可消融预测、实际主控制、资源匹配及会改变决定的任务反事实；这一步本身是零训练设计，不要求参考机制先是 NeuroTopo 独有架构。若写不出，当前 H3 架构实现继续 NO-GO；不能通过任务扫描代替。

最强反驳仍成立：候选无关的任务/基准研究可以有独立价值。它只需在**自己的**事前协议里写独立用途、成本上限和成功/失败都影响的决定，不得标成 Gate 1 效应资格或作为后验模型选择。这个保护使 STR-0002 不是对所有合成基准、H3 一般命题或未来候选的禁令。CAL-0006 `CEILING`、EXP-0004 `FALSIFIED`、EXP-0009 `INCONCLUSIVE` 与 Gate 1 `NOT_PASSED` 均保留。

独立预决策批评（`docs/STR-0002_predecision_review.md`）纠正了初稿“只允许零训练”的过宽句子；最终规则只限**下一次以项目 Gate 1 为目的的任务资格训练**。主代理已把这一顺序写入 `research/decisions/0022_candidate_first_gate1_calibration.md`、`AGENTS.md`、`docs/experiment_protocol.md`、`docs/auto_research_workflow.md` 与 `research/program.md`：在新 CAL/EXP 选择任务前先有具名候选或参考 K 因素、实际主控制、可测消融及三分支决策表；独立领域基准仍有单独入口。没有更改 `ResearchLoop` 旧 EXP 账本或已冻结的旧任务规格。
