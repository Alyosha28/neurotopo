# 未解决的 prior-art 问题

这些是本轮仍缺少一手证据的事项。它们都不改变当前的窄化判断，也不代表项目被阻塞。

1. **BPU 官方实现与重复性。** arXiv 论文明确把 BPU 展开为 Biological Processing Unit，描述固定果蝇幼虫 recurrent core 和训练输入/输出投影；已读正文未见明确作者代码仓库链接。本轮没有独立确认仓库、数据下载入口、软件许可证、正式会议版本或可复现实验脚本。论文里 reported accuracy 仍是作者报告，没有被本项目验证。
2. **“假设修订”的最近邻任务。** conn2res 提供延迟比较/配对关联/匹配类别，TRNN 使用 ODPA/delayed choice，层级模块 reservoir 衡量延迟信号 memory capacity。尚未做跨领域穷尽检索，确认这些工作或其他序贯决策文献是否含有严格的相反证据、显式后验/假设轨迹和翻转行为的相同组合。
3. **训练与推理预算的既有匹配。** TRNN 报告参数数目相同，但本轮没有核对到其 FLOPs/训练步数/推理计算也严格相同。RIMs 的 top-k 活动路由与 CTM 的内部迭代说明只匹配参数不足以排除计算差异。主实验应自行报告并控制这几项。
4. **Grouped GRU 与 RIMs 的差距。** 主计划的 grouped GRU 为并行独立循环组 + 联合线性读出；它没有 RIMs 的输入 query 路由、top-k 模块选择、未激活模块状态保留和模块间注意力。新颖性文字不能把 grouped GRU 称为 RIMs 等价复现或语义机制。
5. **候选轨迹与粒子滤波的差距。** PF-RNN 作者论文与源码已确认带权粒子、随机更新和软重采样，是比 grouped GRU 更直接的多候选信念先例；尚未复现其任务数字，也未建立与 NeuroTopo 的状态/参数/重采样计算公平对照。未来若提出候选特异轨迹，须解释它相对 PF-GRU 的可测结构差异，不能只更换术语。
   `fixed_slot_hypothesis_retention.md` 又发现 PF-RNN 原论文报告 **PF-LSTM** `NoResample` 消融和整体粒子信念从错误位置恢复的示例；它们不证明同一低权重粒子存活，更不是本项目的晚到反证复现。Reid 多假设追踪会剪枝，Belief Net 的 HMM 隐状态会转移；“多解释与后续修订”是旧行为，**固定身份槽一直保留并恢复**的完整机制只见部分重叠。PF-GRU 无重采样若成为数值对照，需要另行实现和验证。
6. **连接组工作边界。** flyvis、BPU、Drosophila ESN 和 conn2res 使用的连接组、动态方程、可训练参数和任务均不同。本轮按各论文描述做了概念比较，不尝试统一重现或直接数值比较。
7. **代码状态与许可。** Transient、RIMs 和 ESA GitLab 仓库本轮未发现声明许可证；BPU 作者代码仓库未确认。已记录的提交哈希让审计可复查，但未安装项目或运行测试；仓库当前兼容性和后续提交状态可能变化。

## 本轮已明确

- 不声称完成穷尽式综述或新颖性证明。
- 不把源码读取当作论文复现，不把论文报告写成本项目实证结论。
