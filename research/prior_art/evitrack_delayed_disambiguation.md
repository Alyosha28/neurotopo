# EviTrack：延迟消歧的轨迹选择直接先例

2026-09-24 定向阅读 [Haq, *EviTrack: Selection over Sampling for Delayed Disambiguation*, arXiv:2605.19283v1](https://arxiv.org/html/2605.19283)。这是**作者预印本报告**；本项目未取得/运行作者代码、未复现数值，也未核到作者公开仓库。它直接覆盖“早期歧义时保留多个潜在轨迹，后续证据到来时选择而非盲目增加采样量”的行为主张，因此不能再把该链条本身表述为 NeuroTopo 的新颖点。

论文方法在测试时维护有分数的 `K` 条潜在路径，按已知转移模型为每路径产生 `C` 个延续，通过累积联合/证据等分数在每个父路径内部选一条，并可按计划做全局 top-K 剪枝。预测使用保留轨迹的分数加权混合。作者在双势阱延迟消歧合成任务中以相同推理候选预算比较 SIS 和 bootstrap PF，并报告消歧后的分支恢复/预测改善；消融涉及评分、剪枝频率、分支因子和粒子预算。论文明确实验使用**真实已知**世界模型的数量，学习到的提议/世界模型只是可扩展方向；这里没有显示与端到端训练的单流 GRU 在总状态、可训练参数和训练计算全部匹配下的效果。论文限制也承认合成真值任务、剪枝并非一致 Monte Carlo 估计，高维观测及 learned world model 尚待验证。

与 NeuroTopo 的重叠和边界：

- “潜在轨迹竞争、延迟承诺、证据打分、适度局部选择、跨轨迹筛选有时有害”都已有直接先例，且比仅有多个 GRU 块更接近可操作的假设维护。
- EviTrack 主要是固定世界模型上的**测试时推理算法**，不是训练出来的稀疏循环神经骨干、拓扑×动力学提取、适应/重组或自然序列能力证据。这个边界允许提出新问题，但不能以术语差异声称机制新颖。
- 若未来任务采用双势阱/延迟可辨观测，须将该论文任务视为已知基准，不得把复制它的样例当自创 benchmark。参考对照至少包括相同推理预算的 SIS、bootstrap PF 与 EviTrack 风格局部选择；若研究可训练 recurrent 表示，还须另有强单流/状态/参数/训练和推理计算对照。
- 作者论文结果不是 NeuroTopo 的实验观察；目前未确认实现许可和测试，不能直接宣称可复用代码。

这一发现不会追改 EXP-0004/0009 或 Gate 1 状态，但会改变后续设计的先例边界。仍可问“在学习到的循环动力学里，哪个可消融因素带来超过这些已知算法及强单流的受限收益”，答案必须来自新注册实验。

定向公式审查和事前 EVT-0001 零训练审计又发现一个**来源内部需核查的问题**：论文附录给出 `a=3,d=2`，稳定井±3位于 `|z|≤2` 的偶发射区外；正文相邻句却同时称吸引到井后仍留在 non-injective 区和“井在歧义区外”。按公布潜在转移采样的100,000条未筛选路径，第30步仅1条尚未**首次**离开 `|z|≤2`，与长期停留在该区的直觉不符。但这不是论文 `t_DD` 的后验阈值分布，也不能推算作者按消歧时间筛选30–170层的出现率；分段发射函数还存在全域值碰撞。详见 `research/evidence/EVT-0001_evitrack_region_exit.md`。因此这篇工作继续作为**行为与算法先例**，其具体生成器的任务资格需独立验证，不能未经核验拿来训练 NeuroTopo 或复述其自然迟消歧频率。
