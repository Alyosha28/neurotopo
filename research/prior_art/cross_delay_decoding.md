# Cross-delay decoding is established methodology

Scoped primary-source review, 2026-09-23. [Parthasarathy et al., Nature Communications 2019](https://www.nature.com/articles/s41467-019-12841-y) used cross-temporal population decoding to test whether a working-memory code could be read across delay epochs despite code morphing. [Piwek, Stokes & Summerfield, PLOS Computational Biology 2023](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1011555) trained decoders at one RNN hidden-activity timepoint and evaluated them at other task times; its fixed- versus variable-delay models were not a matched topology study. Thus training a fixed linear readout at one delay and testing another is prior art, not a NeuroTopo contribution.

EXP-0007 adapts that diagnostic to the **same frozen NeuroTopo checkpoints** with separate delay-8 and delay-32 fit sets and a shared new delay-32 test set. It asks whether an H64→4 linear mapping from pre-evidence state to the cued candidate's label transfers from the trained-delay range to a longer sequence. The prior paper's animal data, biological interpretation, code and numerical effects are not reused or treated as verified here.

A drop in cross-delay decoding can arise from mean/scale shift, representation rotation, nonlinear geometry, cue binding or the probe's fitting protocol. Train-only feature normalization is kept fixed when a delay-8 head is applied at delay32. The comparison does not identify a unique mechanism or prove that the model's original multi-output readout followed the same ridge solution. Hidden-state probes are observational; Gate1 remains closed.
