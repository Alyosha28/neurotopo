# DIR-0006 事前设计 v0：C8（图拓扑本身作为被操纵量）的可注册性审计

2026-09-25。**状态：设计稿，先于审计执行落盘并单独提交。** 本稿**不注册实验、不授权训练、不生成样本、不写也不运行任何图搜索器、不改变 Gate 1 `NOT_PASSED`、不重开非回归清单任何条目、不主张 H1/H2 被证实或否证**。

## 1. 为什么是这条线

DIR-0005 的两次独立审查都指出同一缺口（审查 I3/I7）：候选枚举里**没有任何一行以图拓扑本身为被操纵量**，而这是与本项目使命（topology × dynamics）最贴近的一类；且**限制型操纵**（对称/等变、权重共享、剪枝、把解限制在更小可达集内）被 v0 的 T1 遗漏——这类操纵的表征内容大而消耗不增，**通道可能是收益而非代价**。审计 v1 因此把 **C8（图拓扑本身为被操纵量）** 与 **C9（限制型结构约束）** 列为下一步优先取证方向。

仓库对 H1 已有明确边界：**H1 仍 `UNTESTED`**（`research/hypotheses.md`）；决定0004 关闭了"从 EXP-0004/0009 回溯宣称拓扑原则"的路径并要求重开先做三件事——**成熟 null 的可行性**、**宽范围独立操纵验证**、**主匹配对照余量校准 ＋ 版本化因果端点**；决定0014 判 `NO_GO_NOW`：**不写、不运行新的互反范围/谱联合搜索器，不安装 BCTpy**，且未来 H1 问题必须事前固定目标差异方向/幅度、每图样本与联合成功率、搜索预算、度/自环/cross/连通与谱/motif/路径的数值容差与失败处理；`research/design/h1_null_family_review_criteria.md` 已把上述固化为四条评审条件。

## 2. 问题

> 在**不写也不运行任何新图搜索器**的前提下，能否**指认一个具名的"仅图"操纵**（同单元、同动力学、同参数与执行计算，只改边集/连接分配），使它在**纸面上**同时满足：① 与原图族中代数混淆的性质（`Q = 0.75 − crossEdges/1024` 这一精确恒等式所绑定的固定分区 modularity 与跨块边）**可分离**；② `h1_null_family_review_criteria.md` 的四条可被满足；③ 有**可获得余量**的任务与**实际主匹配对照**；④ 机制内核在先例正文层**未被覆盖**？

若不能指认，缺的是**图族设计**、**任务/余量**、**新颖性**，还是**规则**？

## 4. 冻结的判定项（沿用 DIR-0005 v1 §5 的七条，逐项 PASS / FAIL / UNKNOWN）

N1 具名操纵与方向性预测；N2 余量实测（水平量，非解析量）与 `δ_min` 推导；N3 通道：界的类型/样本量/阈值，且须用**可达集之差**（限制型操纵预期 ≤0，即通道为收益）；N4 无架构基线（参考臂定义与求解方式）；N5 闸门功效（样本量/功效算法/MDD/阈值、监督不泄漏）；N6 统计完整性（多重性、选择零、有效自由度与配对结构）；N7 自缚通用谓词与全轴披露（并注明 `Generic` 未决使第三方不可核验）。

**标签规则（事前冻结）**：

- 四项问题全 PASS ⇒ `C8_CANDIDATE_SPECIFIABLE`：下一步是该操纵的完整事前设计 ＋ 独立前瞻审查（仍**不**注册、**不**训练）。
- ① ② 只能靠**先设计 null 图族**才能判定 ⇒ `C8_NEEDS_NULL_DESIGN_FIRST`：下一步是 null 图族设计评审（按四条条件逐条写死），而非直接设计任务。
- ④ 在正文层已被覆盖，或 ① 被证明在现图族内不可分离 ⇒ `C8_NO_GO_UNCHANGED`：H1 保持 `UNTESTED`，记录并停止本条线。
- 任何 `UNKNOWN` 不得读作 PASS；出现 UNKNOWN 即不得给 `C8_CANDIDATE_SPECIFIABLE`。

## 5. 我预判并必须主动检验的最强反驳

- **P1（决定0014 的改名重演）**：本审计就是已被判 `NO_GO_NOW` 的互反图搜索换个名字；决定0014 的决定性理由是"**没有可被此次搜索改变的当前可执行决定**"，而自那以来**没有出现新证据**，故正确答案应为"结论不变"。**检验**：必须逐字对齐决定0014 的三条重开要求，指出**新出现了什么**（若有）；若答不出"新什么"，标签必须是 `C8_NO_GO_UNCHANGED`。
- **P2（把"限制型"当免罪符）**：C9/C8 借"限制型操纵通道为收益"绕开 K3，但**收益本身也需要界**（更小可达集不等于更好的任务表现），否则只是把未测的通道从一侧换到另一侧。**检验**：N3 必须给出**方向可判**的界（含单侧置信上界与其样本量），不能只写"预期 ≤0"。
- **P3（纯纸面审计无信息）**：不写搜索器的约束使本审计只能做纸面判断，可能产出"无法判定"。**检验**：必须给出**可判定的最小判据**（例如：存在保度/自环/cross/连通的一次交换同时满足谱容差与目标差异，且其可达幅度 ≥ 预注册阈值——并说明该判定为何无需新搜索器即可完成，或明确写"需要搜索器 ⇒ 属 null 族设计评审"）。
