# ARCH-0001 v4：任务通用反事实分支监督的关系状态核心（A0 候选合同修订）

2026-09-29。状态：`A0_CONTRACT_FROZEN / DESIGN_ONLY`。本版取代 v3 作为当前候选合同；v1–v3 及其反思包全部保留。v3→v4 只改**训练期的分支监督定义**，推理路径、状态、读出、编码器、修正器结构、幅度上限与资源口径逐项不变。

## 与 v3 的差异（唯一改动）

v3 把反事实分支监督写死为一比特任务的标签 `q_t xor v`。v4 改为由任务提供反事实下一目标数组 `branch_targets[:,r,v]` 与掩码 `branch_mask[:,r]`：

- `L_branch = mean_{mask}( BCE( r(Tφ(H_r, v)), branch_targets[:,r,v] ) )`，对 `v∈{HOLD,FLIP}` 与所有被掩码选中的读出索引 `r` 取均值；
- 掩码用于排除没有"下一步"语义的末端索引（v3 的末位复制 `y_T` 缺陷由此修正）；
- 训练时同时报告分支一致性指标（`branch_joint_accuracy`），并要求它在 A2 协议中预先注册阈值，而不是只报实际序列准确率。

当任务取一比特命令响应任务（`branch_targets[:,r,v] = q_r xor v`、掩码覆盖 r=0..T）且末端标签按同一规则定义时，v4 与 v3 的损失逐项相同；这不是等价性声明，而是该退化情形下的构造说明。v4 的推理路径与 v3 完全相同（真实命令转移 + 两个假设命令试算 + 有界修正），因此候选推理算子量不变（1161 MAC/步，按 A0 合同口径）。
