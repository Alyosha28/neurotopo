# DIR-0003 新问题事前设计 v0：总容量匹配下的时间尺度组织（`independent_benchmark` 轨）

2026-09-24。**状态：设计稿（未注册、未训练、未进入 live loop、无 Gate 1 主张）。** 本稿是本轮"从新问题的事前设计起步"的落地产物；其可转移设计装置来自 `research/prior_art/dir0003_A..G` 的真实取回来源（证据综合见 `research/evidence/DIR-0003_field_methods_synthesis.md`）。

## 1. 新问题

> **在循环核的总记忆容量被构造性匹配（同状态维数、同输入耦合、同读出族，且总体记忆容量比值 = 1）的条件下，任务表现是由"该任务所需延迟带上的容量分布"决定，还是由总容量决定？**

即：**容量分布是不是一个比总容量更好的能力预测子？** 若是，两支核的表现曲线应在**事前可算的交叉位置** `k*` 处换号；若否（总容量模型），两支在全部任务上应**等价**。

**为什么它的否定有信息**（对应 `research/prior_art/dir0003_A_comparison_methodology.md` 对"任务电池"的要求）：否定不是"某结构没用"，而是**"总容量是充分统计量、分布不含额外信息"**——这是一条可被 TOST 正面确认的命题，不是又一条 `INCONCLUSIVE`。它同时直接回应文献里未解决的张力：`dir0003_G` 记录 Milisav 2026（层级模块 tanh 核占优）与 Rodriguez 2019（tanh 下模块化**降低**记忆容量）给出**相反符号**，且该领域自己没有归一化对照。

## 4. 系统与任务规格

**核（冻结，不训练）**：线性泄漏积分器库 `x_t = diag(λ) x_{t-1} + b u_t`，`N = 64`，输入 `b_i = ±1/√N`（固定种子 `20260924`），`λ_i` 为**对数均匀**的 64 个互异衰减（互异是必要的：完全相同的衰减使单元完全冗余、协方差奇异——本轮预检首先撞到这一点，已作为设计约束记录）。

**读出（凸）**：岭回归，相对岭 `γ_rel = 0.01`（乘以 Gram 对角均值，尺度自适应、可事前冻结）。留出评估（训练/测试流分离）。

**任务族（剂量 = 所需延迟 `k`）**：输入为 **AR(1)**（与容量探针的 i.i.d. 输入**不同**，这正是"转移"维度）；目标 `y_t = u_{t−k}`，`k ∈ {1,2,4,8,16,24,32,48}` 事前冻结；另加 `T_mix: y_t = (u_{t−2} + u_{t−24})/√2`（双侧混合，检验不是单点巧合）与 `T_null`（目标独立于历史）。

**终点**：留出 `R²`（= 1 − 归一化 oracle 相对 MSE；条件均值即 oracle）。**本设计刻意不使用学习效率类终点**，故不触碰决定0062 B 的未决问题。

- **可事前冻结的形状预测**：`k*` 随带宽**单调下降**（21.97 → 17.48 → 12.08 → 7.49），且每一 rung 的总容量相同。这是一条**多点结构预测**，不是水平预测。
- **结构事实（本轮预检的主要发现）**：在岭读出下，固定带宽时总容量对中心**单调**（中心扫描见 JSON 的 `narrow_band_centre_scan`，`0.30→0.42`、`0.62→1.03`、`0.87→1.94`；靠近退化边界的 `0.9999` 掉到 `0.027`）。因此在**总容量固定**的约束下，"带中心"不可自由选择，**唯一可操作的操纵量是带宽**；等价地说，带宽以短延迟容量**换**长延迟容量。
- **自检（必须与预测数字分开读）**：单模闭式恒等式 `λ²(1−λ^80) = 0.85862229` 与实现一致（相对误差 `<1e-12`）；岭化后单模解析总容量 `0.85012` 对**留出**模拟 `0.86140`（差 `0.0113`）；64 维库在 `k ≤ 40` 上解析对**留出**模拟的最大绝对差 `0.00304`。自检检验的是**被冻结的同一泛函**（同 γ、留出评估），不是样本内拟合。
- **如实记录的能力不对称**：窄带侧（短延迟）预测差 `0.21–0.52`（大）；宽带侧（长延迟）预测差仅 `0.0092–0.0143`（小）。故**长延迟侧只作符号/位置预测，不作量级主张**（见 §6 与 §9）。

## 6. 主终点、估计量与判决函数（事前冻结，互斥穷尽）

- **主终点**：由留出任务曲线估计的**交叉位置 `k̂*`** 与**符号模式**（`k ≤ 8` 窄带优；`k ≥ 24` 宽带优）。
- **判决函数**（`δ_task = 0.05` 仅用于**短延迟侧**量级主张；位置容差 `±2` lag；等价界 `Δ_eq = 0.02`）：
  1. `SUPPORTED_BAND_MODEL`：符号模式成立 **且** `k̂* ∈ [k*−2, k*+2]` **且** `T_null` 等价通过。
  2. `PARTIALLY_SUPPORTED`：符号模式成立但 `k̂*` 落在带外（报告实测 `k̂*` 与两侧差）。
  3. `FALSIFIED_BAND_MODEL`：无交叉，或符号模式相反。
  4. `EQUIVALENT_TOTAL_CAPACITY`：全部 `k` 档上两支的 TOST 等价（`CI ⊂ (−Δ_eq, +Δ_eq)`）→ **正面判词**：总容量是充分统计量，分布不含额外信息。
  5. `INCONCLUSIVE_UNDERPOWERED`：由**事前条件机械触发**（三选一）：① 长延迟侧 `MDD > 0.014`（预检给的上界）；② `T_null` 上任一臂 `R² > δ_null = 0.01`（读出泄漏）；③ 任一臂读出 Gram 条件数 `> 1e8`（数值不可信）。
- **可达性自检**：五分支各有触发路径；`PARTIALLY_SUPPORTED` 与 `SUPPORTED` 由位置容差区分，`EQUIVALENT` 与 `FALSIFIED` 由符号模式区分，无空分支。

## 8. 阴性对照与选择性

- `T_null`（目标与历史独立）：真值 `R² = 0`；两支都须落在 `±δ_null` 且**相互等价**。它同时充当 F-11 的 control task 与 F-01 的负对照结局。
- **旋转 rung**（同谱、随机特征向量、`total = 1.4940` 未匹配）：只作**诊断**，回答"容量曲线由谱决定还是由输入—特征向量对齐决定"。本轮预检已给出答案的方向：同谱不同对齐的 `k*` 为 `38.0`，与宽带的曲线不同 → **谱不是充分描述**；该 rung 因非零元数与总容量均未匹配，**不得进入主判词**。

## 9. 功效与 MDE（事前计算，不做事后调整）

- **符号模式**：离散预测，用二项符号检验；`n_streams = 8` 独立评估流下，若真实符号如前，拒绝"随机符号"的 p 上界由二项分布给出（`p = 2·2^-8 = 0.0078`）。
- **短延迟侧量级**：预测差 `0.25`，单流留出 `R²` 的 SE 约 `0.005`（20,000 留出样本量级）→ `MDD(0.8, n=8) ≈ 0.006 ≪ 0.05`，功效充分。
- **长延迟侧**：预测差 `0.0142`，`n = 8` 时 `MDD ≈ 0.006 < 0.0142` → 足以判符号，**不足以**支撑量级主张（如实记录）。
- **等价分支（TOST）**：要求在 `Δ_eq = 0.02` 处有功效；若资格阶段实测 `MDD(Δ_eq) > 0.02`，按 §6 分支 5 机械触发 `INCONCLUSIVE_UNDERPOWERED` 并关闭该配置，**禁止事后放宽 `Δ_eq`**。

## 10. 停止条件（注册前与注册后均适用，仿 0072 的 S1–S5 式自检）

- **S1 可行性**：解析预检须给出**存在交叉**且短延迟侧差 `≥ δ_task`；`spread = 2.00` 即因总容量失配被排除（本轮已实测）→ **通过（rung ≤ 1.40）**。
- **S2 分辨率**：资格阶段实测 `MDD(Δ_eq) ≤ 0.02` 且长延迟侧 `MDD ≤ 0.0142` → 若否，走 `INCONCLUSIVE_UNDERPOWERED`，不放宽界。
- **S3 读数有效性**：`T_null` 等价通过；否则读数通道泄漏，判词作废。
- **S4 数值有效性**：Gram 条件数 `< 1e8`；否则判词作废（本轮预检已暴露退化边界的存在）。
- **S5 分支穷尽**：§6 五分支互斥且各有触发路径（本稿已自检）。
- **S6 任务非同一性**：任务输入分布（AR(1)）必须与容量探针输入（i.i.d.）**不同**，否则"容量预测任务"是同义反复 → 预注册为强制条款。

## 12. 未决规则问题（不阻塞本轨，但必须留档）

3. **`R²` 与项目 `oracle-relative KL` 口径的关系**：本设计用 `R²`（= 1 − 归一化 MSE）。连续目标下 `KL` 依赖噪声模型，`R²` 是其单调对应物；若未来纳入项目轨，须在同一注册内固定口径换算。

## 13. 最强拒绝与已知限制

- **最强拒绝**："这只是把记忆容量测了两遍"（同义反复）。**回应**：S6 强制任务输入分布与探针不同，且预测的是**交叉位置与单调形状**；若容量曲线不能预测另一个输入分布下的任务排序，该拒绝**成立**，判词即为 `FALSIFIED_BAND_MODEL`。这是本设计**接受**的风险，不是被排除的风险。
- **第二拒绝**："冻结核 + 凸读出没有学习，因此不是能力证据。"**接受**：本轨**不主张**能力或 Gate 1；它定位在因果链的 **Representation** 环节，是"训练版问题"的前置识别步骤。
- **第三拒绝**："旋转 rung 资源未匹配。"**已处置**：该 rung 只作诊断，不进入主判词（§8）。
- **文献层限制**：总容量守恒（Dambre 2012）与记忆函数均为**作者报告**，本轮未复现其代码；Milisav 2026 与 Rodriguez 2019 的张力本轮未做归一化对照。
- **数值层限制**：一切解析数字都依赖冻结的 `λ`、`b`、`γ_rel`、`N`、`k_max`；改任一常数即为新版本。
