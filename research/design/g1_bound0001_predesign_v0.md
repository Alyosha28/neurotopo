# G1-BOUND-0001 事前设计 v0（**未注册、未过审、不构成协议**）

2026-09-24。承接决定0072 §5 与容量通道扫描（`g1_align0001_channel_sweep_note.md`）。**不是预注册、不是协议，不得据此注册实验或启动训练。** 不改变 Gate 1 `NOT_PASSED`，不追认任何既有判词，不重开 GPI-0001 或 G1-ALIGN-0001。

## 0. 为什么换问题：从"对齐有益"到"训练能否兑现表示界"

G1-ALIGN-0001 被停止的核心原因是**容量通道与 `δ_min` 同量级**（`0.0388 [0.0285, 0.0508]` 对 `0.05`），且门槛估计量错位。容量扫描给出两条事实：

1. **在中等跨组耦合处 `Δ(c) ≈ 0`**（`c=4`：`+0.0020 [−0.0006, 0.0054]`；`c=5`：`+0.0003 [−0.0013, 0.0021]`）；
2. **两条件都仍非局部**（`gap(16)`：`c=4` 为 `0.4132 [0.3143, 0.5267]`、`c=5` 为 `0.4428 [0.3628, 0.5327]`，区间下界均 `≥ 0.20`）。

**关键**：`Δ` 是**最优可达 KL 的臂间差**（在该结构族内）。写成加法形式

```text
β_trained = KL_trained,U − KL_trained,S = Δ + (e_U − e_S),    e ≥ 0 为各臂的训练超出量
```

当 `Δ ≈ 0` 时，`β_trained > 0` **只能**来自 `e_U > e_S`——即**训练把对齐臂带得更接近它自己的界**。这**不是**替代解释：两臂**只在对齐上不同**，"跨组路由更难优化"与"对齐有帮助"是同一事实的两种说法。

**故本设计的问题（非重言、不依赖可加性假设）**：

> **在表示容量几乎无差别的条件下，训练能否兑现对齐臂的表示界？**

## 1. 冻结条件对与划分

**条件对 `(c=4, c=5)`**（**事前固定**，不得在看到训练结果后更换）：

| 条件 | 边集 | 度序列 | `Δ` | `Δ` 的 95% CI | `gap(16)` |
|---|---|---|---|---|---|
| `c=4` | 2 条组内 + 4 条跨组 | `[1,1,1,2,3,4]` | `+0.0020` | `[−0.0006, 0.0054]` | `0.4132 [0.3143, 0.5267]` |
| `c=5` | 1 条组内 + 5 条跨组 | `[0,1,2,2,3,4]` | `+0.0003` | `[−0.0013, 0.0021]` | `0.4428 [0.3628, 0.5327]` |

**冻结的容量上界**：`C_ub = 0.0064`（配对保守上界，`|成分| + 两条件 Δ 区间半宽之和`）。

划分（与 G1-ALIGN-0001 一致，逐字节冻结）：对齐 `(01)(2)(34)(5)`、跨组 `(05)(23)(4)(1)`。

**条件侧的必须披露**：两条件的**图不同**（度序列不同），故**不再是"同一图只改边位置"**。这是本设计的**主要代价**，须在注册与判词中逐条披露；`c=4` 与 `c=5` 之间的对比**不得**被表述为"仅耦合不同"。

## 2. 两臂与声明消耗轴

两臂共用**同一块对角循环矩阵**（块大小序列相同、块索引随臂置换，见 `g1_align0001_block_load_note.md`），**只有输入路由不同**。

**`G1-MATCH-v3` 声明**：**本候选不消耗任何轴**；全部实测比值须为 `1.000`，注册须附 `repeats ≥ 101` 的全轴比值表与收敛序列、以及**元素级前向/反向计数**（G1-ALIGN-0001 的 pilot 已落地该计数，可直接复用其脚本）。

**条件侧失配披露**：`c=4` 与 `c=5` 的**度序列与边集不同**，属**任务侧**差异，**不随臂操纵变化**，故在同条件内的臂对比 `β` 中消掉；但**禁止**把条件间差异读作机制收益。

## 3. 主终点（单一、不依赖可加性）

**主条件 `c=4`**（`Δ` 的点估计最大者，取**保守**选择），**主终点**：

```text
β = KL_U − KL_S          末端配对 KL 差（逐 seed 配对，末端检查点）
SUPPORTED  ⟺  β 的 95% CI 下界 > C_ub = 0.0064
```

**`c=5` 为独立复核条件**（同一终点、同一门槛），须**同向**。

**不使用**任何常数扣除；**禁止**"超出容量"措辞。`C_ub` 是**披露上界**，不是扣除项。

**解释（预注册，须写入判词）**：由 `β = Δ + (e_U − e_S)` 且 `Δ ≤ 0.0064`，`β` 的 CI 下界 `> 0.0064` 蕴含 **`e_U − e_S > 0`**——**跨组路由的训练超出量大于对齐路由**。判词**只**可表述为这一句。

## 4. 结构族限定检查（**新增，且是 S4 的兑现**）

`C_ub` 只有在**两臂都被限定在"给定 θ 的条件独立块分解"族内**时才是有效界。该限定**不由设计断言，须由数据检验**：

> **限定检查**：若任一臂任一条件下出现 `KL_trained < 该臂该条件的投影代价`，则模型**不在**该族内，`C_ub` 的解释失效 → 判 `INCONCLUSIVE`。

投影代价按臂按条件在**同一 episode 流**上计算（脚本 `scripts/align0001_analytic_decomposition.py` 的 `factored_kl`），并与训练评估用**同一批 episode**。

## 5. 资格门

复用 CAL-0008 加固版（`ε_abs`、`ρ`、`κ`、平台门、跨 LR 一致门、逐 seed 聚合、`INCONCLUSIVE` 原因码、`C1` 锚点、对称坍缩停止项）+ G1-ALIGN-0001 v2 §8 中**未被决定0072 作废**的门：

1. **预算加倍门**：`B` 与 `2B` 下末端 KL 都须 > `ε_abs`。
2. **非局部性门**：**两条件**的 `gap(16)` 区间下界均 `≥ 0.20`（已满足），且 `gap(k)` 曲线须覆盖到 **`k = T = 64`**（**G1-ALIGN-0001 的缺口，本设计须补算**）。
3. **全轴比值门**：`1.000 ± 0.02`，时延须 `repeats ≥ 101`。
4. **块交换性门**：两臂块初始化逐块 i.i.d.、不依赖块索引（见 `g1_align0001_block_load_note.md`）。
5. **限定检查门**（§4）。
6. **容量上界冻结门**：`C_ub` 在任何资格样本前冻结；资格流复算若**升高**，门槛随之升高（保守方向），**不得**降低；该规则**与其在 `δ_min` 处的功效一并预注册**（G1-ALIGN-0001 的 §7/§8.6 冲突在此修正）。

## 6. 估计量与判词分支（**穷尽**，修正 G1-ALIGN-0001 §9 的缺陷）

| 项 | 值 |
|---|---|
| 统计量 | 逐 seed 配对 `β_i = (KL_U − KL_S)`，取均值；双侧 95% **t** 区间，`df = n−1` |
| `n` | **8 seeds/条件**（`c=4` 主、`c=5` 复核） |
| `alpha` | `0.05` 双侧 |
| `δ_min` | `0.05` nat（锚定项目既有 `ε_abs`） |
| sd 出处 | GPI-0001 pilot 逐 seed sd `0.0211`（3 seeds），**预先作 `√2` 放大**为 `0.0298`，声明按**臂差**使用 |
| MDD 约定 | `MDD = (t_{0.975,n−1} + t_{0.80,n−1}) · sd/√n`；`n=8` 时 `0.0344` |
| 升级规则 | 若资格流实测逐 seed sd `> 0.0441`，**允许一次**预注册升到 `n=16`；仍不满足 → `INCONCLUSIVE`。**不得**事后下调 `δ_min` |
| 协变量 | **本设计不设协变量**（G1-ALIGN-0001 的逐 seed 协变量欠定，且 `Δ≈0` 后难度调节的解释力下降）；难度差按 §1 表**披露**而非调整 |

| 分支 | 条件 |
|---|---|
| `SUPPORTED` | `c=4` 的 `β` 95% CI **下界 > `0.0064`**，**且** `c=5` 同向（点估计 > 0），**且**限定检查通过，**且**全部资格门与操作 guard 通过，**且**独立复核 seed 同向 |
| `PARTIALLY_SUPPORTED` | `β` CI 下界 > 0 但未超过 `C_ub`，**或**仅 `c=4` 成立而 `c=5` 不成立 |
| `UNATTRIBUTABLE_POSITIVE`（**新增**） | `β` 点估计 > 0 但 CI 跨零——**不作正面判词**，不得被引用为支持 |
| `FALSIFIED` | `β` 的 CI **上界 < 0** |
| `INCONCLUSIVE` | 任一资格门失败、限定检查失败、`τ_term` 违反、`MDD > δ_min` 且 `n=16` 仍不足、或对称坍缩停止项触发 |
| `NULL_AND_UNINFORMATIVE`（**新增**） | 全部门通过且 `β` 的 CI 含 0 且**区间完全落在 `[−MDD, +MDD]` 内**——记录为**该 n 下不可分辨**，不判 `FALSIFIED` |

**分支穷尽性自检**：对 `β` 点估计 ∈ {负, 零, 正} × CI ∈ {全负, 跨零, 全正} 的 9 种组合，逐一映射到上表（跨零且点估计 ≤ 0 → `NULL_AND_UNINFORMATIVE` 或 `INCONCLUSIVE`；跨零且点估计 > 0 → `UNATTRIBUTABLE_POSITIVE`；全正且下界 > `C_ub` → `SUPPORTED`；全正且下界 ≤ `C_ub` → `PARTIALLY_SUPPORTED`；全负 → `FALSIFIED`）。**该自检须在任何样本前完成并写入注册。**

## 8. 最强拒绝

**主拒绝**：`Δ ≈ 0` 是**解析**结果；若真实的最优可达差远大于 `0.0064`（例如模型不在该结构族内），则 `C_ub` 无效。**处置**：§4 的限定检查直接检验该前提，失败即 `INCONCLUSIVE`。

**次级拒绝**：两条件图不同（度序列不同），条件间对比不可解释。**处置**：主终点是**同条件内**的臂差 `β`，条件间只作**同向性**复核；条件差异按 §1 披露。

**三级拒绝**：`β > 0` 也可能来自**随机优化路径**而非对齐。**处置**：`n=8` 逐 seed 配对 + 独立复核 seed 同向；且两臂共用矩阵、同初值分布、同数据、同优化器，**唯一差异是路由**。
