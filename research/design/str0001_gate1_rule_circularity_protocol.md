# STR-0001：Gate 1 规则是否把通用效应与项目独有贡献锁成循环

2026-09-24，在作任何规则修订或新模型实验前固定。本任务只判断现行项目 Gate 1 是否比用户原始章程多设了“先有相对 PF/RIM 的独有预测”的前置条件，以致已知多轨迹参考机制即使经过本地、资源匹配、可证伪的因子实验，也只能停在领域证据轨，不能回答项目的第一个正式研究问题。审计的是**研究策略的因果障碍**，不是 PF/RIM 效果、H3 新颖性或 Gate 1 通过。

输入范围：`research/design/gate1_user_charter_evidence.md` 所摘用户 §2/9/20/21/34/40；`research/stage_gates.md`；决定0005、0006、0010–0013、0017；`research/program.md`；当前 EXP-0004/0009、CAL-0001/0002/0004 的冻结结论和 `research/design/h3_candidate_trajectory_contract.md`。检查当前限制是否为用户直接要求、从章程合理推论，还是项目后加规则；分开“整套先例架构包的任务效果”“被操纵的多轨迹因素因果效果”“NeuroTopo 独有增量”“竞争假设的功能专化”四个估计对象。只读审计，不运行模型，不重命名既有结果。

最强反驳：取消独有机制前置门会把一个已知 PF/RIM 的胜利当成 NeuroTopo 成功，继而未经证明解锁适应、通信、生物拓扑；而 PF-GRU 对 GRU 的整套模型差异并不隔离轨迹数。另一个反驳是当前实际障碍主要是**没有已资格、非封顶的任务与公平实现**，治理修订本身不能解决；如果不能指明下一项可执行资格工作，修订只是文字游戏。

判定规则：若用户章程 §34/40 明确要求通用效应而未要求此时有项目独有机制，且现行规则确使严格本地、事前登记的轨迹因素实验也无法满足 Gate 1，则判 `PROJECT_RULE_OVERCONSTRAINED`；只允许**前瞻版本化** Gate 1 证据资格：被测因素、参考/新模型归属、K 与等总状态/参数/执行计算消融、真实主对照 oracle-relative 余量、训练/推理预算、效应阈值和失败规则事前冻结；先例架构包效果单独标注，绝不以论文结果、单次 smoke test 或任务选优过门。项目独有增量和语义专化继续分轨，不因 Gate 1 自动成立。若 §34/40 可证明要求先有 NeuroTopo 独有机制，或新规则不能避免先例洗白，则判 `KEEP_CURRENT_RULE`。若文本关系或实施方案仍不足以决断，则判 `INCONCLUSIVE`，保持现行门。

无论标签如何，本任务不把既有 EXP/CAL 追认为正效应，不修改本轮前已冻结的阈值，不把 H3-SLOT 的 NO_SPEC 改为合格，也不把某个 PF/RIM 参考模型的可能优势称为 NeuroTopo 贡献。须提出能改变后续行动的具体资格入口或解释为何目前无入口；任务完成后以 design/action packet 进行全新上下文反思并逐条 react。
