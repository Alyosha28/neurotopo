# STR-0002：CAL-0006 后，继续“先找不封顶任务”的决策价值

2026-09-24，在查验累计校准记录并更改工作流前固定。唯一问题：**没有一个新版本 H3/参考机制的可消融预测和实际主匹配控制时，再做 Gate 1 动机的基准难度筛查，其成功或失败能否改变当前可执行的科学决定？** 本任务审计的是我方研究策略，不训练、不创建任务、不修改旧实验判词；不将“信息增益”伪装成有先验分布的数值期望。

输入范围：用户原始 Gate 1/§40 与阶段门；`research/decisions/0002_gate1_benchmark_strategy.md`、0003、0005–0007、0013、0017、0020、0021；`research/design/h3_candidate_trajectory_contract.md`；CAL-0001–0006 的冻结设计/结果/负结果与 EXP-0004/0009 的主结论；`docs/experiment_protocol.md`、`docs/auto_research_workflow.md` 和当前 `ResearchLoop` 状态。逐项区分“任务有效”“强单流有余量”“某个真实主匹配控制有余量”“已定义候选有资源匹配效应”四层。对下一次**候选缺席**的筛查，明确写出它成功、失败、边界结果分别会改变什么决定；再与写候选合同、检查已有有余量的 EXP-0004 任务、或关闭当前代理这几个可行动作比较。

最强反驳：独立领域基准研究可能有自身价值，即便不解锁 NeuroTopo Gate 1；CAL-0006 已明确为领域筛查，不能因为正式失败就事后把其设计定成“不应该运行”。此外当前任务是否“小充分状态”不证明 GRU 对所有动态任务都容易学习，也不证明多轨迹一般无益。审计必须把**未来为了 Gate 1 继续调任务**与具有独立科学问题、独立预算和用途的 benchmark 工作区分；不得把低决策价值升级为所有新任务或 H3 的否证。

判定：若候选缺席时一次新筛查的成功只允许继续写尚未存在的候选设计、失败只关闭该任务、边界结果只触发阈值/任务争议，而没有任何现有项目决定可被其改变，标 `CANDIDATE_FIRST_FOR_GATE1`；把今后 Gate 1 动机的校准入口改为先有候选更新/先例边界/独有或领域因子预测、实际主控制与会改变决定的反事实，随后才冻结任务和资格阈值。若能指出一个候选无关且成功/失败都改变已列项目决定的独立问题，标 `INDEPENDENT_SCREEN_JUSTIFIED`，只准其按单独目的、资源上限和判定运行。若输入不足以区分，标 `INCONCLUSIVE`，不改现行入口。

任何标签都不追认 CAL-0006 为无效、改其 `CEILING`、重开 EXP-0009 或 Gate 1，不用此审计许可适应、通信、生物图或 LM。先行设计必须经独立科学批评；完成后仍按 design/action packet 交给全新上下文反思，主代理逐项核验并作出**实际**工作流修订或说明为什么不修订。
