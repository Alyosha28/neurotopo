# CAL-0003 — 固定信念问题的延迟迁移校准

2026-09-24。CAL-0001/0002 在原分布上被强单流 GRU 学到接近解析后验。这里检验一个**不同且明确的计算问题**：已学会联合信念更新后，增加无关输入的持续时间是否破坏最终信念读出。它测的是干扰/时间外推，不是通过继续增加隐藏变量来搜索架构优势；CAL-0002 的 `H×R` 分布、八条有效证据、可靠度、训练预算与目标均保持不变。只训练常规单流 GRU，不运行 M3 或 C0；这是工程校准，不是 Gate 1 实验。

先行研究：`research/prior_art/belief_update_benchmarks.md`；TRNN 延迟记忆、conn2res 的 topology×dynamics 和原 EXP-0004 的长延迟分块/随机比较记录在 `research/prior_art/evidence_matrix.md`。最强反驳：若性能下降，仅凭这一比较不能区分额外 recurrent 步数、随机干扰负载和训练分布外长度，也不能证明竞争假设轨迹。后续正式实验须在各架构相同输入步数、状态、有效参数和实际 dense 执行量下比较，并以相同长度的控制变体分析这些混杂。

## 冻结校准

- 使用 `source_belief_task.py` 的原生成过程。每个有效证据后插入 `d∈{1,4,8,16}` 个带标记的随机干扰；`d=1` 是训练分布。给定同一 RNG seed，所有 d 的 `H,R`、有效 cue/source、早末解析联合后验完全相同，只有干扰数与序列长度改变。验证这个逐元素配对不变量。
- 三个新模型种子 301–303；训练流 `391000+seed`，仍为 dense GRU H64、batch128、Adam0.003、梯度裁剪1、1500 updates、每条有效证据后 1 个随机干扰、早末联合后验 soft-target loss。无早停或 best-checkpoint 选择。监测流 `392001`，评估流 `393001`，各 d 使用同一评估 seed；均与 CAL-0001/0002 及后续正式实验不重用。
- 在每个 d 上报告解析 oracle、最后 cue/固定来源快捷解、早末联合后验 KL、oracle MAP 一致率、H/R/joint 真值正确率、每个模型种子、训练/推理时长及参数/状态/运算账户。报告相对 d=1 的配对 KL 变化。将训练后的模型权重及 SHA-256 保留为工程复核材料，不从评估集挑选检查点。
- 只按强单流模型的结果选**最小**的合格 OOD d：三个种子的 d=1 最终 KL 都低于0.01，候选 d∈{4,8,16} 的每个种子最终 KL 都在[0.01,0.20] nat、早期 KL≤0.20、最终 joint oracle MAP 一致率≥0.70。若没有候选，记为未合格，不运行多轨迹比较。这个选择只用于后续独立预注册协议的难度校准，不能作为本轮结构效应。

无论是否合格，都保存全部 d 的结果。若正式比较被允许，必须使用全新种子与测试流、固定所有已选难度，并把最终 IID 准确率、OOD KL、速度/参数成本、干扰与纯时间控制分别报告；不能从多个 d 中事后选对 M3 有利的一项。CAL-0001/0002 和 EXP-0004 的结果与判定不变。
