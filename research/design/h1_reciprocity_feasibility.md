# H1 图因子可行性：在固定跨块数下能否改变互反边

2026-09-24。H1/H2 现存图审计证明在 H64、四个等大原组、每点入/出度16、自环64、总边数1,024下，原分组 modularity 与跨块边数满足 `Q=0.75−cross/1024`，不可独立操纵。新的**图空间存在性问题**是：能否保持节点、逐点入/出度、自环、跨原块边数（因而 Q）和强连通性不变，只经合法有向双边交换使去自环互反边比例改变？这不训练模型、不评价任务、不生成用于科学主比较的 null ensemble。

固定输入为 EXP-0009 的十个 C0 图种子9401–9410，逐 seed 由冻结图生成器重建并核对正式 mask SHA。每图仅查看一次现存图，候选交换来自独立 RNG seed `505000+seed`，最多100,000 次尝试；不更换或筛除种子。合法交换保持两个接收节点和两个发送节点各自的度，禁止自环、重复边，且交换后跨原四块边数相同并保持强连通。遇到第一项合法且使互反边数量变化的交换即停；记录原/新边、尝试次数、图哈希、所有约束、互反比例与第二大绝对特征值。若某 seed 未找到，仅记录有限搜索失败，不推断数学不可能。

成功的含义最多是：在这些冻结 C0 图附近，互反结构与跨块边/固定 Q **可由至少一个具体图变换分开**。它不证明谱混合、motif、路径等其他结构也匹配；该搜索不是均匀或成熟 null 模型，不可直接用于任务性能/生物拓扑结论。正式 H1 实验仍需先评估 BCTpy 与更强 reciprocal-degree null、构造完整匹配图族，且在阶段门允许时预注册资源和 benchmark headroom。若十图中至少八图存在 witness，只允许进入 null 模型设计评审；不足八图则将该候选因素视为当前图族中的低可行性方向，保留全部失败记录。
