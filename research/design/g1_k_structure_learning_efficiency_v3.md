# G1-KSI-0001 v3：带时间演化的耦合／解耦潜变量上的 K 组织学习效率

2026-09-24。**状态：`DRAFT_FOR_RULE_REVIEW_AND_DESIGN_CRITIQUE`。** 本稿在读取既有结果与本仓库记录后形成，不是预注册，不证明先于本轮讨论。无新数据、无训练、无 Gate 1 状态变化。

v3 取代 v2（v2 的评审与修正记录见决定0060 与 `research/reflections/G1-KSI-0001-V1/`）。v3 的两处实质变更：(i) **删除 v2 关于"转移核以 `p_J` 为平稳分布"的断言——该断言为假**，改为如实报告实际平稳律与边缘（检查 G）；(ii) 写入实测难度差，供 §4.7 硬门使用。另记录一个被否决的替代构造。

## 1. v0 被拒的原因：任务没有时间结构，后验只依赖样本均值

v0 为每个 episode 抽**一个静态** `z ~ p_J(z)`，再抽 16 个**条件独立**观察。由恒等式 `Σ_t‖y_t−z‖² = Σ_t‖y_t−ȳ‖² + T‖ȳ−z‖²` 得后验 `∝ exp(Σ_edges J_ij z_i z_j − 8‖ȳ−z‖²)`：**两条件的后验都只通过 ȳ 依赖数据**，递归组织在原理上无作用面。机器核对（检查 A）给出 `max|Δ| ≈ 2e-19`。v0 不是"预测可能错"，而是"预测无法被检验"。

## 2. 生成器（冻结常数与转移核）

| 量 | 冻结值 | 说明 |
|---|---|---|
| `T` | 16 | 序列长度 |
| `β` | 0.8 | 时间持续性；`J=0` 时每维翻转概率 `1/(1+e^{2β}) ≈ 0.168` |
| `λ` | 0.7 | 每步证据强度（`λ<1` 使单步观察弱信息，信念必须跨时间累积） |
| `J_F` / `J_X` | 0 / 0.25 | **唯一被操纵的量** |
| `E` | 四环 `{(1,2),(2,3),(3,4),(4,1)}` | 无外场 |
| 状态 | `z_t ∈ {−1,+1}^4`，`z_1` 各维独立均匀 | |

```text
转移：p(z_t | z_{t−1}) ∝ exp( β·Σ_i z_{t,i} z_{t−1,i} + J·Σ_(i,j)∈E z_{t,i} z_{t,j} )
观测：y_t | z_t ~ N(λ·z_t, I₄)
目标：模型依序接收 y_1..y_T，输出 16 类联合后验 q(z_T | y_1:T)
```

**该核的性质（经检查 G 实测，不作未验证断言）**：

- `J=0` 时核**精确按维分解**（这是 F 机制的全部基础）；
- 其**平稳律在 `J>0` 时不是 `p_J`**：实测 X 的平稳律与 `exp(J·E(z))` 归一化目标的最大绝对偏差为 `0.0596`。v2 曾断言平稳律等于 `p_J`，**该断言为假，已删除**；本稿只报告实测平稳律；
- 两条件的**边缘先验都精确均匀**（实测 F、X 各维边缘均为 `0.5`，偏差 `<3e-16`）——这是裁定 A"仅耦合不同、边缘相同"所依赖的性质。

**被否决的替代构造（保留为负设计记录）**：曾改用"以概率 `1−ε` 保持、否则做一次 Gibbs 扫描"的核，使 `p_J` 成为**精确**平稳分布（检查 G 曾因此通过）。但该核的"是否重采样"是四维**共享**的随机事件，两个乘积核的混合不再是乘积核，于是 `J=0` 时**不再按维分解**（检查 B/C 实测失败：链 0 对他链流的不敏感性从 `2e-16` 恶化到 `3.6e-3`）。机制优先，故回退，并接受"平稳律非 `p_J`"这一代价。

## 3. 精确 oracle 与机制

- **X**：联合状态空间 16，标准 HMM 前向递推（T 次发射、T−1 次转移），`O(T·16²)`。
- **F**：`J=0` 时转移与发射按维分解，故 `p(z_{1:T}|y_{1:T}) = Π_i p(z_{1:T,i}|y_{1:T,i})`；精确解是**四条互相独立的两状态时间递归**，第 i 条只用 `y_{1:T,i}`。
- **独立重推**：检查 E 用**轨迹枚举**（T=4 穷举 `16⁴ = 65,536` 条）作第二实现，与前向递推一致到 `1.9e-15`。该检查此前**抓到过一次真实实现缺陷**（前向递推末步多做一次转移），自洽检查无法发现。
- **预测，而非由 oracle 结构推出**：oracle 事实只说明两条件的最优计算在可分解性上不同（检查 D：X 的联合后验与逐链边缘乘积 TV 距离 `0.951`）。是否在有限预算训练中表现为学习效率差异，是**假设**，不是上述事实的推论。

**预注册方向与对照**：`I = β_F − β_X > 0`，其中 `β_c = (D_{4,c} − D_{2,c})/ln2`，`D_{k,c} = mean_s[AUC(random_sparse) − AUC(block)]`；**K 不变对照** `I_flat = D̄_F − D̄_X`，`D̄_c = (D_{2,c}+D_{4,c})/2`，与 `I` 同时进入决策规则，防止"F 独有但 K 恒定"的真实优势被 `I≈0` 掩盖。两点 K 只支持有限差分，**不**主张 `ln K` 标度律。

## 4. 终点、估计量与资格门

- 损失 `L = KL(p_oracle‖q)/ln16`；唯一 primary `AUC_B = (1/B)Σ_j (u_{j+1}−u_j)[L(u_j)+L(u_{j+1})]/2`，检查点网格预锁。
- **终端非劣**：primary 判定同时要求块臂 `L(u_M)` 不劣于其配对控制超过预注册容差 `τ_term`；"更快但收敛到更差平台"不算支持，判 `INCONCLUSIVE` 并如实报告该权衡。
- 次要：`updates-to-ε`，未达记 `>B`，不插补、不替代主终点。
- 三分支：`I`（与 `I_flat`）的 95% 区间下界 `> δ_min` 支持；上界 `< δ_min` 否定最小有用预测；跨越则不确定。训练种子为推断单位。

**资格门（每 K×F/X 单元，任一失败即停止，不改终点、不扫 J、不合并条件）**：

1. 未训练模型 `L(u₀)` 显著高于 ε；
2. 实际主控制在预注册**早期检查点**仍显著高于 ε；
3. 实际主控制在 B 内达 ε，达标时间中位数落在预注册 `[τ_lo, τ_hi]`；
4. dense H64 guard 达 ε；
5. oracle 正确性经**第二实现**（检查 E）独立重推；
6. 状态、有效／分配参数、同 kernel 执行形状与**实测** p50 时延符合预注册护栏；
7. **难度硬门**：在冻结常数下，F 与 X 的 oracle 平均后验熵差须落在预注册容差内。**实测（检查 F，2000 episodes/条件）**：F `0.5620`、X `0.5360`（归一化熵，`ln16` 为分母），**差 `0.0261 ± 0.0049`（SE）**，即约 `0.072` nat；两条件平均最大后验概率分别为 `0.4680` 与 `0.4915`。该差虽在统计上可辨（约 5.3 SE），量级很小，故容差取 `≤0.05`（归一化）时该门在冻结常数下**可通过**；若资格流实测超出容差即停止；
8. **余量与分辨力**：由资格流种子级方差计算配对 MDD，要求 `MDD ≤ δ_min`；并做分辨力检查（终点须能分辨先验已知不同的臂，dense guard 对随机稀疏）；
9. **对称坍缩为停止项**：块臂用每块独立输入投影（总参数与控制臂稠密输入映射相同）＋每块独立初始化，**不**按潜变量硬编码输入分路或候选指派；坍缩诊断 FAIL 即停止，不重调、不换初值救结果。该诊断只判断操纵是否生效，**不**推断槽的假设语义。

**任何资格门都不能排除"交互在结构上为零"的任务**；门能保证的是任务可学、控制未被弱化、终点有分辨力、难度未混淆。区分"无效应"与"无作用面"依赖预注册方向、`I` 与 `I_flat` 双对照与三分支判词。

## 5. 功效与不可行性前置声明

正式种子数由基于**配对**结构的预注册功效计算确定（同一种子在全部单元共用 batch 与流）。若在预注册可行种子数上限内 `δ_min` 处功效低于预注册水平，**本设计判定不可行并停止**；不得事后降低 `δ_min`、删单元或改用单条件点比较。`δ_min, τ_term, ε, B, τ_lo, τ_hi, 种子数, bootstrap, 难度容差, 坍缩阈值, MDD 算法` 全部在资格流解封前以数字冻结。

## 6. 与决定0049 的关系、最强拒绝与先例边界

- 本生成器是**新注册的生成器**（时间演化 + 单一耦合矩阵条件），不是对已关闭 EXP-0013 阶段显露生成器的再参数化；两条件是否满足 0049 的"独立研究问题"须**独立前瞻裁定**（本稿即该裁定的送审对象之一）。
- **最强拒绝**：(a) F/X 难度与联合熵不同 → §4.7 硬门（实测差 0.0261）＋ §6 解释限制；(b) 控制学习失败或有效参数随 K 变化 → §4.1–4.4/4.6；(c) 同 kernel 不保证实测时延相等 → §4.6 要求实测；(d) 只是已知"任务相关性 × 模块结构"规律的复现 → 先例边界见 `research/prior_art/dir0002_direction_prior_art.md`；(e) 块臂对称坍缩 → §4.9 停止项；(f) 功效不足注定不确定 → §5。

- 先例边界：任务变量相关性与模块化／资源约束对功能专化的影响已有直接 RNN 先例；本设计**不**声称"任务结构调节模块效应"、"模块消融"或"匹配随机位置干预方法"新颖。
