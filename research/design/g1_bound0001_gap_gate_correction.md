# G1-BOUND-0001：`gap(k)` 覆盖到 `k = T` 的门是**定义性空洞**（更正）

2026-09-24。关闭 G1-ALIGN-0001 v2 §8.2 与 G1-BOUND-0001 §5.2 记录的缺口，并**更正该门的表述**。**不是判词。**

## 1. 原缺口

两版设计都要求"`gap(k)` 曲线须覆盖到 `k = T = 64`"，而冻结工件只覆盖 `k ∈ {4, 8, 16, 32}`（G1-ALIGN-0001 v2 审查 I12 提出）。

## 2. 补算结果（200 episodes，bootstrap 200）

机器输出 `research/design/structural_task_probe/align0001_gap_to_T.json`。

| 条件 | `gap(4)` | `gap(8)` | `gap(16)` | `gap(32)` | **`gap(64)`** |
|---|---|---|---|---|---|
| `F`（`c=0`） | 0.6900 | 0.5691 | 0.4023 | 0.2259 | **0.0000** |
| `X`（`c=6`） | 0.6361 | 0.5448 | 0.3853 | 0.2156 | **0.0000** |

| `c=5`（复核条件） | 0.6758 | 0.5698 | 0.4131 | 0.2530 | **0.0000** |

## 3. 判定：`gap(T) ≡ 0`，故该门**不可满足**

`gap(k) = KL( p(z_T | y_1:T) ‖ p(z_T | y_{T−k+1:T}) )`。当 `k = T` 时，截断后验使用的**正是全部历史** `y_1:T`，故两个分布**恒等**，`gap(T) = 0` **对任何生成器成立**。

**因此**："`gap(k)` 须覆盖到 `k = T`"作为**资格门**是**定义性空洞**的：它要求一个恒为 0 的量 `≥ 0.20`，**任何设计都无法满足**。

## 4. 更正后的门（**建议**，待审查裁定）

> **非局部性门（更正）**：注册前提交 `gap(k)` 曲线，覆盖到**预注册的 `k_max`**，其中 `k_max` 须 `≤ T/2`（留出可分辨余量），且要求**两条件**的 `gap(k_max)` 的 95% 区间下界 `≥ 0.20`。

**对本设计取 `k_max = 16`**（与既有冻结值一致，且 `T/2 = 32`）：`c=4` 为 `0.3874 [0.3424, …]`、`c=5` 为 `0.4131 [0.3609, …]`，**区间下界均 `≥ 0.20`，门通过**。
