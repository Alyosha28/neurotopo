# DIR-0004 独立前瞻设计审查说明（送审前提交）

2026-09-24。本说明在**送审前**提交，并随设计稿 v0.1 一起冻结为 packet。**不是效果证据、不是注册、不是训练许可、不改变 Gate 1 `NOT_PASSED`、不追认任何既有判词。**

## 背景（审查者须知道的最少事实）

**任务线**：CAL-0008 已实测关闭"在同一生成器族内加难取得余量"这条路（四个固定配置的匹配稠密单流控制全部 `SATURATED`，末端 oracle-relative KL `0.00043–0.0038` nat）。它留下的开放问题是：需要**结构性不同的任务**——精确解本身不可用低维平滑近似。DIR-0004 就是对该问题的"第 0 步可供性筛查 + 第 1 步机制"作答：选**混沌潜轨迹跟踪**，其精度需求随视界线性增长，故不存在有界维、有界精度的精确解。

**本设计的机制**：状态被**声明地**划分为"扩张子空间坐标"与"收缩分量"（后者由已知映射与观测重新导出，不存储），并配一个声明的时间尺度/增益分配；oracle 臂直接获得真实扩张坐标。

**设计稿当前版本是 v0.1，不是 v0**。主代理在冻结送审前自查，发现 §2 原稿把"稠密状态**必然**丢失轨迹"写成已证结论，但那只在**声明的每坐标固定精度编码**这一模型类内成立。据此把主张拆成：

- **C1（任务侧，已核验）**：隐藏不稳定模态的跟踪所需**存储精度**随视界线性增长，斜率 `log2 λ_u` 比特/步（线性复核斜率 `1.000`；帐篷 `1.030`、逻辑斯蒂 `r=4` `1.073` 比特/步）。
- **C2（架构侧，未证）**：在**匹配状态预算**下，被声明为扩张/收缩组织的架构是否比未被这样声明的稠密控制更接近 oracle。

**本轮另补**：先例核查（AUS＝assimilation in the unstable subspace 是成熟领域；"卡尔曼滤波误差协方差坍缩到不稳定子空间"已有专文），故 C1 与教科书可预报时间关系等价、机制不具新颖性；§4 要求的 bits(T) 显式曲线已由新脚本产出并自带观测控制。

**入口规则**：决定0080（经用户授权，非经独立审查）已允许项目 Gate 1 轨申报 `architecture_organization` 因子，但要求该注册**在其自身合同内自缚一个冻结的通用性谓词**；且 0080 明写**不批准本设计**——它仍须过本审查与资格阶梯。

## 问题（七问）

1. **C1／C2 的拆分是否够**：把原稿的"可证明分离"拆成 C1（任务侧、模型类内）与 C2（架构侧、未证）之后，设计稿里是否**仍有**越出声明模型类的措辞或推论？请逐条指出。
2. **C2 是否有内容，以及 oracle 拟合探针能否判定它**：探针要求"每臂在直接监督拟合 oracle 时能否达到 oracle 水平"。**"达到 oracle 水平"的判据是什么**——末端 `KL` 的绝对水平、相对 oracle 的比值、还是拟合损失？若该判据在注册时没有预注册水平、容差与功效，它是否会重演 G1-BOUND-0001 被审查判死的 **S4"名义通过"**（限定检查对唯一能使其失效的方向零功效）？
3. **对照的合法性与匹配轴**：在 `G1-MATCH-v3` 下本机制实际消耗的轴应声明为什么（状态？执行计算？），主对照应该是哪一臂？oracle 臂直接拿到真实扩张坐标，它在**信息**上优于候选臂——它是否只能作诊断臂、不得进入主比较？
4. **终点合法性**：设计把主终点定为末端 `KL`（水平），并把 `T*`／交叉位置降为**描述量**，理由是 `T*` 是 steps-to-threshold 型量、会触发决定0062 B。**这一处置是否足够**？设计稿里是否仍有以时间量承载判词的地方？
5. **任务是否退化为"高精度保存一个未知初值"**：扩张模态**永远不被观测**，那么所选视界内模型唯一能做的是把初始条件高精度地传播下去。这还算"跟踪/同化"吗？**AUS 的机制直觉（不稳定方向由观测约束）在"完全不可观测"的设定下是否仍然适用**？若本任务族实际是"带噪观测下的精度受限预测"，请说明这对 C2 的可解释性与对照设计意味着什么。
6. **先例是否已覆盖 C2**：AUS 的"最优子空间维数"与"协方差坍缩到不稳定子空间"这两项结果，是否**已经蕴含** C2 的答案（即：只需追踪不稳定子空间）？若已蕴含，C2 是否只是把既有理论换成"匹配预算下的架构措辞"？请给出可核验的判断依据。
7. **最强拒绝**：设计自列两条——A（稻草人控制：稠密臂被强制对称分配；它本可不存储被观测的收缩分量、并用多单元承载隐藏标量）与 B（换名：AUS／经典滤波早已如此）。**是否还有设计未列的、更致命的一条？**

## 最强拒绝（审查须正面处理）

- **A（稻草人控制）**：C1 的"对称分配"是**模型类的参数选择**；真实稠密状态可以（i）不存储被观测的收缩分量、（ii）用多个单元承载隐藏标量。若如此，C2 的"结构化 vs 稠密"就不是两种组织，而是两种**人为设定**，主比较不合法。
- **B（换名）**：AUS 与经典滤波已覆盖"只追踪不稳定子空间"，C1 等价于教科书可预报时间公式。本设计若只剩措辞差异，应当停止。
- **C（探针无功效）**：oracle 拟合探针若没有预注册水平/容差/功效，或只覆盖"训练值低于族内投影代价"一侧，则不能判定 C2，属名义通过。
- **D（信息不对等）**：oracle 臂获得真实扩张坐标，可能使 C2 的"分离"只是**信息差**而非组织差；若 oracle 臂进入主比较，本设计立即失去资格。
- **E（任务退化）**：扩张模态完全不可观测时，任务可能退化为"高精度保存未知初值"，与"跟踪"的语义不符，且使 AUS 的机制直觉不适用。
