# EXP-0012 生成矩阵的零样本解析筛查（设计冻结）

2026-09-24，在任何EXP-0012样本、控制/候选训练及正式实验配置前固定。目的是构造一次有限的**晚到证据**任务参数，而非寻找RS4效果。G1-RS v1仅获`READY_FOR_NUMERIC_PROTOCOL`；本筛查只使用生成矩阵的解析脉冲响应，不调用任务随机根，也不测任何模型。最多四个预列候选，全部数值与未通过项保留；没有合格项则关闭此生成器方向，不改变菜单继续搜索。

NumPy 2.3.3 / PCG64 seed`35017`取一个6×6独立标准正态矩阵，QR分解并令R对角非负、Q行列式为+1，得`Q_T`。对角度菜单`[0.08,0.12,0.16,0.20]`按顺序构造`R(ε)`：在坐标(0,1)、(2,3)、(4,5)上分别施加`+ε,−ε,+ε`的二维旋转，`Q_D=R(ε)Q_T`。`A_T=0.98Q_T`，`A_D=0.98Q_D`，`B=C=e1`，观测标准差`σ=0.8`。目标/干扰共享相同观测噪声和驱动分布。所有数值使用float64 little-endian C-order数组保存，附数组及JSON SHA-256、算法脚本/解释器/NumPy/lock SHA；生成后不得重抽seed或改符号规则。矩阵设计成本单列，不计模型研究更新。

令`d_l=Cᵀ(A_T^l−A_D^l)B`，`l≥0`；对长度`t`，随机驱动`u_s∼N(0,1)`下目标与干扰条件均值差的预期累计单流KL为

`D(t)=Σ_{s=1}^t Σ_{l=0}^{s−1} d_l²/(2σ²)`。

这是给定全部u历史时两个同方差高斯轨迹模型的期望辨别信息，**不是**实际四流后验修订率、模型误差或资格结果。错误cue可靠度计划`r=0.75`，其先验目标/误导候选log-odds为`log(3r/(1−r))=log9≈2.197`；两流预期证据优势约`2D(t)`。因此只为筛查早期仍有歧义且t32有翻转机会，预写PASS当且仅当`0.05≤D(8)≤1.0`且`1.5≤D(32)≤4.5`。若多项PASS，选菜单顺序的**第一项**；无PASS则`NO_MATRIX`。不按RS4/SC64/D64分数、样本修订率或矩阵外观挑选。真实修订率、cue/current-frame捷径与实际主单流余量仍需在独立任务/控制资格流按未来正式协议检查，失败关闭固定配置。

执行脚本只能输出四个候选的`D(8),D(16),D(32)`及PASS与所选数组/哈希；不得生成H/cue/u/y样本或调用任何模型。第二人/独立脚本逐字节重推数组及公式并写验证报告后，才把选择结果填入EXP-0012数值协议。保留每个失败尝试与源码提交，绝不以修改本门槛追认已经看过的值。
