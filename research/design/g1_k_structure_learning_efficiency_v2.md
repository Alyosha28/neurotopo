# G1-KSI-0001 v2：带时间演化的耦合／解耦潜变量上的 K 组织学习效率

2026-09-24。**状态：`DRAFT_FOR_RULE_REVIEW_AND_DESIGN_CRITIQUE`。** 本稿在读取既有结果与本仓库记录后形成，不是预注册，不证明先于本轮讨论。无新数据、无训练、无 Gate 1 状态变化。

v2 取代 v1（v1 及其独立评审保留：`research/reflections/G1-KSI-0001-V1/`）。v1 的生成器数学与 v0 缺陷诊断经独立评审确认成立，但评审提出 8 项缺陷；v2 逐条修正，对应关系见 §9。

## 1. v0 被拒的原因：任务没有时间结构，后验只依赖样本均值

v0 为每个 episode 抽**一个静态** `z ~ p_J(z)`，再抽 16 个**条件独立**观察 `y_t | z ~ N(z, I₄)`。由恒等式

```text
Σ_t ‖y_t − z‖² = Σ_t ‖y_t − ȳ‖² + T‖ȳ − z‖²
```

得 `p(z|y_1:T) = exp(Σ_(i,j)∈E J_ij z_i z_j − 8‖ȳ − z‖²)` 归一化。**两条件的后验都只通过 ȳ 依赖数据**，F 与 X 的差别仅是那个固定二次型读出的系数；递归组织在原理上无作用面。机器核对（检查 A）在冻结常数下给出 `max|Δ| ≈ 2e-19`。**v0 不是"预测可能错"，而是"预测无法被检验"。**

## 2. v1／v2 生成器：潜变量按时间演化，F/X 只差耦合矩阵

### 2.1 冻结常数（v2 修正：v1 未承诺这些数值，评审指出核对因此不对应设计）

| 量 | 冻结值 |
|---|---|
| `T` | 16 |
| `β`（持续性） | 0.8 |
| `λ`（每步证据强度） | 0.7 |
| `J_F` / `J_X` | 0 / 0.25 |
| `E` | 四环 `{(1,2),(2,3),(3,4),(4,1)}`，无外场 |
| 状态 | `z_t ∈ {−1,+1}^4`，`z_1` 各维独立均匀 |

```text
转移：p(z_t|z_{t−1}) ∝ exp( β·Σ_i z_{t,i} z_{t−1,i} + J·Σ_(i,j)∈E z_{t,i} z_{t,j} )
观测：y_t | z_t ~ N(λ·z_t, I₄)，逐步同步观察四维
目标：模型依序接收 y_1..y_T，输出 16 类联合后验 q(z_T|y_1:T)
```

`β, λ, T, E` 在两条件完全相同；**F 与 X 的差异只有 J**。该转移以 `p_J` 为平稳分布（可解析验证），故 F 的平稳分布均匀、X 为耦合 Ising 分布。取 `λ = 0.7 < 1` 使单步观察弱信息，信念必须跨时间累积。

### 2.2 精确 oracle

- **X**：联合状态空间 16，标准 HMM 前向递推（T 次发射、T−1 次转移），`O(T·16²)`。
- **F**：`J=0` 时转移与发射按维分解，故 `p(z_{1:T}|y_{1:T}) = Π_i p(z_{1:T,i}|y_{1:T,i})`；精确解是**四条互相独立的两状态时间递归**，第 i 条只用 `y_{1:T,i}`。

**独立重推（评审 R6）**：检查 E 用**轨迹枚举**（T=4 时穷举 `16⁴ = 65,536` 条轨迹）作为第二实现，与前向递推一致到 `1.9e-15`。该检查**实际抓到过一次实现缺陷**：修正前的前向递推在最后一步多做一次转移（得到 `z_{T+1}` 的预测分布而非 `z_T` 的滤波后验），而自洽检查 B/C/D 因两实现共享同一约定错误无法发现。缺陷已修，v1 评审记录中的数值已随之更新。

### 2.3 预测，而非由 oracle 结构推出（评审 R8 修正）

oracle 侧的事实只说明：**两条件的最优计算在可分解性上不同**——F 可分解为四条独立时间滤波，X 不可分解（检查 D 在冻结常数下给出联合后验与逐链边缘乘积的 TV 距离 `0.95`）。**是否在有限预算训练中表现为学习效率差异，是本设计的假设，不是上述事实的推论。** 本稿不作"因此必然有机制依据"的表述。

预注册方向与预期量级（评审 R7）：

- **主预测**：`I = β_F − β_X > 0`，其中 `β_c = (D_{4,c} − D_{2,c})/ln2`，`D_{k,c} = mean_s[AUC(random_sparse) − AUC(block)]`。
- **K 不变对照（新增，防假阴性）**：`I_flat = D̄_F − D̄_X`，`D̄_c = (D_{2,c}+D_{4,c})/2`。若机制预测的是"F 中块组织优势存在但在 K 上大致恒定"，则 `I ≈ 0` 而 `I_flat > 0`；**两个对照都进决策规则**，`I_flat` 与 `I` 同时报告，不得只报其一。
- **预期量级**：`δ_min` 由配对功效计算在效果轮前确定（§4.5）；本稿不虚构数值，也不把 `ln2` 归一化当作已测得的标度律——两点 K 只支持有限差分。

## 3. 终点与估计量

- 损失 `L = KL(p_oracle‖q)/ln16`；唯一 primary `AUC_B = (1/B)Σ_j (u_{j+1}−u_j)[L(u_j)+L(u_{j+1})]/2`，检查点网格预锁。
- **终端非劣条件（评审 R2 新增）**：primary 判定同时要求块臂 `L(u_M)` 不劣于其配对随机稀疏控制超过预注册容差 `τ_term`。**只有"更快但收敛到更差平台"不能算支持**；若 AUC 更低而终端超容差，判 `INCONCLUSIVE` 并如实报告该权衡。
- 次要：`updates-to-ε`，未达记 `>B` 并报达标比例，不插补、不替代主终点。
- 决策三分支：`I`（与 `I_flat`）的 95% 区间下界 `> δ_min` 支持；上界 `< δ_min` 否定最小有用预测（另行如实报告可能的正向小效应）；跨越则不确定。训练种子为推断单位。

## 4. 资格门（v2 修正：加入余量／分辨力判据与停止项）

**每个 K×F/X 单元**须同时满足；任一失败即停止资格轮，不改终点、不扫 J、不合并条件：

1. 未训练模型 `L(u₀)` 显著高于 ε；
2. 实际主控制（保度随机稀疏）在预注册**早期检查点**仍显著高于 ε；
3. 实际主控制在 B 内达 ε，达标时间中位数落在预注册 `[τ_lo, τ_hi] ⊂ (0, B)`；
4. dense H64 guard 达 ε（任务可学）；
5. oracle 正确性经**第二实现**（轨迹枚举，检查 E）独立重推；
6. 状态、有效／分配参数、同 kernel 执行形状与**实测** p50 时延符合预注册护栏；
7. **难度匹配为硬门（评审 R4 修正）**：在冻结的 `β, λ, J₀, T` 下，F 与 X 的 oracle 平均后验熵与可达 `L` 下界之差须落在预注册容差内；超出即停止。本项与"F/X 难度不同"的表述不再并存：**难度差超容差 → 停止，而不是报告一个混淆的交互。**
8. **余量与分辨力（评审 R1 新增）**：由资格流的种子级方差计算配对**最小可检测差 MDD**，要求 `MDD ≤ δ_min`；并做**分辨力检查**——终点必须能分辨两个先验已知会不同的臂（dense guard 对随机稀疏，二者有效参数不同）。若 MDD 超 `δ_min` 或分辨力检查失败，则该任务对目标效应**没有分辨力**，停止。
9. **对称坍缩为停止项（评审 R3 修正）**：块臂采用**每块独立输入投影**（块对角输入映射，总参数与控制臂稠密输入映射相同）＋每块独立初始化，使块可分化而**不按潜变量硬编码输入分路或候选指派**。资格轮内做坍缩诊断（预注册阈值）；**诊断 FAIL 即停止该轮**，不重调、不换初值救结果。该诊断只判断操纵是否生效，**不**推断槽的假设语义，也不构成 H3-semantic 或 Gate 3 证据。

**任何资格门都不能排除"交互在结构上为零"的任务**——门能保证的是任务可学、控制未被弱化、终点有分辨力、难度未混淆。区分"无效应"与"无作用面"最终依赖预注册方向、`I` 与 `I_flat` 双对照以及三分支判词，本稿不声称资格轮能替代这一区分。

## 5. 功效与不可行性前置声明

`I` 与 `I_flat` 都是多重差分。正式种子数由基于**配对**结构的预注册功效计算确定（同一种子在全部单元共用 batch 与流）。**若在预注册的可行种子数上限内，`δ_min` 处功效低于预注册水平，本设计判定不可行并停止**；不得事后降低 `δ_min`、删单元或改用单条件点比较。`δ_min, τ_term, ε, B, τ_lo, τ_hi, 种子数, bootstrap, 各容差` 全部在资格流解封前以数字冻结。

## 6. 与决定0049 的关系与最强拒绝

- 本生成器是**新注册的生成器**（时间演化 + 单一耦合矩阵条件），不是对已关闭 EXP-0013 阶段显露生成器的再参数化；两条件是否满足 0049 的"独立研究问题"须**独立前瞻裁定**。
- **最强拒绝**：(a) F/X 难度与联合熵不同 → §4.7 硬门 + §4.9 与 §7 的解释限制；(b) 控制学习失败或有效参数随 K 变化 → §4.2/4.4/4.6 与资源护栏；(c) 同 kernel 不保证实测时延相等 → §4.6 要求实测；(d) 只是已知"任务相关性 × 模块结构"规律的复现 → §7 先例边界；(e) **块臂对称坍缩** → §4.9 停止项；(f) **功效不足注定不确定** → §5 不可行性前置声明。
- **难度匹配的次要分析**：可在资格流上选 `λ_X` 使 X 的 oracle 平均后验熵与 F 匹配，作为**次要**报告；它改变观测模型，**不得**进入 primary 判词，也不得替代主判词。
