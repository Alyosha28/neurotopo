# GPI-0001 关闭记录的独立审查说明（送审前提交）

2026-09-24。本说明在送审前提交。**它不是效果证据、不是注册、不是 Gate 通过。**

## 问题

1. **关闭判定是否被数字正确支持**：两臂 pilot 给出 `D_F = −0.0142`、`D_X = −0.0201`、`I = +0.0059`（sd `0.0211`，95% t 区间 `[−0.0466, +0.0584]`）。由此判 `CLOSED_BEFORE_REGISTRATION`（而非注册或"不确定"）是否正确？**是否过度解读了 3 seeds 的 pilot**？
2. **保留结论是否成立**：控制侧（`LR ∈ {1e-3,3e-3}` × 3 seeds × F/X，3200 步末端 KL `0.065–0.089` > `0.05`，落差 `0.0005–0.0118`）是否足以支持"该任务族具有真实末端余量"？`gap(16)` 与 `0.063` 解析形状代价的表述是否准确（**不得**把形状代价说成容量上界）？
3. **负面结果的边界是否正确**：关闭是否只覆盖这组固定配置与掩码式组织操纵？是否遗漏了"块组织一致劣于随机掩码"这一更强发现的替代解释（例如随机掩码带来额外混合、初始化差异、优化效应）？
4. **实现缺陷的影响**：`curve[0]` 在训练后计算导致 JSON 自带 `I_mean` 含伪点（`+0.0036` 对重算 `+0.0059`）。该缺陷是否影响任何判定？

## 输入范围

送审 packet 只含：本审查说明、关闭记录全文、机器输出（两项测量的曲线与重算字段）。评审者**不得**浏览仓库其他内容、不得读取对话、不得运行代码或训练。

## 最强拒绝（须正面处理）

- **R1**：3 seeds 的 pilot 不足以"关闭"一个方向——区间 `[−0.047, +0.058]` 也包含 `+0.05`，故正确标签或许是"不确定"而非"关闭"。
- **R2**："块组织一致劣于随机掩码"可能只是**随机掩码的额外混合**在起作用的优化效应，不是关于组织的结论。
- **R3**：余量证据来自控制臂的 KL 平台，而平台同样可能是**优化下界**（虽已有 LR 扫描与预算加倍）。
- **R4**：把"任务族有末端余量"与"效应不存在"并列，可能诱导读者把两者合并成"余量存在但组织无用"的一般结论。
