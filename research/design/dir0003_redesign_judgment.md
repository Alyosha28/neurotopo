# DIR-0003 重新设计判断：为什么"更好的匹配"救不了这条线，以及该改成什么

2026-09-24。本文件回答用户问题"该怎么重新设计"。**结论先行：v0 的失败不是参数没调好，而是"匹配一个标量摘要 + 比较水平"这一提问形态在本族里自毁；重新设计必须换提问形态（换 claim type），而不是换构造。** 全部数字来自本轮机器输出，无训练、无复现外部结果。

## 1. 我做了哪些"修补式"尝试（决定不采用它们）

针对独立审查的 17 项，我先按"可修补"路径做了三项修补并实算，结果如下。

### 1.1 把截断和换成**精确无穷视界**总容量（治 I1）
`scripts/dir0003_v1_exact_check.py`：对 AR(1) 输入下的线性对角核，闭式给出 `Σ_{k≥1} g_i(k)g_j(k)`（几何级数求和），因此总容量是**精确无穷和，无截断**。
- **自检 1**：闭式 Gram 对直接求和到 `k=20000` 的最大绝对误差 `6.25e-13`（修复过程中我自己的一个广播错误被这条自检抓出并改正）。
- **自检 2**：`φ=0` 时宽带精确总量 `3.7020119`，与 v0 独立实现 `h=4000` 截断值 `3.6991701` 一致（差即 4000 以外尾部）。
- 结论：**I1 在计算层面可修**——"总容量"可以精确、无截断。

### 1.2 把匹配与预测都放到**任务分布**（AR(1)）下（治 I2）
同上脚本在 `φ=0.5` 下直接计算匹配与曲线，不再用 i.i.d. 探针。结论：**I2 可修**，且修好后仍存在 33 个匹配 rung（`|比值−1| ≤ 0.02`）。

### 1.3 把操纵量改成**三段固定时间尺度带上的单元分配**（治 I6 的捆绑）
固定带边界（短 `0.20–0.40`、中 `0.60–0.75`、长 `0.90–0.97`），`N=64`，单元数向量 `(n₁,n₂,n₃)` 为操纵量，约束为**精确总容量匹配**（2 维单纯形 + 1 约束 ⇒ 1 维族）。结论：**匹配族存在**，且"中心/谱半径"是被约束决定的因变量而非自由旋钮。

## 2. 但修补完仍然死：本族的**退化**（这是本轮最重要的实算发现）

`research/design/dir0003_v1_degeneracy_check.json`（`sha256 = ac63dc26a27a9b0c…`）对一对**总容量匹配到 3×10⁻⁵** 的分配 `(49,11,4)` 对 `(21,21,22)`（`φ=0.5`）：

| 量 | 数值 |
|---|---|
| 臂间差（全网格最大） | `0.0599 – 0.0880` |
| 臂间差（`k ≥ 20`） | `0.0042 – 0.0115` |
| **同一臂自身曲线的 γ 变化**（`γ ∈ {0.003, 0.01, 0.03}`） | **`0.0810 – 0.0844`** |
| 网格上符号翻转个数随 γ | `1 → 1 → 2`（**不稳定**） |
| 匹配比值随 γ 漂移 | `0.9955 → 1.0000 → 1.0034` |

即：**要检验的效应（≤0.088，长延迟侧仅 0.004–0.012）不超过读出选择本身带来的伪影（0.081–0.084），而我原定的"形状预测"（符号翻转个数）在 γ 上不稳定。**

原因不是实现：`research/design/dir0003_v1_exact_check.json` 显示，在匹配总容量后，不同分配的容量曲线**几乎重合**（网格差多数 ≤0.02，最大 0.12 且非单调）。**总数一被匹配，剖面就基本被决定**——因为总容量本身是各延迟容量的加权和，长带主导总数，匹配总数即锁定了长带，从而锁定了剖面。**"分布 vs 总数"这一提问形态在本族里近乎退化。**

### 范围（不得外推为不可能定理）
该退化结论成立的范围：① 对角线性核；② 三段固定带、带内对数均匀的构造；③ 岭读出族；④ `φ=0.5` 的 AR(1) 任务输入；⑤ `N=64`。不是"任何分布效应都不存在"的一般命题。

## 3. 三条结构性教训（重新设计的依据）

1. **"匹配一个标量摘要再比水平"在本族自毁**：标量摘要一旦匹配，机制能动的自由度就所剩无几；剩下的差值落在读出/优化/任务侧的伪影带里。G1-ALIGN 死于容量通道与效应同量级，v0 死于**读出通道**与效应同量级——**同一个病**。
2. **修 I1/I2/I6 是必要的但不充分**：三条致命项修完后设计依然不可执行，说明审查的致命项是**症状**，真实的病在提问形态。因此**不应**再产出 v1 的修补版送审。
3. **能活下来的估计量必须满足两条**：① 它的**否定有定义且可被正面确认**（等价检验式，而非"不显著"）；② 常数因子、读出选择、超参**不能吸收它**（形状/斜率/序关系，而非水平）。这正是 `dir0003_B`"抗混杂的形态是形状预测"与 `dir0003_F`"TOST + 冻结判决函数"两条结论的交点。

## 4. 重新设计的四个候选与我的排序

| 候选 | 形态 | 判定 |
|---|---|---|
| **R1（不推荐）** | 继续在"总容量匹配"上加约束（同时匹配总数与一阶矩、更多带、连续权重） | 治不了退化：约束越多，可动自由度越少，效应更小 |
| **R2（不推荐）** | 换线性核为 tanh 核，做"线性/非线性 IPC 分配"在**总 IPC 匹配**下的交叉 | **理论上**总数不决定线性/非线性拆分，故有非退化空间；但同样要面对读出/数值带，且本轮已证明**必须先量出该带再谈效应**。可作为 R3 的一个特例，不作为首选 |
| **R3（推荐）** | **换 claim type**：从"某结构更好"改成"**预测的**学习指数/谓词分侧"，即把 `dir0003_B` 的形态（维数指数 `d^θ`、非单调临界线、平台/相变个数与位置、布尔谓词分侧）搬到合成 teacher–student 设定上；主终点在**单一冻结样本档**上是水平（避开决定0062 B 的时间量终点），而**指数只作机制通道** | 常数、读出、超参只能移动截距，不能移动斜率；否定是"测到的指数等于无结构对照的指数"，可被正面确认；与审查的全部 17 项不冲突 |
| **R4（备选）** | 回到 NQ-1：用 `dir0003_E` 的 **oracle 臂**做"潜力缺口 vs 实现缺口"分解，配 `dir0003_F` 的对照任务 selectivity | 需要"可学但未饱和"的任务——正是本项目反复失败的前置（EXP-0013 学习失败、CAL-0008 饱和）。**前置未满足前不得启动** |

**推荐 R3**，理由是它唯一同时满足：不依赖未满足的前置；不需要"匹配一个标量"；估计量抗超参（斜率）；终点不触 0062 B（主判词用水平，斜率只作机制通道）；且它与本轮取回文献的方法学同形（`dir0003_B` 的算法类阶梯与谓词式判定本身就是该领域做可证伪主张的标准形态）。

## 5. R3 要成立，**注册前**必须先算清的五件事（否则不得送审）

1. **带有多宽**：用与 v1 相同的做法，先量出**读出/数值带**（γ 与流长两维上的估计量漂移），并证明**预测的指数差**在量级上远离该带。v0/v1 的教训是：不做这一步就等于把伪影当效应。
2. **指数可辨**：目标的结构参数（信息指数/leap 一类）必须能**在生成器侧解析给定**，且两侧的预测指数**不同且差值可由现有理论给出区间**；理论只给"方向"时必须写明区间来源，不得事后补。
3. **算法类阶梯**：`dir0003_B` 要求同时声明**算法类的正则性/等变假设**并给出匹配的算法类对照（核/线性方法、一次样本多次更新等），否则"结构收益"在理论上不可证伪。
4. **终点不触 0062 B**：主判词必须逐字写成**非时间量**（冻结样本档上的损失/KL），任何"更快达到/更新数更少"的措辞都会重新触发 0062 B，须走 B1–B7 或另轨。
5. **判决函数级联**：按 `dir0003_F` 用**先判可否测（功效/带宽门）→ 再判等价 → 再判分侧**的级联，使分支互斥穷尽，且每个阈值都由脚本输出或资格流实测给出（不得凭经验取整；v1 的 `δ_task/Δ_eq/δ_null/±1e8` 全部栽在这里）。

## 6. 本轮**不做**什么

不产出 v1 修补版送审（第 2 节已证明其不可执行）；不注册 R3（它还只是问题形态，不是设计）；不启动 R4（前置未满足）；不改变 Gate 1 `NOT_PASSED`；不重开非回归清单任何条目；不对本项目任何机制下"无效"结论——本轮证明的是**提问形态**的失效范围，不是机制本身。
