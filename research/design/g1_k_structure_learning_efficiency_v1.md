# G1-KSI-0001 v1：带时间演化的耦合／解耦潜变量上的 K 组织学习效率

2026-09-24。**状态：`DRAFT_FOR_RULE_REVIEW_AND_DESIGN_CRITIQUE`。** 本稿在读取既有结果与本仓库记录后形成，不是预注册，不证明先于本轮讨论。无新数据、无训练、无 Gate 1 状态变化。

本稿取代 `research/design/g1_k_structure_learning_efficiency_v0.md`（保留 v0 作为被拒记录）。**v0 的生成器有一个可解析证明的致命缺陷，见 §1**；v1 只改生成器与资格门，保留 v0 的终点、估计量骨架与先例边界。

## 1. v0 被拒的原因：任务没有时间结构，后验只依赖样本均值

v0（第 40–41 行）为每个 episode 抽**一个静态** `z ~ p_J(z)`，再抽 16 个**条件独立**观察 `y_t | z ~ N(z, I₄)`。则

```text
p(z|y_1:16) ∝ p_J(z)·Π_t exp(−½‖y_t − z‖²)
            = exp(Σ_(i,j)∈E J_ij z_i z_j − 8‖ȳ − z‖²),   ȳ = (1/16)Σ_t y_t
```

**两个条件的后验都只通过 ȳ（4 维）依赖数据。** F 与 X 的区别仅是那个**固定**二次型读出的系数。于是：

- 模型只需累加 4 个均值再套一个固定映射，**递归组织在原理上就无作用面**；
- 块对角、保度随机稀疏、稠密 H64 应当表现相同；预期 `D_{2,c} ≈ D_{4,c} ≈ 0`，`I` 由噪声决定；
- 更危险的是资格门**很可能照常通过**（两臂都能达 ε，从 u₀=0 起的"动态范围"看起来也大），于是烧掉一轮预算才发现交互为零。

这与 TH-0001 已记录的模式同族：该任务存在极小的精确滤波。**因此 v0 不是"预测可能错"，而是"预测无法被检验"。**

## 2. v1 生成器：潜变量按时间演化，且 F/X 只差耦合矩阵

同一变量、同一字母表、同一观测族、同一长度、同一初始分布族，**只改一个事前固定的耦合矩阵**：

```text
状态：z_t ∈ {−1,+1}^4,  t = 1..T
初始：z_1 各维独立均匀
转移：p(z_t|z_{t−1}) ∝ exp( β·Σ_i z_{t,i} z_{t−1,i} + J·Σ_(i,j)∈E z_{t,i} z_{t,j} )
      E = {(1,2),(2,3),(3,4),(4,1)}，无外场
观测：y_t | z_t ~ N(λ·z_t, I₄)，逐步同步观察四维
条件：F 取 J = 0；X 取 J = J₀ > 0（事前固定，不搜索）
```

`β`（持续性）与 `λ`（每步证据强度）在两条件**完全相同**；F 与 X 的差异**只有 J**。取 `λ < 1` 使单步观察弱信息，信念必须跨时间累积，滤波非平凡。

### 2.1 精确 oracle（两条件都可解析、可独立重推）

- **X**：联合状态空间 16，标准 HMM 前向递推，`p(z_T|y_1:T)` 由 16×16 转移矩阵与逐时刻发射密度精确得到，复杂度 `O(T·16²)`。
- **F**：`J=0` 时转移与发射都按维分解，故

```text
p(z_{1:T}|y_{1:T}) = Π_i p(z_{1:T,i} | y_{1:T,i})
```

  精确解是**四条互相独立的两状态时间递归**，第 i 条只使用自己的观测流 `y_{1:T,i}`。

### 2.2 为什么这次有机制论证（v0 没有）

F 的最优计算结构是**四条独立的时间滤波**；X 的最优计算是**不可分解的 16 态联合滤波**（耦合使任一维的后验依赖全部四条观测流）。于是：

- K 块独立递归组织与 F 的计算结构**对齐**，与 X 的**不对齐**；
- 预注册方向 `I = β_F − β_X > 0` 因此有机制依据：块组织在因子化条件下提供有限预算归纳偏置，在耦合条件下不能跨链共享信息。

**诚实边界**：F 的后验仍存在低维充分统计量（每条链的 log-odds），所以本设计**不**主张状态容量分离，也不主张纯 K 数效应；它检验的只是**有限预算下的组织／归纳偏置**（决定0043 允许的估计对象）。TH-0001 继续封闭"加难即可制造容量分离"的论证。

## 3. 终点与估计量（沿用 v0 骨架）

- 每 episode：模型依序接收 `y_1..y_T`，末尾输出 16 类联合后验 `q(z_T|y_1:T)`；训练用 oracle 软目标交叉熵；评估损失 `L = KL(p_oracle‖q)/ln16`。
- 唯一 primary：`AUC_B = (1/B)Σ_j (u_{j+1}−u_j)[L(u_j)+L(u_{j+1})]/2`，检查点网格预锁，越低越好。
- 次要：`updates-to-ε`，未达记 `>B` 并报达标比例，不插补、不替代主终点。
- 估计量：`D_{k,c,s} = AUC(random_sparse) − AUC(block)`；`β_c = (D_{4,c} − D_{2,c})/ln2`；`I = β_F − β_X`；训练种子为推断单位。三分支：95% 区间下界 `> δ_min` 支持；上界 `< δ_min` 否定最小有用预测（另行如实报告可能的正向小效应）；跨越则不确定。

## 4. 资格门（对 v0 的关键修正：要求真实动态范围）

v0 的门只要求控制"能达 ε"。这检测不出 §1 那类无作用面任务。v1 要求**每个 K×F/X 单元**同时满足：

1. **未训练**模型 `L(u₀)` 显著高于 ε（上界远离阈值）；
2. **实际主控制**（保度随机稀疏）在预注册的**早期检查点**仍显著高于 ε —— 即学习确实在预算内发生，而不是瞬间触底；
3. 实际主控制在预算 B 内达到 ε，且达标时间的中位数落在预注册区间 `[τ_lo, τ_hi] ⊂ (0, B)`；
4. dense H64 guard 达 ε（任务可学）；
5. oracle 正确性独立重推（F 的四链分解与 X 的 16 态前向在固定小例上逐位核对）；
6. 状态、有效／分配参数、同 kernel 执行形状与实测 p50 时延符合预注册护栏；
7. F/X 的**可达到难度**（oracle 平均后验熵与 `L` 的可达下界）落在预注册容差内；超出容差则该单元停止，**不改终点、不扫 J、不合并条件**。

任一单元失败 → 停止资格轮，只关闭该固定任务规格，不启动正式效果轮。**资格流与正式流分离**，所有数值（`B, ε, δ_min, τ_lo, τ_hi, β, λ, J₀, T`、种子数、bootstrap、容差）在资格流解封前冻结。

## 5. 功效与不可行性前置声明

`I` 是**四重差分**（臂 × K × 条件）。要求：正式种子数由基于**配对**结构的预注册功效计算确定（同一种子在全部 8 个单元共用 batch 与流，以利用相关性）；若在预注册的可行种子数上限内，`δ_min` 对应的检验功效低于预注册水平，则**本设计判定为不可行并停止**，不得事后降低 `δ_min` 或改用单条件点比较。此项在数值协议阶段必须以数字落实，本稿不虚构数值。

## 6. 对称性／可辨识性设计诊断（不是语义主张）

块臂若"共享输入投影 ＋ 块对角递归 ＋ 相同初值"会退化为 K 个同构副本，从而无组织差异可言。v1 的处理：

- 两臂**总参数、张量形状、kernel 形状相同**；块臂的输入投影与递归连接按块组织，控制臂用**同度数分布**的随机稀疏结构；主对照与候选都记录分配／有效参数。
- 资格轮内做**设计有效性诊断**：检查块臂各块对同一输入的输出是否坍缩为同构（预注册 PASS/FAIL 与阈值）。该诊断只判断"操纵是否真的生效"，**不**推断槽的假设语义，也不构成 H3-semantic 或 Gate 3 证据。

## 7. 与决定0049 的关系与最强拒绝

- 本生成器是**新注册的生成器**（时间演化 + 耦合矩阵条件），不是对已关闭 EXP-0013 阶段显露生成器的再参数化；两条件的关系是否满足 0049 的"独立研究问题"须**独立前瞻裁定**（v0 的该项裁定请求因缺具体矩阵与机制论证未获通过，本稿补齐了矩阵、机制论证与决策规则，须重新送审）。
- **最强拒绝**：(a) F/X 的联合熵与难度不同，交互可能只是难度差异；(b) 控制学习失败或有效参数随 K 变化；(c) 同 kernel 不保证实测时延相等；(d) 结果可能只是已知"任务相关性 × 模块结构"规律的复现。对应处理：§4.7 难度容差、§4.1–4.3 真实动态范围门、§4.6 实测时延、§7 先例边界。
