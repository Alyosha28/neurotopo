# CAL-0002: hidden source reliability calibration

2026-09-24. This exploratory revision responds to CAL-0001's documented failure: displayed reliabilities reduced Bayesian belief updating to four easily learned accumulated weights. It is not a formal architecture comparison and cannot change EXP-0004 or Gate 1. Prior-art overlap: `research/prior_art/belief_update_benchmarks.md`.

One episode samples a content hypothesis `H∈{0,1,2,3}` and a hidden source regime `R∈{0,1}`, both uniform and fixed within the episode. Eight evidence cues arrive, four before and four after an intermediate query. Each half contains two cues from each of two visible sources in randomized order. The source equal to `R` reports the true H with probability 0.80; the other reports it with probability 0.40; otherwise a different H is chosen uniformly. The model observes source ID and cue, not R or the reliability values. Each evidence token is followed by one tagged, independent distractor. The exact target at each query is the eight-class posterior `P(H,R | observed evidence)`, with H and R marginals reported separately. A one-cue, fixed-source and previous-belief rule are shortcut controls.

The independent analytic simulation seed 29001 was used before this written plan to inspect five reliability pairs. For 0.80/0.40 on 100,000 episodes with four-plus-four informative cues, the approximate full-information accuracies were H 92.45%, R 83.66%, joint 81.58%; last-cue true-H accuracy 59.70%; H-MAP changes 18.65%. These are design calibration numbers, not held-out scientific evidence. They suggest a joint task with real uncertainty and late revision, while leaving open the decisive question: can a strong single H64 GRU still learn the entire joint posterior almost exactly?

Freeze for this calibration: generator parameters above; GRU H64 dense, eight-output joint soft-target loss at early and final query, batch128, Adam0.003, gradient clip1, 1,500 updates, model seeds201–203 with independent `291000+seed` training streams. Validation seed292001 and separate calibration seed293001; none overlaps CAL-0001 or any later formal comparison. Monitor only at steps500/1000/1500; no best-checkpoint choice. Run exact oracle and shortcuts on the separate calibration set, then evaluate every final model on identical episodes. Record source/script hashes, RNG streams, loss, posterior KL, true joint/H/R accuracy, oracle-MAP agreement, inference resources and runtime.

Decision for task design only: if any final model KL to the exact joint posterior is below0.01 nat, this configuration is treated as saturated and is not promoted to an architecture experiment. If every model's final KL exceeds0.20 or joint MAP agreement stays below0.70, the fixed budget failed to establish baseline learning and this configuration is also not promoted. Values between these bounds warrant further independent benchmark qualification, not an M3 result or Gate 1 advancement. Do not select a seed, cue order, metric or reliability pair after seeing M3 results; M3 is not run in this calibration.
