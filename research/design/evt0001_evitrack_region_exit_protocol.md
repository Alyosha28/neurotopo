# EVT-0001：EviTrack 公布参数的歧义区停留时间零训练检查

2026-09-24，在运行采样前保存。唯一问题：按 [arXiv:2605.19283v1](https://arxiv.org/html/2605.19283) 附录固定的 `a=3,V0=.06,Δt=1,σz=.05,d=2,z0~N(0,1)`，有多少未经筛选的路径首次离开 `|z|≤d` 的偶发射/正负不可辨区发生在30步之后？正文一处称 `a>d` 仍停留 non-injective，紧接着又称井在歧义区外；这可由 `±3` 与 `±2` 直接核对。此任务只查**潜在状态首次出区**，不计算观测、后验或作者定义的 `t_DD`，不能把出区时刻等同消歧时刻，也不能推翻作者论文数值。

独立 NumPy `PCG64` 默认生成器种子20260924，100,000条路径；每路径 `z0~N(0,1)`，已在 `|z0|>2` 者首次出区记为0；其余按论文 `z_t = z_(t−1)−.06 z_(t−1)(z_(t−1)^2−9)+.05 ε_t`、`ε~N(0,1)` 更新，至首次 `|z_t|>2` 或 t=200。按固定时点0、5、10、20、30、80、140、170、200报告累计首次出区比例与仍在区比例；记录所有100,000条的计数、seed、源码哈希、运行耗时。只更新尚未出区的路径，不会为已出区路径进一步采随机数；因此该流只用于**本检查**，不能当模型训练/正式评估流。最多30秒；非有限值、样本数不足或超时为 `AUDIT_FAILED`，不重新选seed。

若到30步已有≥99%路径首次出区，标 `EARLY_EXIT_PROXY`：在作者公布参数下，未经筛选的轨迹几乎都很早离开偶发射区，G1-DD-0001 不可假定作者30–170消歧层对自然分布普遍存在；必须在任何模型训练前另做独立后验/`t_DD` 资格，且如稀有筛选所需样本数超预算应关该任务。若到30步仍在区≥10%，标 `REGION_PERSISTENCE_PLAUSIBLE`，只允许继续后验资格；其余 `INCONCLUSIVE_PROXY`。这三个标签都不批准候选模型，不改作者参数、不选择有利路径/任务，也不把 EviTrack 已报告结果视为本项目复现。最强反驳：出区是一个可观察性代理，观测噪声和滤波先验可使 posterior `t_DD` 不等于首次出区；因此本检查最多决定是否值得继续实现昂贵数值 oracle，不能独自断言真实消歧分布。
