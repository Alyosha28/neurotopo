## 1. 问题与判据假设

同 v1：既有四次"触顶"（CAL-0001 `0.0003–0.0005` nat、CAL-0002 `0.0018–0.0023` nat、CAL-0006 `0.06497` 对 `0.08`、EXP-0009 `0.012463` 对 `0.07`）共享同一形式——**精确后验只依赖少数充分统计量**（TH-0001：仅 4/8 个 log 权重的构造性精确滤波），H64 控制能表示并学到。

**待检验判据**：末端余量要求精确后验**超出匹配状态的表示能力**，或**难以在预算内优化**。v1 把两者都当作余量的充分原因，被审查判为"许可欠训练"；v2 用**平台判据**把二者分开（§4）。

## 2. 固定配置菜单（v2：拆开混淆轴）

|---|---|---|---|---|---|
| C1 | 4 | 16 | 0.7 | 铁磁环 | **仅管线健全性**；**不得**作为余量答案 |
| C2 | 8 | 16 | 0.7 | 铁磁环 | 容量轴（与 C1 同 `T,λ`，只变 `M`） |
| C3 | 8 | 32 | 0.4 | 铁磁环 | 视界／证据轴（与 C2 同 `M`，只变 `T,λ`） |

共同冻结：`β=0.8`、`|J|=0.25`、`z_t∈{−1,+1}^M`、初始各维独立均匀、`y_t|z_t ~ N(λ z_t, I_M)`、转移 `p(z_t|z_{t−1}) ∝ exp(β·z_t·z_{t−1} + J·Σ_e s_e z_i z_j)`、图种子固定。**菜单固定为 4 项，不扩充**：不追加 `M/T/λ/β/J` 取值，不因结果重选图种子。答案按 `C2 → C3 → C4` 顺序取第一个 `HEADROOM`；`C1` 永不作为答案。

## 3. 决策统计量（审查 R6 要求：完全指定）

- 逐 episode 的**末步后验** KL（nat）：`KL(p_oracle(z_T|y_1:T) ‖ softmax(logits))`；
- 决策量 = 该 KL 在**预注册的 512 条 held-out episodes** 上的均值；
- **episode 级蒙特卡洛误差**（均值标准误）与 **seed 间离散**分别报告，不混同；
- 3 个 seed 的区间：95% **t 区间**；同时报告 min–max 作为稳健性说明；
- 按 `C2→C3→C4` 的顺序检验是**选择规则**，不主张族错误率控制；四个配置全部报告，不隐藏未过门者。

## 4. 门槛（解封前冻结；v2：绝对 + 相对 + 学习量 + 平台）

| 符号 | 值 | 含义 |
|---|---|---|
| `ε_abs` | `0.05` nat | 绝对残余下限（末端 KL 的 95% 区间下界须高于此值） |
| `ρ` | `0.05` | 相对残余：末端 KL 须高于该配置**自身未训练 KL** 的 5%（防止 `ln 2^M` 尺度把余量变成定义产物） |
| `κ` | `0.90` | 学习量：`(未训练 KL − 末端 KL)/未训练 KL ≥ 0.90`，排除 `LEARNING_FAILURE` **并排除高位早停**（在 500 步即停在半程水平者判 `LEARNING_FAILURE`，不得判 `HEADROOM`） |
| `τ_plateau` | `0.01` nat | 平台，三条件同时成立：**尾段平坦** `|KL(u_i)−KL(u_{i+1})| ≤ τ`（对 500→1000、1000→2000、2000→4000）；**无逐步上升** `KL(u_{i+1}) ≤ KL(u_i) + τ`（对 250→500、500→1000、1000→2000、2000→4000）；**无净上升** `KL(4000) ≤ KL(250)`（**无 τ 余量**）。全部检查点 KL 在 held-out 决策流上测量、绑定到该 seed 的**选定 LR**；`0/250/500/1000/2000/4000` 全部公布。违反即 `INCONCLUSIVE`，**不得**判 `HEADROOM` |
| `LR_TOL` | `0.02` nat | **跨 LR 一致**：另一注册 LR 的末端 KL **必须 > `ε_abs`（即它也未饱和）**，且（与选定 LR 之差 ≤ `LR_TOL` **或**该 LR 学习量 ≥ `κ`）。否则 `HEADROOM` 不成立——第二 LR 已饱和时，本配置不得声称有残余 |
| `未训练良态上界` | `ln 2^M + 0.5` nat | **尺度上界（逐 seed）**：未训练 KL 不得超过 `ln 2^M + 0.5`。未训练读出近均匀，故其 KL 由后验熵决定，此界用于捕捉初始化异常，**不**依赖熵恒等式的精确成立 |
| 熵恒等式残差（**诊断，非门**） | 报告 | `\|未训练 KL − (ln 2^M − H(后验))\|`，其中 **`H(后验)` 与未训练 KL 取自同一条 512-episode 评估流**；该残差同时反映随机读出自身的离散度，故只报告、不设门（第五轮审查指出：v6 把该残差当门且 `H` 取自另一条流，导致 C2/C4 在训练前被误判 `INCONCLUSIVE`） |
| `未训练下限` | `0.10` nat | 若某配置的未训练 KL 低于此值，则相对门槛病态 → 该配置判 `INCONCLUSIVE` 并如实报告 |

**逐 seed 聚合（明确）**：`ρ`、`κ`、跨 LR 一致门、平台门、**未训练下限与良态上界**均**逐 seed 计算，且要求每个 seed 都通过**；`ε_abs` 门用 3 个 seed 的 95% t 区间下界。均值另行报告，不用于判词。

**`ρ` 的良定性**：`κ=0.90` 蕴含残余分数 ≤ `0.10`，`ρ=0.05` 要求残余 > `0.05`，故 `ρ` 在 `(0.05, 0.10]` 区间内**必然可绑定**；分母由未训练下限 `0.10` 与良态上界 `ln 2^M + 0.5` 双向约束。

**跨 LR 一致门（第三轮审查要求替换原"LR 不敏感"写法）**：仅要求另一 LR 的残余分数 > `ρ` 不足——那允许另一 LR 几乎没学到。`HEADROOM` 要求：选定 LR 与另一注册 LR 的末端 KL 相差 ≤ `LR_TOL = 0.02` nat，**或**另一 LR 的学习量也 ≥ `κ = 0.90`。两个 LR 的末端 KL 全部公布。

**定义（第三轮审查要求明确）**：`未训练 KL` ＝ 该 seed 在 update 0 时于 held-out 决策流上的末步后验 KL；`残余分数` ＝ 选定 LR 的末端 KL ÷ 同 seed 的未训练 KL；`学习量` ＝ 1 − 残余分数。`ρ`、`κ`、平台门、跨 LR 门**逐 seed 计算并逐 seed 绑定到该 seed 的选定 LR**；`未训练下限 0.10` 亦**逐 seed** 检查。

**判词分支（顺序固定；每个 `INCONCLUSIVE` 必须带具体 `reason` 代码，不得一律记为"预算不足"）**：
1. 若未训练 KL 越出 `[未训练下限, 良态上界]` → `INCONCLUSIVE`，`reason = ILL_CONDITIONED_UNTRAINED_SCALE`；
2. 否则若**学习量门未过**（任一 seed 的 `learned_fraction < κ`）→ **`LEARNING_FAILURE`**（不论末端 KL 多高——"学不会"绝不能被记为"预算不足"）；
3. 否则若末端 KL 的区间上界 ≤ `ε_abs` → `SATURATED`；
4. 否则若全部门槛通过 → `HEADROOM`；
5. 其余 → `INCONCLUSIVE`，并按具体原因记 `reason`：`PLATEAU_GATE_FAILED`（平台门未过）、`OTHER_GATE_FAILED`（其余门未过）、`BUDGET_ADEQUACY_ANCHOR_FAILED`（被 C1 锚点降级）。**只有 `BUDGET_ADEQUACY_ANCHOR_FAILED` 才可被表述为预算问题**；平台失败是轨迹问题、`OTHER_GATE_FAILED` 主要是 `n=3` 下 `ε_abs` t 区间跨零的**精度限制**（不得一律记为标定缺陷）。

## 5. 控制、预算与学习率选择（审查 R7 要求）

- 控制：稠密 GRU，`H=64`，逐步输入 `y_t`，末端线性读出到 `2^M`；本项目一贯的强单流控制族。**初始化冻结**：PyTorch 默认初始化，`torch.manual_seed(seed)`，不额外设初值、不做多次重启。
- 训练：oracle 软目标交叉熵；batch 128；`B=4000`；Adam；CPU float32 单线程确定性；种子 `{0,1,2}`。
- **学习率 `{1e-3, 3e-3}` 的选取规则已冻结**：只用训练侧独立验证流（256 episodes，与 held-out 流不同源），统计量为**末次更新（`B=4000`）后的验证流末端 KL**，按 `(配置, seed)` 各自选取，**平局取较小 LR**；**两个 LR 的末端 KL 全部报告**。决策量只取自 held-out 流，选取不触碰该流。
- 数据流：训练 4096 episodes、验证 256、评估 512，均由 `SeedSequence([20260924, graph_seed, seed])` 派生并记录根。

## 6. oracle 正确性（多轮审查要求：覆盖生产视界、公布全部检查、独立重建定义）

三实现并报：① log-space 前向递推（生产视界）；② **线性概率 + 逐步重标定**前向（与 ① 无共享算术路径，生产视界）；③ 轨迹枚举（短视界）。**必须公布**：逐时步后验最大绝对差（① 对 ②，生产视界全程）、软目标归一化残差 `|Σp − 1|`、KL 双路计算差（同一参考分布下由 ① 与 ② 的后验各算一次）、最终后验最大绝对差、枚举核对差、各配置后验熵，以及 §6 的独立重建三项（索引、图与符号、发射比值恒等式）。任何一项超 `1e-12` 即停止运行。

**状态索引约定（须写明并被核对）**：第 `i` 行、第 `b` 维取 `+1` 当且仅当 `i` 的第 `(M−1−b)` 位为 1，否则 `−1`。

## 7. 最强反驳与处理

- **R-a 余量是欠训练产物** → `τ_plateau` 平台门 + `κ` 学习量门 + 最优 LR 选取（在独立验证流上）。
- **R-b `M=8` 实现有误** → §6 三实现 + 生产视界第二实现。
- **R-c 选择偏差** → 菜单固定 4 项、全部报告、按预注册顺序取第一个过门者、不追加搜索。
- **R-d 被误用为架构证据** → §9 禁止推论。
- **R-e 绝对阈值尺度依赖** → `ρ` 相对门与 `ε_abs` 同时要求。
- **R-f 全失败即关闭族可能过强** → 关闭判词只覆盖**这 4 个固定配置**，并须与"预算不足"区分（`INCONCLUSIVE` 不构成关闭）。
- **R-g 平台判据只测差值会放行发散或高位早停** → 已改为双侧、覆盖末两段并要求末点不高于半程点（见 §4）。
- **R-h 残余可能只是 LR 未调够** → 已改为跨 LR 一致门（另一注册 LR 须未饱和，且与选定 LR 差 ≤ `LR_TOL` 或该 LR 学习量 ≥ `κ`）。
- **R-i "学不会"被误记为"预算不足"** → 判词分支已把 `LEARNING_FAILURE` 提前到第二位，且不依赖末端 KL 水平。
- **R-j 欠训练仍可能被判 `HEADROOM`** → `κ` 提高到 `0.90`（排除高位早停）、跨 LR 一致门（排除"小 LR 没学完"）、完整网格平台门（排除高位早停与发散）三者同时生效。
- **R-k 预算充分性只有断言** → 已实现为**可执行锚点**：`C1` 必须在同一 `B=4000` 下判 `SATURATED`；否则 `C2/C3/C4` 一律降级为 `INCONCLUSIVE`（`downgraded_by = budget_adequacy_anchor_failed`）。**锚点作用范围（第四轮审查要求明确）**：它只是**必要条件**——只能降级、**不能**证明 `C2/C3/C4` 的预算充分性；C1 是最容易的配置，其饱和不足以认证 `M=8/T=32` 或阻挫图。本筛查**不提供**任何能认证 C2–C4 预算充分性的观测，该限制必须在结果中如实报告。
- **R-m 平台判据仍容许缓慢漂移** → 已加"无逐步上升"与**无 τ 余量的无净上升**，并纳入 250 检查点。
- **R-n 未训练 KL 只有下限没有上界** → 已加**良态上界 `ln 2^M + 0.5`**（逐 seed）并冻结初始化；熵恒等式改为诊断项，且 `H(后验)` 与未训练 KL 取自**同一条评估流**（v6 曾因两条流不一致而误判 C2/C4，见第五轮审查 R1）。
- **R-p `INCONCLUSIVE` 被一律记为预算不足** → 已为每个 `INCONCLUSIVE` 增加 `reason` 代码并分类归档（第五轮审查 R2）。
- **R-q 版本账目不清** → 见 §10 修订台账。
- **R-o pilot 曾发出判词形状字段** → pilot 模式不再产出 `aggregate`（记为 `NOT_APPLICABLE_ENGINEERING_PILOT`），不得被引用为筛查结果。
- **R-l 共享构造错误无法被枚举实现发现** → **模型定义独立核对**分两层：(i) 四项结构性恒等式（转移行和、`J=0` 时核等于逐维两状态核之积、能量对暴力边循环、发射对展开二次式）；(ii) **从 §2 规则独立重建**：状态索引按文档约定逐位解码、图与符号按构造规则独立重写并比对边集与符号、发射比值恒等式 `logp(s) − logp(s′) = 2λ·y_b·s_b`（单维翻转）。**并如实披露**：枚举 oracle 与实现 ② 均复用同一 `transition_matrix`／`emission_loglik` 定义，故 (i) 类恒等式无法发现共享语义错误，(ii) 类重建是为此设置的独立路径。

## 8. 判定与作用

- 任一 `C2/C3/C4` 判 `HEADROOM` → 记录"存在保留末端余量的可接受任务配置"，把该配置连同数字交独立审查，由其决定是否可作为后续候选设计基础。
- `C2/C3/C4` 全部 `SATURATED` → 关闭**这 4 个固定配置**（不改 `M/T/λ` 再试），并记录"在本项目资源约束与该生成器族下未找到保留末端余量的配置"；同时记录若要构造真正受表示限制的任务需要什么（另立问题）。
- 出现 `INCONCLUSIVE` → **不关闭**，但须**按 `reason` 分别归档**：锚点降级记为预算问题；平台失败记为轨迹/收敛问题；其他门失败记为门槛标定问题。不得把三者合并为"预算不足"。
