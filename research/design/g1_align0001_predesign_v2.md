## 1. 为什么需要一个新操纵（不变）

GPI-0001 的关闭审查把"块组织一致劣于随机掩码"收窄为**"该掩码式操纵下未检测到优势"**：密度匹配只固定非零个数，**掩码位置与跨组混合量相混淆**。

**本设计的做法与代价**：让两臂跨块边**都为 0**，把混淆变量固定为常数。代价是**递归组织在两臂间不再有变异**——故：

> **本设计不检验递归组织（拓扑）本身。** 它检验的是**输入到分块的维度路由是否与任务的因子分解结构对齐**。全文一律不得表述为"组织对齐"或"模块化有效"。

## 2. 候选：输入—分块路由与任务因子分解的对齐

任务组 `A={0,1,2}`、`B={3,4,5}`。**冻结划分（与脚本逐字节一致，并有断言）**：

| `K` | 对齐 `S` | 跨组 `U` | 跨组维数 |
|---|---|---|---|
| 2 | `(012)(345)` | `(125)(034)` | **6 / 6** |
| 4 | `(01)(2)(34)(5)` | `(05)(23)(4)(1)` | **4 / 6** |

**块身份与共享矩阵（审查 I13 更正）**：两臂共享的是**块大小序列相同的同构块对角矩阵**；因两臂的划分不同，**块索引按各自划分重排**（块身份随臂置换）。故正确表述是"**同一矩阵的块置换**"，而非"逐元素相同的同一矩阵"。自同构论证的射程据此限定为：在（任务图 × 分块结构）上，两臂**不是同一问题的重标号**（§5）。

## 3. 预测与主终点（本版按 R-c/R-f 重写）

**F 中的 `β_F > 0` 是构造的解析推论，不是经验预测。** 依据**主单元 `K=4`** 的实测投影代价（§4）：F 中对齐划分 `0.0438`、跨组 `0.0734` → **构造下限 `0.0296`**；且 S 臂本身**也是有损的**（`0.0438 ≠ 0`）。（v1 曾用 `K=2` 的 `0.0000/0.0416` 论证，那属于已被降级的单元；本版已改。）

**主终点的经验内容在 `β_X`**：X 中两臂都不可分解，**没有**由构造保证的方向。

**主终点（不再扣除）**：

```text
I = (KL_U − KL_S)_F − (KL_U − KL_S)_X          末端配对 KL 差之差，配对 CI
表示代价成分（披露上界，冻结）= 0.0388，配对 95% CI [0.0285, 0.0508]
```

**`SUPPORTED` 要求 `I` 的 95% CI 下界 > `0.0508`**（即观测效应须**高于容量通道的区间上界**），**并且**满足 §7 的独立优化难度探针条件。**不做任何常数扣除**；"超出容量"的措辞**禁止**使用。

**`β_X` 的判据（R-c）**：`β_X` 的 95% 上界**由资格流实测的逐 seed `β_X` 的 95% CI 给出**；§4 的解析值仅作**构造成分先验**，**不**作为独立证据，也**不**作为判据来源。

## 4. 解析分解（以冻结划分重算；决定性前置测量）

脚本 `scripts/align0001_analytic_decomposition.py`；机器输出 `research/design/structural_task_probe/align0001_analytic_decomposition.json`。对精确联合后验计算"给定 `θ` 的条件独立块分解"族的最优投影 KL（闭式）：

| 划分 | F 投影代价 | X 投影代价 |
|---|---|---|
| 对齐 `K=2` | `0.0000` | `0.0768` |
| 跨组 `K=2` | `0.0416` | `0.0542` |
| 对齐 `K=4` | `0.0438` | `0.0821` |
| 跨组 `K=4` | `0.0734` | `0.0729` |

**表示代价成分（配对 bootstrap，同一 episode 上两划分取差）**：

| `K` | F 侧额外代价 | X 侧额外代价 | **成分** | 配对 95% CI | 半宽 |
|---|---|---|---|---|---|
| 2 | `0.0416` | `−0.0226` | **`0.0642`** | `[0.0501, 0.0799]` | `0.0149` |
| 4 | `0.0296` | `−0.0092` | **`0.0388`** | `[0.0285, 0.0508]` | `0.0111` |

**读数**：

1. **`K=2` 被混淆**：成分 `0.0642` **超过 `δ_min = 0.05`**，且由构造保证 → `K=2` **描述性**，不参与判词。
2. **`K=4` 的成分 `0.0388` 亦不可忽略**（约为 `δ_min` 的 78%），且其 CI **不含零**。故**不能**把它当作可扣除的修正项；它作为**披露上界**进入 §3 的判据。
3. 配对 bootstrap 把 MC 半宽从"四区间半宽相加"的 `0.083` 收到 **`0.0111`**（7.5 倍）。
4. **X 侧对齐划分的投影代价反而更高**（`0.0768 > 0.0542`；`0.0821 > 0.0729`）——"对齐"在 X 中表示上不利，为 `β_X ≈ 0` 提供构造侧理由，**但不保证**学习后仍为零。

**边界**：以上是**解析容量**陈述，不是学习结果；**可加性未被证明**（见 §7 探针）。

**声明消耗轴**：S/U 两臂在**所有**轴上比值恒为 `1.000`。

## 6. 任务与难度（本版按 R-h 补齐出处）

复用 GPI-0001 已证非局部的族与冻结 F/X 对：`M=6`、6 节点 6 边、度 2、**`T=64`**、32 点 `θ` 网格 `[0,0.6]`、步长 `0.01935`、`β=0.8`、`λ=0.7`；目标为 **`p(θ | y_1:T)`**；**只改边的位置**。

**难度差（不得在资格流复算前写"超过 ε_abs"）**：

| 量 | 值 | 来源 |
|---|---|---|
| `θ` 后验熵 F / X | `2.649` / `2.6773`（本轮 200 episodes） | `align0001_analytic_decomposition.json` |
| 差 | `0.0283` nat | 同上 |
| 400-episode 版 F / X | `2.6251` / `2.6929`，差 `0.0678` | `gpi_v1_analytic_fx.json` |

**注册须写入**所登记的**具体版本**、来源文件 **sha256** 与 bootstrap CI。**在资格流复算前，不得写入"超过 `ε_abs`"**——两个版本给出相反的结论（`0.0283 < 0.05` 而 `0.0678 > 0.05`），v1 正是在此处出错。

**另一项更正（沿用 v1）**：`gpi_v1_analytic_fx.json` 的 `theta_posterior_entropy_nats` 与 `uniform_baseline_kl_nats` **代数恒等**（`KL(uniform‖p) = ln32 − H(p)`），其"measured-matched … ratio 1.088"只依赖**单一量**，**禁止**沿用该措辞。

**难度不调节对齐效应的可证伪检查**：见 §7 的逐 seed 协变量与单调性检验。

## 7. 主终点与估计量（本版按 R-d/R-e/R-f 重写）

| 项 | 值 |
|---|---|
| 统计量 | 逐 seed 配对 `d_i = [(KL_U − KL_S)_F − (KL_U − KL_S)_X]`，取均值 `I`；双侧 95% **t** 区间，`df = n−1` |
| `n` | **8 seeds/单元**（主单元 `K=4` × {F, X}） |
| `alpha` | `0.05`（双侧） |
| `δ_min` | **`0.05` nat**（锚定项目既有 `ε_abs`，非本轮数据） |
| `SUPPORTED` 门 | `I` 的 95% CI **下界 > `0.0508`**（§4 冻结的容量上界），**且**优化难度探针条件成立 |
| **独立优化难度探针（R-d，新增）** | 与终点**独立**的臂级探针：每臂每条件达到固定 KL 阈值所需的 **steps**（阈值预注册）。**要求其臂差（`U−S`）的 95% CI 含 0**；若该 CI 不含 0，`I` 须按**优化难度**解释，**不得**表述为对齐收益 |
| sd 出处 | GPI-0001 pilot 的逐 seed sd `0.0211`（3 seeds）；**预先作 `√2` 保守放大**为 `0.0298`，并声明它按**差之差**使用 |
| 功效 | `δ_min` 处 `0.8`；按 `sd=0.0298`、`n=8`、双侧 `alpha=0.05` 计 |
| **MDD 约定（R-f）** | MDD 定义为**在 `alpha=0.05` 双侧、功率 `0.80` 下可分辨的最小真值**；`MDD = (t_{0.975,n−1} + t_{0.80,n−1}) · sd/√n` |
| 升级规则 | 若资格流实测逐 seed sd `> 0.0441`，**允许一次**预注册升到 `n=16`；仍不满足则 `INCONCLUSIVE`。**不得**事后下调 `δ_min` |
| **协变量（R-e）** | 改为**逐 seed** 量（逐 seed 末端信念熵），**不是**每条件标量。`df = n−2` **仅当**资格流显示该协变量在 seed 间有方差时使用；否则退回 `df = n−1` 并**放弃**协变量调整 |
| 单调性检验 | 方向：`S−U` 对逐 seed 难度的**斜率**；统计量：该斜率的 95% CI；阈值：**CI 含 0 为通过**，不含 0 则 `I` 按 `INCONCLUSIVE` |
| `K=2` | **描述性**，不参与判词 |
| 冻结时点 | 全部数值在任何资格样本**之前**冻结；资格后不得修改 |

**终点类型**：**末端**配对 KL，**不是**学习效率终点——不触碰决定0062 留给项目轨的未决问题。

## 8. 资格门

复用 CAL-0008 加固版（`ε_abs`、`ρ`、`κ`、平台门、跨 LR 一致门、逐 seed 聚合、`INCONCLUSIVE` 原因码、`C1` 锚点、对称坍缩停止项）。新增：

1. **预算加倍门**：`B` 与 `2B` 下末端 KL **都**须 > `ε_abs`。
2. **非局部性前置门**：**F 的 `gap(16)` 的 95% 区间下界 ≥ `0.20`**，且 `gap(k)` 曲线须覆盖到 **`k = T = 64`**。已冻结实测 F `0.4023 [0.3578, 0.4421]` → 通过。三个 `gap(16)` 数值的归属：`0.350` 属 **KSI**、`0.4097` 属 **F**、`0.3846` 属 **X**。
3. **全轴比值门**：pilot 全轴比值须落在 `1.000 ± 0.02`（时延须 `repeats ≥ 101`）。
4. **解析估计的 MC 稳定性门（本版改名，R-f/I12）**：以**不同 MC 重复**复算 §4 的成分，检验其**稳定性**。**该门不检验可加性**，不得被表述为对表示代价的检验；可加性由 §7 的独立优化难度探针承担。差异来源：episodes、bootstrap 重复数、seed。
5. **对称降级规则（R-f，覆盖全部区间）**：对 **`K∈{2,4}` 同时生效**——
   - 复算成分 **`> 0.02`** → 该 `K` 单元**停止**（不得事后放宽阈值）；
   - `K=2` 复算 **`≤ δ_min`** → `K=2` **恢复为次级终点**并预注册其判词分支；
   - 落在 **`(δ_min, 0.02]`** → 该 `K` 单元保留但**只作描述性**，并在注册中写明。
6. **表示代价上界门**：`K=4` 的成分上界须在任何资格样本前冻结为 §4 的配对 CI 上界；资格流复算后若上界**升高**，`SUPPORTED` 门随之**升高**（保守方向），**不得**降低。

## 9. 判词分支

| 分支 | 条件 |
|---|---|
| `SUPPORTED` | `I` 的 95% CI 下界 > 冻结容量上界（`0.0508`），**且**优化难度探针臂差 CI 含 0，**且** `β_X` 的实测 95% 上界 ≤ `0.02`，**且**全部资格门与操作 guard 通过，**且**独立复核 seed 同向 |
| `PARTIALLY_SUPPORTED` | `I` 点估计为正但 CI 跨零，或 CI 下界 > 0 但未超过容量上界 |
| `FALSIFIED` | `I` 的 CI **上界 < 0** |
| `INCONCLUSIVE` | 任一资格门失败、`τ_term` 违反、`MDD > δ_min` 且 `n=16` 仍不足、单调性检验 CI 不含 0、优化难度探针臂差 CI 不含 0、或对称坍缩停止项触发 |

**`K=2` 的任何结果均不进入上述分支**（除非 §8.5 的恢复分支被合法触发）。

## 10. 最强拒绝

**主拒绝**：S 臂在 F 中的划分与 F 的组结构同构，故 F 侧收益可能来自"手工先验恰好匹配任务"。**本版处置**：承认其为**构造推论**；§4 给出构造下限 `0.0296` 并作为**披露**而非扣除；`SUPPORTED` 要求 `I` 超过**容量上界 `0.0508`**。

**次级拒绝（本版视为**未消除**）**：`S−U` 在 F 中可能只是**优化难度差**。v1 的常数扣除恰好把这个混淆项**当成**了主终点（审查 I4），故本版**放弃扣除**，改由 §7 的**独立优化难度探针**作为 `SUPPORTED` 的**必要条件**；**若探针显示臂差，`I` 一律按优化难度解释**。

**新增拒绝**：容量上界 `0.0508` 与 `δ_min = 0.05` 同量级，故本设计**只能检出大于容量通道的效应**；较小的真实对齐收益**不可分辨**。这是本设计的**固有分辨率上限**，须写入判词。

## 11. 禁止推论

不得得出：本设计检验了**递归组织/拓扑**；模块化有效；机制或方法新颖；H3 语义分工；生物图效应；自然任务泛化；由 512/2048 状态差读作机制收益；把本设计当作 GPI-0001 的追认或重开；使用"超出容量"措辞。结果**只**支持所测任务、种子与控制设置的范围。

## 13. 已知缺口
