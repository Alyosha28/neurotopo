# GPI-0001 v0 独立前瞻审查说明（送审前提交）

2026-09-24。本说明在送审前提交，规定本轮独立审查要回答什么、依据什么、不得得出什么。**它不是效果证据、不是注册、不是 Gate 通过或实验许可。**

## 问题

1. **设计是否自洽且可执行**：`GPI-0001 v0` 的生成器、F/X 结构因子、oracle、主对照、终点与估计量，是否构成一个**可数值否定**的设计？特别是 F（两块各一个 16 点网格参数）与 X（单一 256 点网格参数）是否真的在**图、字母表、观测模型、参数空间基数、增广状态数**上匹配，只差参数是否跨块共享？
2. **前提是否已被证据支持**：把目标从边缘潜变量后验换成全局参数后验（`gap(16)` 从 `0.024` 升到 `0.350` nat）是否足以支持"该任务不局部"的判断？`gap(16) ≥ 0.20` nat 这条前置门是否恰当？**"非局部"是否被误当成"不可压缩"？**
3. **claim track 与规则边界**：本稿自我声明为**新的独立研究问题**、**不主张 Gate 1 计分**、项目轨资格须另行裁定。该自我限定是否成立？一句话新问题（"组织收益随任务参数结构的可分解性而变"）的否定是否真的不被"多轨迹组织有益"蕴含（决定0062 条件 A1）？
4. **是否遗漏更强的拒绝或更省的替代设计**：是否存在更简单的解释、更强的反驳、或明显更省的设计（例如无需引入全局参数推断就能检验同一交互）？

## 输入范围

送审 packet 只含：本审查说明、`GPI-0001 v0` 设计全文、前提证据包（三个候选的非局部性探针数字与配置）。评审者**不得**浏览仓库其他内容、不得读取对话、不得运行代码或训练。

## 最强拒绝（审查须正面处理）

- **R1**：F/X 的差别可能只是"两个参数 vs 一个参数"的**难度差异**，不是"可分解性"这一结构属性；匹配参数空间基数并不等于匹配难度。
- **R2**：组织收益可能只是**容量或有效参数**差异，而非组织本身。
- **R3**：`p(θ|y_1:T)` 可能只是少数几个 log-odds，**64 维状态装得下**——非局部性探针不能证明不可压缩，因此本设计仍可能像 CAL-0008 一样饱和。
- **R4**：`p(θ|y_1:T)` 与 PF-RNN 等先例高度重叠，本设计**没有可主张的新意**。
- **R5**：本设计不产生项目 Gate 1 证据，却使用了项目轨的判据与资源匹配语言，可能被误读为项目轨候选。

## 判定规则

四项问题各给结论；整体给 `READY_FOR_NUMERIC_PROTOCOL` / `REVISE_BEFORE_DESIGN_FREEZE` / `REJECT` 之一。任何"通过"**不得**被读作实验许可、Gate 1 通过、候选有效性、先例新颖性，或对既有冻结判词的追认。若判 `REVISE`，须写出**可执行的最小修订**。
