# G1-DD-0001：外部延迟消歧任务上的显式候选轨迹（设计版）

2026-09-24，在任何本候选新代码或性能读取前保存。唯一问题：**在真正多峰且后期才可消歧的连续序列上，两条分离的可学习循环轨迹能否在相同总状态、参数、数据和执行计算下，优于一条连通循环状态及强稠密单流？** 这直接针对项目 Gate 1 的通用效应，而非 EXP-0010 温度旁支或已关闭的四值缓存/四模式小滤波任务。这里只是候选/任务合同；未注册 EXP、未实现或训练，必须先经独立设计审查。

## 外部任务与先例边界

使用 [Haq 2026 EviTrack 预印本](https://arxiv.org/html/2605.19283)公开的双势阱延迟消歧生成律，**不得称自创 benchmark**：`z_t ~ N(z_(t−1)−Δt V0 z_(t−1)(z_(t−1)^2−a^2), σ_z²)`，`x_t ~ N(h(z_t),σ_x²)`，`h(z)=z²` 当 `|z|≤d`，否则 `h(z)=z`；固定作者给出的 `a=3,V0=.06,Δt=1,σ_z=.05,d=2,σ_x=.12,T=200,z0~N(0,1)`。在歧义区正负盆地发射不可辨，晚期出区后才可分；作者论文报告其**真实已知世界模型**的 EviTrack 轨迹选择在匹配推理候选预算下优于 SIS/BPF。本项目新问题是端到端**学习**循环表示 vs 单流；不能把作者的效果据为己有，也不能把仅复制 EviTrack 计 Gate 1。

训练任务为每时刻给定 `x_1:t` 预测 `x_(t+1)` 的密度，主损失为一步预测负对数似然；不以真实 `z` 或消歧时间为模型输入/训练标签。独立高精度数值滤波仅生成评估用 oracle posterior/消歧时间，须与单独实现/收敛检查核对。作者的 `t_DD` 定义及 early/mid/late 区间与固定参数原样保留；作者按区间筛选100例的结果不能直接当本项目训练样本或我们独立复现。最终评价保留未筛选总体和按固定区间分层的后消歧预测 log-likelihood、真盆地概率/branch accuracy及在消歧前的校准；不能只挑作者有利切片。资格与正式随机流/种子完全隔离。

## 候选、主控制和参数/算子因子

候选 `DD-MB2`：H64 分成两条32维 block-mask GRU 轨迹，参数不共享、每步都完整执行两个候选更新；每轨迹以自己的旧状态产生下一观测的 Gaussian 均值/尺度预测，再用当前 `x_t` 的该预测 log density **累加**自己的证据分数 `s_t^k`，之后才按当前输入更新自己的 GRU 状态。归一化 `softmax(s_t^1,s_t^2)` 给下一步两个 Gaussian 的混合权重；输出为连续混合预测密度。`s_0^k=0,h_0=0`，不重采样、不适应、不通信、不提供盆地符号或真实潜变量。两轨迹不按标签硬编码为正/负，分量标签允许交换；必须监测分量坍缩、得分分离和在相反证据后的恢复，不能单凭隐向量距离称语义。

实际主对照 `DD-SC64`：同 H64、相同两个按32维分组的 Gaussian/证据分数头、相同计分递推及输出混合，唯一操作因子是把 block recurrent mask 改为保度/自环的**强连通** random mask。候选与主对照每个配对种子共用输入、初值张量、总递推状态64 floats、两个持续分数 floats、损失、优化器、样本/更新、内部步数和完整 GRU/头的执行算子形状；两者均做稠密运算并按实际操作记账。强连通只是图事实，不能预先断言控制功能上只有一个假设；需用干预/轨迹指标诊断。`DD-D64` 稠密 H64、同混合头/分数、同分配参数与执行形状但更多有效 recurrent 参数，是强单流敏感性对照，按自身入度正确初始化；不冒充有效参数匹配。还须报告直接全状态稠密 mixture-head GRU 作为读出限制敏感性，不能只选择弱控制。

候选机制与 PF-RNN 带权粒子、EviTrack 有分数轨迹、RIMs 模块循环直接重叠；无新颖性主张。因相同输出/证据计分装置也给所有神经对照，主因果因素只限**独立递推轨迹 vs 连通递推状态**。EviTrack、SIS/BPF在已知模型下的固定推理预算结果应作为参考性能和机制边界，不拿它们与学习模型的训练计算作伪公平比较。若项目条件要求这些参考机制的数值基线，在正式实验前定义和验证，不能观察结果后挑选。

## 事前可否定预测、资格和决定

预测方向：在固定外部任务、相同训练预算和严格资源匹配下，`DD-MB2` 相对 `DD-SC64` 的**总体**一步预测 NLL 更低，且在固定后消歧窗内优于 `DD-SC64` 和强稠密控制；早期歧义期不应靠过度自信换优势。若仅匹配稀疏控制获益，不能称强单流普遍优势。任何 Gate 1 判定还须独立复核，而且只意味着此类可学习多轨迹在这个外部任务上的**可复制受限收益**，不是新机制、SAE或语言推理能力。

在任何候选正式效果训练之前，先冻结唯一任务配置（作者参数，不扫描噪声/时长/井深）、训练更新预算、有效与分配参数/score状态/缓存/推理执行操作、独立资格种子、正式种子、数值 oracle 的精度容差、实际 `DD-SC64` 与强稠密控制的可学习性和相对oracle余量窗口、结果样本单位、预写效应阈值和成功/失败/贴边判词。资格阶段**只运行真实主控制及强控制**，不看候选结果；失败就关闭当前任务/预算配置，不改作者参数寻找有利余量。评估先固定所有轨迹，包括未消歧者；按 `t_DD` 筛选的条件结果必须另报选择比例。工程预检可用与所有研究 seed 隔离的微型流。正式协议和 runner 必须强制资格过门后才允许候选训练，并记录失败尝试；不能沿用会先跑完全部种子的旧 `study` runner。

最强拒绝：外部先例已做有分数轨迹/双势阱，两个可学习 GRU 块加混合头可能只是 PF-RNN/EviTrack 的低保真改造；强连通 `DD-SC64` 也能在64维内模拟两个假设，分数/头本身已是多候选装置，因而所测差异可能是连接正则化而非“必须有两条轨迹”。相同 H64不等于相同学习能力；论文外部任务可能让任何神经控制或候选都无法在固定预算学习。独立批评若发现上述问题不能靠实际主控制资格、匹配和明示范围解决，判 `NO_GO_BEFORE_TRAINING`，不编程或跑任务；若可解决，只允许进入带数值阈值和有限预算的正式协议设计，不得把此纸面候选算项目过门。
