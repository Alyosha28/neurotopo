# G1-BOUND-0001 独立前瞻设计审查说明（送审前提交）

2026-09-24。本说明在送审前提交。**不是效果证据、不是注册、不是训练许可、不改变 Gate 1。**

## 背景（审查者须知道的最少事实）

G1-ALIGN-0001（F/X 条件对上的"对齐是否有益"）经三轮独立审查后被**停止**（决定0072）：容量通道 `0.0388 [0.0285, 0.0508]` 与 `δ_min = 0.05` **同量级**，且门槛估计量错位——`0.0388` 是**最优因子化投影**的 KL 差，而终点由**被训练模型**构成，逐臂 `KL_trained ≥ 投影代价` 不能给**差之差**定序。

随后一次**容量通道扫描**（把 6 边任务图按跨组边数 `c` 参数化）发现：`Δ(c) = 投影代价(跨组划分) − 投影代价(对齐划分)` **随跨组耦合单调衰减**，在 `c=3–5` 处 `≈0`，且**全部 7 个条件仍非局部**（`gap(16)` 区间下界均 `≥0.20`）。

G1-BOUND-0001 据此换问题：**从"对齐是否有益"改为"训练能否兑现表示界"**。冻结条件对 `(c=4, c=5)`；`Δ` 分别为 `+0.0020 [−0.0006, 0.0054]` 与 `+0.0003 [−0.0013, 0.0021]`，配对保守上界 **`C_ub = 0.0064`**。主终点为**同条件内的臂差** `β = KL_U − KL_S`；`SUPPORTED` 要求 `β` 的 95% CI 下界 `> C_ub`。**不做任何扣除**。

**核心解释**：`β = Δ + (e_U − e_S)`，`e ≥ 0` 为各臂的训练超出量。`Δ ≈ 0` 时 `β > 0` 只能来自 `e_U > e_S`。

## 问题（七问）

1. **重构是否合法**：`β = Δ + (e_U − e_S)` 是否成立？`e` 定义为 `KL_trained − KL_projection` 是**定义**还是**假设**？若 `KL_projection` 不是该臂的**真实**可达下界，该等式与由它推出的解释是否失效？
2. **`Δ` 是否是有效界（S4 的核心）**：`Δ` 是**特定结构族**（"给定 `θ` 的条件独立块分解"）内两个投影代价之差，而两臂的架构（`H=64` 连续状态 + 32 维读出）**并不被限定在该族内**。设计用**限定检查**（任一臂出现 `KL_trained < 该臂投影代价` 即 `INCONCLUSIVE`）来兑现 S4。**该检查是否足以确立 `Δ` 是有效界？** 一个在该族**之外**的模型完全可能仍有 `KL_trained > 投影代价`，从而通过检查却使 `Δ` 失去界的意义。
3. **是否只是 GPI-0001 的复现**：GPI-0001 已检验"块组织对密度匹配随机掩码"，结果 `D < 0` 在全部六个「条件 × seed」单元成立。本设计检验"对齐路由对跨组路由"，两臂共用同一矩阵、只差输入路由。**这是新问题还是同一问题的改名？** 若为后者，为何预期不同结果？
4. **`(4,5)` 对的选择是否可辩护**：两条件**图不同、度序列不同**（`[1,1,1,2,3,4]` 对 `[0,1,2,2,3,4]`）。设计称主终点是**同条件内**臂差、条件间只作同向复核。**该处置是否足够**？`c=5` 的"同向"是否构成独立复核，还是与 `c=4` 高度相关？
5. **S1–S5 是否真的满足**：S1 `0.0064 < 0.025`、S2 `0.0313 ≤ 0.05`、S3（设计称无等价条款）、S4（由限定检查条件化）、S5（9 组合映射 + 2 新分支）。**逐条核验**，特别是 S3 的"移除等价条款"是否属于**回避**而非满足。
6. **分支是否真穷尽**：§6 声称对「点估计 × CI 位置」9 种组合无空分支。**请独立检验**，并指出任何**未覆盖的输入**（例如 CI 宽度与 MDD 的关系、`C_ub` 与 0 的相对位置）。
7. **最强拒绝**：设计自列三条（`Δ≈0` 是解析结果；两条件图不同；`β>0` 可能来自随机优化路径）。**是否还有设计未列的、更致命的一条？**

## 最强拒绝（审查须正面处理）

- **A（界无效）**：`Δ` 是特定结构族内的量，两臂架构不被限定在该族内；限定检查是**弱检验**，不能确立 `Δ` 是臂差的有效界。若此条成立，S4 不满足，设计重蹈 v2 的覆辙。
- **B（等式是假设）**：`β = Δ + (e_U − e_S)` 只在 `KL_projection` 是**真实可达下界**时成立；否则等式两端不是同一分解。
- **C（改名复现）**：与 GPI-0001 是同一问题，且已得负结果。
- **D（同向复核不独立）**：`c=5` 与 `c=4` 共享任务族、臂结构、优化设置，不构成独立复核。
- **E（S3 回避）**：移除等价条款使 S3 名义通过，但 `c=5` 的"同向"是弱条件，不控制任何东西。
- **F（可分辨性）**：`MDD = 0.0344` 而门槛 `C_ub = 0.0064`；`β` 落在 `(0.0064, 0.0313)` 的区间会被判 `PARTIALLY_SUPPORTED`——**该带是否又是不可归因带？**
