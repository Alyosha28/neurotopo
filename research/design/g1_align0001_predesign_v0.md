# G1-ALIGN-0001 事前设计 v0（**未注册、未过审、不构成协议**）

2026-09-24。本文回答"决定0066 要求的新组织操纵是什么"。**它不是预注册、不是协议、未过独立前瞻审查，不得据此注册任何实验或启动训练。** 本设计不改变 Gate 1 `NOT_PASSED`，不追认任何既有判词，不重开 GPI-0001。

## 1. 为什么需要一个新操纵（决定0066 的收窄结论）

GPI-0001 的关闭审查把"块组织一致劣于随机掩码"收窄为**"该掩码式操纵下未检测到优势"**，理由是：密度匹配只固定非零个数，**掩码位置与跨组混合量相混淆**；且 `D<0` 在 F（块掩码与任务分组结构相匹配）同样成立，正是一般混合/优化效应所预测的模式。

因此 GPI-0001 的比较实际上问的是"**少混合 vs 多混合**"，而**不是**"组织是否对齐"。本设计把混淆项直接消掉。

## 2. 候选：块与任务维度分组的**对齐**（alignment），而非混合量

**两臂的循环稀疏模式完全相同，只有"哪个块处理哪些维度"不同。**

| 臂 | 循环结构 | 与任务分组的关系 |
|---|---|---|
| **S（对齐，候选）** | 块对角，块 `b` 只处理**第 b 组**的潜变量维度 | 与 F 的逐维独立分组**对齐** |
| **U（置换，主对照）** | **同一**块对角矩阵，但在**随机置换的维度基**下施加——块 `b` 处理一个**随机子集**的维度 | 与分组**错位** |

**被消掉的混淆**：两臂的块数、块大小、稀疏模式、度、跨块边数（**均为 0**）、参数、状态、样本、更新、内部步数与执行计算**全部相同**。唯一差异是**对齐与否**。GPI-0001 的"混合量"变量在本设计里**不存在**——两臂都不混合。

**预测（条件化交互，非主效应）**：在 **F**（逐维独立 `θ_i`）中，对齐块可**精确分解**为每维独立滤波，故 `S` 优于 `U`；在 **X**（单一共享 `θ`）中，`θ` 的后验耦合全部维度，**两臂都无法分解**，故差异消失。

```text
I = β_F − β_X  > 0        （β = 各条件下 S 相对 U 的配对 KL 收益）
```

**这是预测，不是由 oracle 结构推出的必然结论**（G1-KSI 评审 R8 的教训）。

## 3. 任务：复用 GPI-0001 已证非局部的族与 F/X 对

不新建任务族（0049 禁止以换任务救候选；本设计**不需要**换任务）。

- **生成器**：Ising 耦合二元潜变量，未知全局耦合 `θ`；观测 `y_t | z_t ~ N(λ z_t, I)`；**目标为全局参数后验 `p(θ | y_1:T)`**。
- **为何必须是全局目标**：`structural_task_proposal_v0.md` §8 已实测——以**边缘潜变量**后验为目标时最大 `gap` 仅 `0.037` nat（**不予注册**），换成 `θ` 后验后 `gap(16) = 0.350`、`gap(32) = 0.192`，约为 `ε_abs = 0.05` 的 **7 倍**。
- **F/X 结构对**（已冻结、可复用）：`M=6`、6 节点 6 边、度 2、同一 32 点 `θ` 网格 `[0,0.6]`、同一 32 维目标；**只改边的位置**。
  - **F**：两个不相交三环 `((0,1),(1,2),(2,0),(3,4),(4,5),(5,3))` —— 组内边；
  - **X**：跨组 6-环 `((0,3),(3,1),(1,4),(4,2),(2,5),(5,0))` —— 跨组边。
- **已知非局部性**：F `gap(16) = 0.410 [0.380, 0.447]`、X `0.385 [0.354, 0.418]`。
- **已知控制余量**：LR 扫描（2 个）× 3 seeds × 2 条件下 **12/12 单元**末端 KL `0.0655–0.0889`（> `ε_abs = 0.05`），`1600→3200` 落差 `0.0005–0.0118`。

**难度差必须处理（决定0062 强制）；本设计初稿在此处有归属错误，已更正。**

初稿引用"实测归一化熵 F `0.5620` 对 X `0.5360`，差 `0.0261 ± 0.0049` SE，X 更易"。**该组数字属于 KSI 任务**（`research/design/g1_k_structure_learning_efficiency_v3.md` §4.7 门 7；归一化分母为 `ln16`，`T=16`，四环 `J_F=0 / J_X=0.25`），**不是**本设计复用的 GPI-0001 F/X 对（`T=64`、`M=6`、32 点 `θ` 网格）。**归属错误已更正，原数字不得用于本设计。**

**GPI-0001 F/X 对的真实难度量**（机器输出 `research/design/structural_task_probe/gpi_v1_analytic_fx.json`）：

| 条件 | `theta_posterior_entropy_nats` | `uniform_baseline_kl_nats` |
|---|---|---|
| F | `2.6251` | `0.8406` |
| X | `2.6929` | `0.7729` |

**关键更正（比归属错误更重要）**：这两个字段**不是两个独立难度量**——`KL(uniform ‖ p) = ln 32 − H(p)`，二者**代数恒等**（`3.4657 − 2.6251 = 0.8406` ✓，`3.4657 − 2.6929 = 0.7728` ✓）。故该机器输出 `reading` 里"Difficulty is measured-matched … (ratio 1.088)"的说法**只依赖单一量**，`ratio` 框定掩盖了实际差值：**F 与 X 的 `θ` 后验熵差为 `0.0678` nat，超过 `ε_abs = 0.05`**。**两条件在本设计所关注的尺度上并非难度匹配。**

**由此产生的预注册要求（不得含糊）**：

1. 难度协变量**唯一指定**为 `θ` 后验熵 `H(p(θ|y_1:T))`（等价地 `ln32 − H`）；**禁止**把二者当作两条独立证据，也**禁止**沿用 `ratio 1.088` 的"匹配"措辞；
2. 注册须写入实测差 **`0.0678` nat** 及其 bootstrap CI，并**明确承认该差 > `ε_abs`**；
3. 交互估计量须**同时**报告难度协变量调整后与未调整两个值；
4. **未决问题（须由审查裁定，不得由本设计自行放宽）**：若规则要求两条件难度匹配到 `ε_abs` 以内，则**冻结的 F/X 对不满足**，而决定0066 禁止改 `M/T/λ/网格/K` 重试同一配置——此时本设计**须换结构对或停止**，**不得**把容差事后调到 `0.0678` 之上。容差必须在**任何资格样本之前**冻结并给出理由。

**为何水平难度差本身不必然致命（本设计的分析，须经审查核验）**：主终点是**交互** `I = (S−U)_F − (S−U)_X`。F 与 X 之间**与对齐无关的难度水平差在差分中被消掉**；它只有在**调节**对齐效应（即"难度改变了 `S−U` 的大小"）时才污染 `I`。因此本设计需要的**不是**两条件难度相等，而是：

1. **两条件都处在"可改善"区间**——由资格门保证（`B` 与 `2B` 下末端 KL **都** > `ε_abs`，即控制**未饱和**）。已冻结的实测控制余量为 12/12 单元 `0.0655–0.0889 > ε_abs`，**F 与 X 均在内**；
2. **难度不调节对齐效应**——**不可**由设计断言，须作为**可证伪检查**报告：以难度协变量（`θ` 后验熵）分层的 `S−U` 是否随难度变化。若分层后 `S−U` 呈现单调趋势，则 `I` 的解读受限，须按 `INCONCLUSIVE` 处理；
3. **不得**以"交互会消掉水平差"为由**免去**报告难度协变量调整后的 `I`（要求 3 仍强制）。

**边界**：以上是**分析论证**，不是实测；它**不**改变要求 1–4，也**不**预先裁定 §3 的未决问题。若审查判定"水平差仍致命"，本设计须换结构对或停止。

## 5. 主终点（避开未裁定的终点类型问题）

**主终点为末端配对 KL 的交互 `I = β_F − β_X`**，`β` 取**最终检查点**的配对 KL 差——**不是**学习效率终点。

理由：决定0062 明确"项目 Gate 1 的终点类型问题**不因此解决**"，学习效率主终点在项目轨**仍未获授权**。本设计**不使用**它，故**不触碰**该未决问题。

**估计量与自由度**：按决定0062 的要求预注册——确切交互统计量、每单元 `n`、alpha、`δ_min`、`δ_min` 处功效 0.8、资格后不得修改。

## 6. 资格门（复用 CAL-0008 加固版 + 三条）

复用：绝对残余 `ε_abs = 0.05`、相对残余 `ρ = 0.05`、学习量 `κ = 0.90`、双侧分层级平台门（含无净上升）、跨 LR 一致门、逐 seed 聚合绑定所选 LR、`INCONCLUSIVE` 原因码、`C1` 预算锚点、对称坍缩停止项。

## 7. 最强拒绝（须在结果前冻结）

**S 臂的块对角结构与 F 的逐维独立分组同构，故 F 中的收益可能来自"手工先验恰好匹配任务"，而非任何可迁移的组织原则。** 本设计用 X 条件与置换臂部分处理它，但**不能**完全排除：一个足够强的单流在 F 中也可自行学出分解。

**次级拒绝**：置换臂可能因"块内维度不相关"而**更难优化**（而非"更不对齐"），使 F 中的 `S>U` 退化为优化难度差。
