## 1. 一个明确问题

在相同完整 GRU 函数类、参数、状态、样本与更新预算下，**与任务转移对齐的固定循环群软正则**，能否比**正则 Hessian 同谱但方向不对齐的软正则**取得更低的最终后验 KL，并胜过无该正则的强常规控制？

操纵不是增加 K，也不是重启 G1-RS 分块递归。各臂均是全连接单 GRU；唯一处理是一个固定、有限的权重空间惩罚的方向。它是 C9 启发的**软组织先验**，不是严格函数类限制。因果链：权重组织先验 → 循环更新偏好 → 过滤表示 → 历史证据整合 → 固定预算后的预测水平。学习速度不作主终点；不主张候选语义或生物效果。

最强反驳：这只是已知软等变正则，优势是任务知识/正则化而非新拓扑原则。**接受已知机制这一事实**；本实验只检验给定先验对齐的有限预算收益及其反例。不得预先称它为新贡献或可计 Gate 1；0080 的入口字段放行不足以决定“训练目标先验”是否是合格 architecture_organization 因子。

## 2. 为什么不用硬共享

硬等式约束会改变可表示函数类，且随机共享可能制造错误约束。这里 θ 始终遍历同一个 R^1904；有限惩罚不删除参数、不截断权重。因此两处理的**函数可达集严格相同**，对任一固定数据分布，未正则化预测风险的 infimum 差严格为 0。这排除函数类包含差，不排除有限预算的有效容量、优化或隐式偏置。

采用标准 PyTorch GRU 方程，输入=隐藏=输出=16。六个 16×16 门权重（3 输入、3 循环）、六个 16 维 bias、一个 16×16 读出及一个 16 维 bias，共 1,904 trainable/allocated 参数；状态 16。h0=0；不缓存历史 logits 作模型输入。强 H64 GRU 是额外保护，不削弱其全输入/全读出能力。

S 为长度 16 环的单步循环置换。每个方阵的 P_G(W)=16^(-1) Σ_(k=0)^15 S^k W S^(-k)，每个 bias 的 P_G(b)=mean(b)·1。P_G 在 Frobenius 内积下是正交投影。固定置换
`p=[0,5,11,2,14,7,3,12,8,1,15,6,10,4,13,9]`，Q=I[p,:]，G'=QGQᵀ。P_G'(W)=Q P_G(QᵀWQ)Qᵀ。

目标为最终后验交叉熵 + λ ||θ−Pθ||² / 1904，λ=1.0，**不调 λ、不学习群、不适应正则强度**。两个惩罚都覆盖所有输入/循环/读出矩阵和 bias；仅惩罚循环矩阵而让输入/输出任意换基，会引入可吸收坐标变换，不能代表这里的处理。

P 总秩=7×16+7=119，残差秩=1785；两惩罚 Hessian 谱均为 119 个 0 和 1785 个 2λ/1904。**这不等于总训练损失 Hessian、条件数或梯度范数相同**；可归因范围是“等强度同谱先验的方向对齐”，不能声称排尽优化机制。

## 3. 固定任务菜单：一个族、两个共轭条件

F：隐藏状态 z_t∈{0,…,15}，z0 均匀，列随机转移 T=0.7I+0.2S+0.1Sᵀ。y_t=z_t 的概率 0.6，否则在其余 15 个类别均匀。每步输入 x_t 是 y_t 的 16 维 one-hot；不输入 z、T、oracle、群标记或隐藏未来。目标 q_t 是完整 y_1:t 下的后验，q0=uniform，q_t ∝ L(y_t)⊙Tq_(t−1)。训练只监督 t32；终点为 t64 的 KL(q64 || model64)。IID32、t8/16/32/48/64 和真实 z accuracy 均完整报告但不挑切片。

X：把同一基础轨迹的 z/y/后验全部乘 Q，转移为 Q T Qᵀ。F/X Bayes 难度、信息量、序列长度逐例相同。它是**同一任务族的坐标失配条件，不是第二族**；不把共轭重复当独立样本或通用性证据。训练覆盖所有标签位置，不故意留掉某些状态以使对照不能学习。

最小充分统计是 16 类过滤后验（15 自由度）；不存在单流表示不可能性。简单无架构 oracle 是上述 forward filter。额外可训练简单控制是 16 状态 HMM：已知共同发射律、全 16×16 列 softmax 转移 logits，自 uniform 转移初始化，使用同训练输入/末端软监督拟合，不获取真实 T 或潜在 z。这个控制有更合适的算法先验，资源另披露；若它封顶，则本配置不能支持“普通序列模型缺计算组织”的强解释。

cache-and-select 检查明示能力：缓存完整观测并运行 forward filter 与 oracle 相同；禁止称“任何 cache 都不能解”。截断捷径从 uniform 只过滤最后 1/8 帧；history contribution 用 KL(full || suffix) 测。另保留共同前缀而后缀证据不同、共同后缀而前缀不同的确定配对：前 32 帧共享/后 32 帧独立或相反，所有统计只看观测和 oracle，不以候选分数筛选。

RNG 用 NumPy PCG64 + SeedSequence(root).spawn(3)，分别用于 z0、转移 categorical、发射 categorical；X 从 F 置换而不另抽噪声。训练 root=70,000,000+100,000*seed+step；资格评估 root=80,000,000+seed；最终 root=90,000,000+seed。归档真实 root 与流 hash。不同阶段 seed 不重叠。

## 4. 模型与判别性

所有主 GRU 臂完整 trainable 参数相同：A=P_G；B=P_G'；U=λ0 同一 H16 GRU（自消融）；R=各向同性 L2，系数 λ×1785/1904，使惩罚 Hessian trace 与 A/B 相同，**不称同谱**。D=H64 标准全输入/输出 GRU；H=可学习全转移 HMM。另记录硬 G 等变 GRU 的先例臂 E（共享参数 119，展开后同 1904 张量形状；不冒充资源匹配主臂）。E 代表已有机制，不把“胜 E”预设为新颖性。

F/X 每臂都训练。预注册交叉差
`I = [(L_B,F−L_A,F) + (L_A,X−L_B,X)]/2`。
还须分别报告两项，不让平均掩盖一侧伤害。I 是配对 seed 的一个数；F/X 不翻倍样本量。两任务共轭使该交互的两半相关，**交互本身不证明超出已知对称性**。

主要水平收益 δ=0.02 nat（预先选定的实际用途门槛：每序列正确后验的几何平均密度比约 exp(.02)=1.0202；不是经验估出来的阈值）。要求 I 的单侧下置信界 >δ；F 上 A 与 X 上 B 分别优于 U、R、D 的相应匹配条件，并分别报告 δ 以上的下界；不得只赢 B。H/E 为先例和简单解保护：若候选不优于它们，最多报告组织对齐局部效应，不能声称胜出已有方法或已满足 Gate 1。

正则方差/条件数替代解释：归档 penalty、任务梯度 norm、penalty 梯度 norm；不在看见结果后做 λ 匹配。全预算指标随臂公开。若好处只来自不同惩罚大小，此设计仍只能支持“固定先验的总效应”，不能拆成纯拓扑效应。上述诊断不升级因果判词。
