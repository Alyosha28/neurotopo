# EVT-0001 packet 反思回应

2026-09-24。独立反思四项均接受，保持 `EARLY_EXIT_PROXY` 的限定判词，不把它升级为后验迟消歧频率或作者论文复现。

**R1 / R3：代理与目标没有已知数值桥梁。** 首次 `|z|>2` 既非必要也非充分的后验 `t_DD` 时刻；第30步1/100,000仍在区的结果只触发**审慎核源/决定是否投入oracle**的预写代理标签。99%/10%是本次预算优先级分档，不是作者后验资格阈值，不能据其推算30–170分层自然率或需要筛多少条。当前 G1-DD 候选因自身因果因素未隔离已独立 NO-GO，故不为救它追加后验扫描；未来若另立可辨候选并使用此任务，须**事前**冻结后验oracle精度、未经筛选样本、`t_DD`分层自然率、可容筛选量/预算和失败分支，再运行。

**R2：来源归属已由 packet 外科学复核。** 原作者 [arXiv HTML v1 §5.1 式(14)–(16)、附录 E](https://arxiv.org/html/2605.19283) 给出转移、分段发射和 `a=3,V0=.06,Δt=1,σz=.05,d=2,z0~N(0,1)`；井±3不在偶发射区`|z|≤2`内。正文一处称吸引到井后仍在 non-injective 区，下一句称井在区外，属文本内部不一致。`docs/EVT-0001_independent_result_review.md` 逐项核对原文与脚本；此论断不涉及作者数值效果真实性。以后若需要 packet-only 反思独立核源，应在事前design内放精确公式/位置或把原始来源摘录作为 action，而不能指望模型访问 packet 外网页。

**R4：反思输入边界不等于运行复核。** Packet 只包含设计/证据/原始 JSON，未附脚本源码；它只允许反思证据表达和算术，不证明执行独立性。另一次拥有仓库与一手论文访问的结果审查确实核对哈希和公式，用相同PCG64 seed在另一 NumPy版本独立重算得到完全相同计数，见 `docs/EVT-0001_independent_result_review.md`。原始 JSON 保存脚本/协议哈希及提交，`scripts/audit_evitrack_region_exit.py` 可重跑到另一个新路径的副本；不能把 packet-only 模型说成做过这个重算。
