# EXP-0010 训练前 NO-GO 的独立反思回应

2026-09-24。对 packet-only 反思 R1/R2/R3，原决定的标签仍为**项目当前优先级下关闭 v1、未训练**；这不是温度因素的科学否证，也不是封闭 `independent_benchmark` 轨。

**R1 接受：独立价值被表述得过低。** 现将“旁支好奇心”限定为**本轮 Gate 1 目标的机会成本**，不表示独立问题没有研究价值。若门控资格失败，独立决定是关闭该固定温度/任务规格；若正式支撑，则保留旧任务族温度 package 候选并申请独立任务/门控中介干预；若正式否定，则关闭其+3pp有用收益预测；不可判则保留边界。该独立科学价值与项目过门价值是两个轴。v1 原定最多156,000训练更新，并需先新建强制两阶段 runner；G1-MB-0001 设计若被独立接受，按拟议2臂×3资格×600 + 3臂×10正式×600 =21,600更新量级，**只是方案预算估计**，还没有正式数值协议、资格或训练。即使该 G1 方案被否，EXP-0010 v1 仍因四项运行/统计阻断而不得原样启动；将来重新排入独立轨须新版本协议和明确机会成本，不得追认 v1 效果。

**R2 接受：原四行把统计判词压扁。** 原协议逐层的互斥结果应按下列顺序理解；这些都是*假设分区*，没有任何新模型结果。

| 分区 | 独立温度问题的允许决定 | Gate 1 |
|---|---|---|
| 资格学习、实际高温主控制余量、门值操纵或资源任一失败 | 对该固定规格关闭，记录明确失败类别；不启动正式训练 | 不变 |
| 资格通过但正式种子的学习/门值/高温余量/资源护栏任一失败或运行不完整 | `INCONCLUSIVE`，保留所有已完成种子和失败 | 不变 |
| 正式所有护栏通过，OOD32主差均值≥0.03、CI下界>0，confirm均值≥−0.01 | 原协议 `SUPPORTED` 仅限“正效应，点估计≥3pp”，不声称真实效应下界≥3pp | 不变 |
| 上述主差/CI条件通过但confirm均值<−0.01 | `PARTIALLY_SUPPORTED`，承认confirm损害 | 不变 |
| 正式护栏通过且主差CI上界<0.03 | 对≥3pp有用收益预测的 `FALSIFIED`，**非**凭点估计未达阈值 | 不变 |
| 其他完整结果，如CI跨越0/0.03或均值未达且CI仍覆盖0.03 | `INCONCLUSIVE` | 不变 |

即使这份分区修正改善独立解释，预运行审查指出原协议仍没有程序化资格闸门、推断范围和超时一致性；所以不推翻 v1 的训练前 NO-GO。**R3 接受且已有实际纠偏：**事前提交的 `research/design/g1_mode_bank_candidate_v0.md` 把 MB4、连通 SC64 主对照、强 D64、主端点和失败条件写实，但独立批评判其是旧 M3/已筛查任务的后验救援，主代理按决定0030在训练前关闭。随后 `research/design/g1_external_dd_candidate_v0.md` 已事前提交，改用外部已发表的真正多峰延迟消歧任务，并写明两条持续评分轨迹、资源匹配连通控制、强稠密控制及资格失败分支。它**仍在独立设计审查中**，无数值协议或训练；审查若不通过，还需继续调整方向。EXP-0010 关闭结论不依赖外部候选必然成功。
