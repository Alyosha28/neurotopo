## 3. 放宽内容：`G1-MATCH-v3`

**单层。无通用/严层之分。无自动降级。无数值上限。**

### 3.1 必须匹配的（保留，且只有这一条）

**匹配机制实际消耗的那一条轴。** 该轴在**注册时声明**，并经 **pilot 实测的超出消耗 argmax 验证**。（此条继承决定0067，未改动。）

### 3.2 不再必须的（本次放宽的主体）

| 项 | `G1-MATCH-v2` | `G1-MATCH-v3` |
|---|---|---|
| `state` 匹配 | **必须**（通用层） | **不再必须**；按实测比值披露 |
| 其余各轴（分配/有效参数、样本、更新、内部步数、时延） | **各自预注册数值上限，默认 `1.15×`** | **取消上限**；一律按实测比值披露 |
| 超限后果 | **自动降级**为非通用层 | **无降级**；超限只体现为披露中的比值 |
| 层别 | 两层（通用/非通用） | **单层** |
| 严层不可达时 | 须记录不可测声明 | **该条款作废**（无严层） |
| 时延 | 受计费报告指标；降级须附 profile | 受计费报告指标；**除非机制把时延声明为消耗轴，否则不单独阻断 Gate 1 判词** |

### 3.3 保留的其余要件（未放宽）

- 给 `SUPPORTED` 判词须 **compute matched-or-operator-profiled**（保留 v2 的收紧，不退回"仅披露"）；
- 整包比较仍走带**资源未匹配标志**的 `PACKAGE_EFFECT` 轨，**禁止聚合或作为 Gate 1 证据引用**；
- 每个注册存储 `matching_criterion_version`（值 `G1-MATCH-v3`）；
- **决定0067 §5 的日落条款继续有效**（前三次放宽轴运行后复评；中位未匹配轴比值 >2× 且出现正面判词则暂停本放宽）——该条款在 0068 中未被带入三文件，本决定予以显式承接；
- **预注册、控制不得弱化、全轴披露、筛查阈值冻结、其余全部阶段门不变**；
- 原始数据不可变；无 `biological > random` 之外的生物学主张。

### 3.4 Gate 1 要求文本同批修改

现行文本点名 `state`，而 v3 不再要求 `state` 匹配。若不同批修改，将**重演** 0067/0068 期间"行文点名 state 而判据不要求 state"的**同一类不一致**。改为：

```
| 1 | Generic trajectory benefit after matching the declared consumed axis (compute matched-or-profiled for SUPPORTED; all other axes disclosed as measured ratios) | NOT_PASSED; ... |
```

**注意方向**：这是把**判据与行文对齐**，不是"为了过门而改门"——v3 的判据比行文**不宽**：行文原先点名两条轴，v3 的强制匹配只剩一条，但同时新增了 compute 的 matched-or-profiled 要求与全轴披露义务。**行文修改必须与判据修改在同一次变更中落地，并在变更日志中显式记录方向。**

## 4. 放宽的代价（须显式记录，不得隐去）

- `state` 未匹配的比较**不能再被读作**"分离出机制的组织结构"；残余可归因性由**声明轴匹配 + 全轴披露 + 条件化判词**承担，而**不由** `state` 匹配承担。
- 因此 v3 下任何 Gate 1 判词**必须是条件化的**：其效力**仅**覆盖所声明的消耗轴。
- **v3 与 v2 在科学上不等价**；v3 更弱。这一事实须留在记录中，不得表述为"澄清"或"等价改写"。
