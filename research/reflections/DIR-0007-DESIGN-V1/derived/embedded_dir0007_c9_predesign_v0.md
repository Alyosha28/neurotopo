# DIR-0007：固定对称性约束的候选设计任务

2026-09-26。设计任务，非 EXP 注册、非运行授权。先保存本说明，再形成具体协议；本会话此前已查到等变网络和 HashedNets 的检索摘要，不能称为先例盲选。没有任务样本或模型结果。历史 C1–C7、G1-RS、DIR-0004 不重开。

问题：C9 的固定参数共享约束能否形成一个可区分“共享组织的对齐”与“参数减少/通用正则化”的、以最终预测水平为终点的候选？优先考虑环形状态上的循环群约束；不得把已知等变网络包装为新机制。

因果链：固定权重等式约束 → 在重标记下相同的递归更新 → 后验表示一致性 → 序列证据整合 → 有限预算的留出预测水平。不是多假设语义、不是生物效应。

范围：决定0043/0044/0049/0054/0062/0069/0080/0082、当前 stage_gates、已有简单滤波器先例；原始论文 Equivariance Through Parameter-Sharing、Group Equivariant Convolutional Networks、HashedNets、Flow Equivariant RNN。产出具名操作、实际主控制、简单算法 oracle、任务匹配/失配、样本与预算、成功/失败/边界分支及未决项。

最强拒绝：这只是已知任务对称性的硬编码，随机共享主控制会被人为削弱；约束本身同时改变可达函数类、优化与正则化，等参数不解决归因。另一个拒绝是新任务仅在救被关闭的 G1-RS，或把坐标重标记冒充第二任务族。

接受条件：明确承认先例；不把随机共享作为唯一控制；包含最强常规与先例控制；数学上可定位共享约束、全轴资源、任务失配与表示偏差；冻结有限任务菜单、最终水平终点、控制学习/余量和停止规则；将未测量量标为未测量。资格可执行性由独立 packet-only 审查判断。

审查标签：DESIGN_READY_FOR_REGISTRATION_REVIEW（仅可进入正式注册审查）、DESIGN_NEEDS_REVISION（最多一次版本修订；仍有实质缺口则停在设计）、DESIGN_REJECTED（保留并停止该候选）。任何标签不自动注册、不训练、不改 Gate 1。提交最终稿前执行 packet-only 反思并记录主代理处理。
