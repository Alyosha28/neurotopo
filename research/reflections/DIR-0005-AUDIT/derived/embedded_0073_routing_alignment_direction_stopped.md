# 决定0073：停止"路由对齐"方向（G1-BOUND-0001 判 `V0_REJECTED`）

2026-09-24。执行 G1-BOUND-0001 窄范围独立审查的判词。**本决定不注册实验、不授权训练、不改变任何阶段门状态、不追认任何既有判词。**

## 1. 判词与依据

G1-BOUND-0001 经**第三次投递**（文件投递 + 问题收窄为两问）获得独立审查，判 **`V0_REJECTED`**（3 项，全部 accept；`research/reflections/G1-BOUND-0001-DESIGN/`，`check` 判 `valid: true`）。审查者自报 `FILES_READ` **仅列 packet 一个文件**，独立性成立。

**致命项 = 本设计自列的最强拒绝 A（界无效）。**

## 2. 致命项（审查 I1）

`β = Δ + (e_U − e_S)` **作为恒等式只是定义**——对**任意**投影代价 `P` 都成立，故它**不含**可加性假设。真正的实质假设是：

```text
P_arm  =  该臂架构可达的下界
```

而两臂架构（`H=64` 连续状态 + 32 维读出）**明确不被限定**在"给定 `θ` 的条件独立块分解"族内。

**限定检查对唯一能使其失效的方向零功效**：该检查只排除"训练值**低于**族内投影代价"一侧；而能令 `C_ub` 失去界意义的方向是**架构可达最优高于族内投影代价**——此时 `KL_trained ≥ KL*_arm > P_arm`，检查**必然通过**。且该检查**未预注册任何水平、容差或功效**，实际只筛查同一 episode 流上的蒙特卡洛噪声。

**故 S4 是名义"通过（条件化）"**，预注册的独句判词（"跨组路由的训练超出量大于对齐路由"）**无执照**。

**不是措辞可修**：唯一救法是把界换成对**两臂架构本身**成立的可达界（架构级 oracle，或可证包含两臂架构的族）——**那已不是本设计的 `Δ`**。

## 4. 我方错误（审查 I2 提出，已独立复算确认）

`c=5` 的边集为 `[[0,1],[0,3],[0,4],[0,5],[1,3],[1,4]]`，**节点 2 度为 0、完全孤立**——六个潜变量维中**有一维毫无耦合**。复算确认：`c=5` 的度序列为 `[4,3,0,2,2,1]`（`c=4` 为 `[4,3,1,2,1,1]`，`c=6` 全为 `2`）。

**我在 entry 草稿里记录了那个 `0`，却没认出它的后果**：`c=5` 里"组结构"几乎不存在，"同向复核"取自**对齐操纵内容最稀薄处**。

审查据此给出更深的洞察，本决定采纳：**`Δ ≈ 0` 的识别条件与"对齐操纵仍有内容"天然对立**——`Δ` 随 `c` 单调衰减（`c=6` 已为 `−0.0064`），故容量通道小的地方，操纵本身也被稀释。**这是容量扫描设计的固有缺陷，非本设计可修。**

## 5. 停止范围（**整个方向**）

- **G1-ALIGN-0001 与 G1-BOUND-0001 均不注册、不跑资格流、不启动训练**；两者的判据架构**作废**。
- **停止整个"路由对齐"方向**：**不再以换条件对、换措辞、换 `c` 或换统计量重开**。
- 若日后仍要保留该对比，**只可**登记为对既有对比的**高功效重复**（明确标注为重复而非新问题），且**须先补架构级可达界**（§2）。
- 已冻结的控制资格协议与 entry 合同草稿**不启动**；保留为历史件。
- 可复用资产保留：解析分解、自同构判定、采样器/路由/oracle 的第二实现核对脚本、F/X 与 `c` 参数化任务族、`gap(k)` 探针、块交换性论证。

## 6. 保留的负面结果（不得改写为"方向无效"）

- **GPI-0001**：掩码式操纵下冻结 `δ_min` 处无信号（`I = +0.0059`，sd `0.0211`）。
- **G1-ALIGN-0001**：F/X 条件对上容量通道 `0.0388 [0.0285, 0.0508]` 与 `δ_min` 同量级，**对齐效应与容量通道不可分辨**。
- **G1-BOUND-0001**：换条件对**不能**买来可辨识性——`Δ ≈ 0` 与"操纵仍有内容"对立；且族内投影代价**不是**臂架构的可达界。
- **本决定不构成**"组织/对齐普遍无效"或 H3 的一般证伪。它只说明：**在这条具体构造路线上，可辨识性无法建立。**
