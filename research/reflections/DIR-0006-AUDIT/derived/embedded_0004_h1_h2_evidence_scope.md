# H1/H2 决策：现存图对照不足以识别单一原则

2026-09-24。独立 H3 审查在有条件接受“当前候选规格暂不实施”的同时，要求检查是否存在不越过 Gate 1、又能改变 H1/H2 判断的现存证据问题。本次只读审计重建了 EXP-0004/0009 全部20对正式 block/random 图，掩码 SHA 与结果一致；图指标及其数学约束见 `research/evidence/h1_h2_existing_evidence_audit.md`。第二次独立审查见 `docs/h1_h2_evidence_independent_review.md`：直接复算40图恒等式，并在修复解释器路径后独立重放十个互反 witness；接受下面的解释范围。

**H1 仍 UNTESTED。** 原比较精确匹配节点、边、每节点入/出度、自环和主模型资源，但四块图与重连图同时改变全局连通、跨块边、固定分区 modularity、互反结构及谱混合。对本图族，`Q=0.75−crossEdges/1024` 是精确恒等式，40张重建图残差为0。因此“跨块桥的影响”与“固定原分区 modularity 的影响”甚至不能在现有约束下作为两个独立因子提出；新增样本数或种子数不能解决该代数不可辨。EXP-0004 只对**两种整体图生成器**给出局部负效应，EXP-0009 的能力主检验因 headroom 失败而 INCONCLUSIVE。

**H2 仍 UNTESTED。** 两组正式架构比较使用同一种 GRU 更新方程，没有将至少两个动力学条件与图因素交叉；行为分数、图谱值和冻结状态线性探针均不是对适应、瞬态或吸引子逃逸的因果消融。Gate 2 所需适应/噪声/计算对照尚不可从这里推导，也不应为解释 EXP-0004 的负结果临时加入。

存在性补充审计发现十张 C0 图均可经一次保度/自环/跨块边/强连通的合法交换改变互反边比例；这说明**互反结构与 cross/Q 可局部分离**，但每次变化只有约0.002–0.004且谱值同时移动，远未构成统计 null 或任务效应。现有 BCTpy 文档包含 directed degree-preserving rewiring，reciprocal-degree null 有独立论文先例；两者都不能自动解决本项目的精确自环、固定跨块数和谱匹配，见 `research/prior_art/topology_null_feasibility.md`。

决策：关闭“从 EXP-0004/0009 回溯宣称某个拓扑原则或 topology×dynamics 协同”的解释路径，保留 H1/H2 为未检验。当前**不启动新图训练、适应、通信、生物连接组或 LM**，Gate 1 仍 NOT_PASSED。若将来重新登记一个 H1 问题，唯一值得先做的工作是成熟 null 的可行性及宽范围独立操纵验证、主匹配对照余量校准和版本化因果端点；图存在性 witness 绝不代替这些条件。本决定收窄主张并排除一个不可辨的因素组合，不宣称 H1/H2 被否证。
