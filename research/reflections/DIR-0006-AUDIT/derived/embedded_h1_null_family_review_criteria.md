# H1 互反结构 null 图族的设计评审条件

2026-09-24。此记录回应图存在性任务的独立任务后反思 `H1-R01/R02`。它不是新 EXP、null 采样器或 H1 因果结果，也不授权在 Gate 1 未通过时训练拓扑模型。

现有十图只各有一次合法交换。互反比例的单次变化为 −0.004167 至 +0.002083，第二大绝对特征值同时变化 −0.003632 至 +0.007024。因此，`10/10 witness` 只能证明局部图空间非空，不能作为可用处理强度或混杂控制的证据。

若以后进入完整 null 图族设计评审，**在搜索和任务分数之前**固定下列量及失败规则：

1. 目标互反差异的数值和方向、可接受范围、每张源图的采样目标、独立图样本数量、搜索预算与失败处理。报告十图各自可达到的范围、目标成功率、尝试次数与未达标图；不得只保留成功种子或择优选取目标。
2. 要精确保留的逐点入/出度、自环、跨原块边数和强连通性；要匹配或显式视作混杂的谱指标、motif、路径、聚类及其他动力学相关统计量。每项容差须数值化，报告联合满足目标差异与全部容差的图数量。若无法联合满足，不宣称互反结构的单因素效应。
3. 采样算法、版本、许可证、固定 RNG、混合/覆盖诊断、重复与图间依赖评估。一次或少量局部交换不构成均匀 null；不能以“度保持”代替对源图身份、接受率和覆盖范围的审计。
4. 若图族可行，仍须另行预注册任务、实际主匹配对照的 oracle-relative headroom、参数/状态/执行计算匹配、训练种子和因果判定规则。图空间可行性本身不推进 H1、H2 或 Gate 1。

当前决定是**保留因素候选、禁止把现有 witness 用于性能归因**。因 Gate 1 的更近障碍是 H3 候选机制缺乏独立可测预测，当前不继续靠加图搜索来回避该障碍。
