审查日期：2026-09-24。只读已封存的 `artifacts/EXP-0009/v1/manifest.json`、`analysis.json`、`report.md`、30 份 `result.json`、30 份 `predictions.npz`、30 份最终 checkpoint，及登记协议、运行前审查与答复、preflight、相关源码和先前工作。未重训、调参、改协议、改结果或推进 Gate 1。读取结果前确认 manifest 为 `run_kind=REGISTERED`、`status=COMPLETED`，9401–9410 的三种模型各一份结果齐全；账本处于 `ANALYZED`。

## 审查结论

**同意登记决策 `INCONCLUSIVE`，同意 `STOP_MECHANISM_ESCALATION`，Gate 1 仍为 `NOT_PASSED`。** M3（四块独立 GRU）相对 C0（保度、自环的重连掩码 GRU）在唯一主终点 d=4 最终联合后验 KL 上没有观察到有用增益：十个配对种子的 `Δ=KL(C0)−KL(M3)` 均值为 **−0.001356 nat**，样本 SD 为 **0.002657**，固定种子 20,000 次配对 bootstrap 的 95% 百分位区间为 **[−0.002990, 0.000120]**。M3/C0 的 KL 均值分别为 0.013819/0.012463 nat；十个差值中 3 个为正、7 个为负。此区间的上界虽远低于 0.05 nat，但登记规则先检查对照 headroom；该门槛失败，因此不能绕过规则改判 `FALSIFIED`。

导致不可判定的具体原因是 **C0 已接近低误差区**：其 d=4 KL 均值 0.012463，低于预设下限 0.07；十个种子中 **0/10** 的 KL ≥0.05，少于预设 8/10。训练充分性通过：d=1 M3/C0 均值 0.003112/0.003307，最大单种子值 0.003284/0.003715，均低于 0.05/0.10 门槛。代价护栏也通过：M3−C0 的 d=1 KL 均值 −0.000195 ≤0.01，d=4 H 真值准确率差 +0.000171 ≥−0.01。资源/配对核对无发现不符。因此审查认为主要限制是登记任务在 d=4 对照上缺乏预期的误差空间，而非一次可归责于配对错误的比较。

描述性结果与主结论相容：d=8 C0−M3 的最终 KL 均值 −0.015203 nat，配对区间 [−0.036619, 0.002999]；它不是预登记主终点。宽稠密 H64 GRU 的 d=4 KL 均值为 0.015780，作为有效参数不匹配的实用参照，不参与 M3/C0 因果判定。单次 CPU 运行的训练耗时中位数约 M3 3.456 秒、C0 3.436 秒、宽 GRU 3.429 秒；这些小差异不能充当跨硬件的延迟优势证据。

## 独立复核内容与证据边界

我从每份 `predictions.npz` 的 logits、oracle target 和真值 **独立重算 30×3 个 d 条件下的前/最终联合 KL、前/最终 oracle MAP 一致率、H/R/联合真值准确率和联合真值 NLL**；与对应 `result.json` 的数值相符（浮点容差 2×10⁻⁶）。随后从 30 份 `result.json` 重新聚合各模型均值、十个 d=4 配对差值、SD 与 NumPy `default_rng(694001)` 的 20,000 次配对种子 bootstrap，和 `analysis.json` 完全相符。d=1 充分性、C0 d=4 headroom、两项代价护栏及预登记判定顺序也由这些逐种子值独立执行。4,096 个测试题是同一冻结测试流；**配对种子**才是区间的十个重复单位，该区间条件于此测试流，没有覆盖重抽测试流或任务族的不确定性。

我逐字节核对配置、preflight、`uv.lock` 与 manifest 所列源码 SHA-256；核对 30 份预测档、checkpoint 的文件哈希，并从 checkpoint 重新计算最终参数哈希、实际掩码的入/出度、自环和跨原四块边数，均与结果记录一致。十个 C0 图的跨块边数为 717–747，M3 为 0；两者每点入/出度 16、64 个自环，C0 强连通由 preflight/图记录和源码约束支持。30 份预测档的 oracle target、H/R 真值在三模型、十种子和 d=1/4/8 间逐元素相同；各结果的最终测试流哈希也与 preflight 相同。M3/C0 每对初始参数哈希相同，掩码不同。每对训练流和日程哈希相同、每臂 1,500 更新、192,000 例、3,456,000 输入 token，且与无结果 preflight 一致。

**证据层级需分开：**预测档中的逐题指标、固定测试目标配对、输出文件/最终参数哈希和统计汇总已由本审查重算；初始参数逐元素相同、训练批次逐步相同、随机图的生成/强连通性和源代码对数据流的约束，主要依据记录哈希、preflight、runner/模型源码及其验证，并未重放 1,500 步训练或逐步重新生成训练流。实际资源记录与 preflight 一致：M3/C0 各 5,704 有效、14,920 分配参数，64 个动态状态值、3,072 个活跃循环参数，d=4 每例 589,696 个**稠密前向线性 MAC 解析代理**，每输入一步循环更新；宽 GRU 有 14,920 有效参数。执行代码在三臂均做稠密线性运算，M3/C0 的该代理匹配；完整训练 FLOPs、峰值内存和硬件层实际运算量没有测得，不应由代理冒充。

## 最强替代解释与可主张范围

这次近零主效应的最强替代解释是：经 d=0/1/2 混合日程训练后，固定生成器的 d=4 流对 C0 已太容易，出现评价指标的 headroom 不足；该条件无法敏感地区分 0.05 nat 的预设结构收益。不能据此推断所有区块拓扑都无益，也不能将 d=8 的描述性随机图优势确认为一般反向效应。即使出现差异，特定度保持重连生成器改变了跨块连边、图路径和混合方式；单一日程下的优化稳定性也可能解释差异，不能隔离出“模块性”或语义候选轨迹机制。d 增大同时拉长序列并增加带显式标记的干扰项，本设计也不能区分纯保持时间与抗干扰。先前 RIMs、TRNN、conn2res 和 NeuroGym 相关工作限制新颖性主张；本实验没有候选特异干预、自然任务或生物数据。

沿 `Topology → Dynamics → Representation → Computation → Capability` 链条，本实验直接操纵的是循环掩码拓扑，观察的是训练后联合后验误差及合成干扰长度迁移。它没有直接证明分立假设动力学或机制性表示，更不能从单一合成测试流、十对训练/图种子外推到广义序列任务、Transformer 替代、神经生物解释或 Gate 1 所要求的通用轨迹收益。保留 `INCONCLUSIVE` 和所有负向/零向种子结果，符合冻结协议。
