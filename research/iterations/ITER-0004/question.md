The user's continuation request opens an observational representation diagnostic on the original full-noise task, with the same frozen trained models and no new neural mechanism.

Early model output in EXP-0004 already tested the cued candidate. A fixed ridge probe with independent train/validation/final data tests a different, narrower question about linearly accessible uncued information.
